### 2.1 位置编码（day078）

- **本质**：一行加法，加两道护栏。
  ```text
  injected[i] = inputs[i] + table[positions[i]]
  dx   = dInjected                    （逐位传回）
  dTable[p] = Σ_{i: positions[i] = p} dInjected[i]   （按位置**累加**）
  ```
  造表有两条路：`sinusoidal`（公式给出、无参数、可外推）与 `learnable`（每行是参数、定长、越界必须拒绝）。
- **为什么**：因为对齐频率的正弦表有两条**能被证明**的性质：
  ```text
  行范数恒定      ‖PE(p)‖ = √(d/2)      （每一对贡献 sin² + cos² = 1）
  位移律          <PE(p), PE(q)> = Σ_i cos((p−q)/f_i)   只依赖 p − q
  理由            PE(p + δ) = R_δ · PE(p)，而 R_δ 是分块**正交旋转**
  ```
  实测（`d = 4`、`base = 10000`）：`PE(0) = (0.0, 1.0, 0.0, 1.0)`、
  `PE(1) = (0.841471, 0.540302, 0.01, 0.99995)`；`δ = 1` 的内积 `1.540252306284805`
  与闭式 `cos(1) + cos(0.01) = 0.540302 + 0.999950` **逐位对上**；
  `|R_1·PE(p) − PE(p+1)|` 最大值 `1.11e-16`、`|R_3·PE(p) − PE(p+3)|` 恰为 `0.00e+00`。
- **误区**：
  ```text
  ① 把表梯度"按行覆盖"（grad_table[positions[i]] = row_gradients[i]）
     形状正确、不报错；位置重复时表梯度偏小（差 4.90e-03），
     只表现为"位置编码学得慢一点"
  ② day073 的 staggered 配对（cos 用了隔壁频率）会让两条性质一起失效
     ——行范数变成 (1.414214, 1.642622, 1.669655, 1.390494)
  ③ 下界写成均匀分布处的 (1−1/V)/V = 0.138889 是错的；
     轨道只覆盖 n 个类别 ⇒ 最优输出是**袋子分布**，
     正确的界是 (n−1)/(n·V) = 3/24 = 0.125000
  ```
- **唯一"值钱"的结论**：没有位置信息时，"第 0 位是什么"最多只能被读成
  "这一袋里有什么"；差 `(n−1)/(n·V) = 0.125000` 就是**位置知识的价格**。
  四个刻度实测（同一任务、同一批初始参数）：`none` 停在 `0.125003`（命中率 25%）、
  `sinusoidal` `0.003188`（100%）、`learnable_random` `0.003872`（100%）、
  `learnable_from_sine` `0.000477`（100%）——**等变变体停在界上，破对称变体越过界**。

### 2.2 一个块：三个子层、两处残差、两种反向（day079）

- **本质**：六个阶段——
  ```text
  ① norm1 = LN(inputs)        ④ norm2 = LN(residual1)
  ② branch1 = attention(norm1) ⑤ branch2 = ffn(norm2)
  ③ residual1 = inputs + branch1  ⑥ output = residual1 + branch2
  ```
  而 `post-LN` 只差一件事：`y = LN(x + F(x))` 与 `y = x + F(LN(x))`
  **是同一条代码路径上的一个位置差**。
- **为什么**：因为"一个块"带来了三样可以手算的东西。
  ```text
  LayerNorm（x = (1,2,3,4)）  μ = 2.5；σ² = 5/4 = 1.25
                             x̂ = (−1.341641, −0.447214, 0.447214, 1.341641)
  前馈参数量（d=6, d_ff=4d=24）  4d + 2·d·d_ff + d_ff + d = 24 + 288 + 24 + 6 = 342
  残差反向             dx = dy + dF      ← 那个 dy **不带任何雅可比**
  ```
  深度实验（8 层，相对第 1 层的输入梯度）：`pre_residual` `9.27e+00`、
  `post_residual` `9.45e-01`、`bare`（关掉 `+x`）`1.92e-03`——
  **pre 与 bare 在 8 层上相差 4832 倍**。
- **误区**（本章踩到的坑最密集）：
  ```text
  ① 反向里两个 add 漏掉：形状全对、训练也真的在动，只是梯度少了一条路
  ② "块没有拥有它的第一个子层"：把算好的注意力账当参数传进来，
     pre-LN 下注意力作用在 LN(x) 上 ⇒ 两边算的不是同一个函数
     （norm1_gamma 那一项差 1e-1 量级）
  ③ eps **不是**误差：把判据写成"方差应当为 1"会亮红，
     而那是**定义的一部分**（真实方差是 σ²/(σ²+eps)，σ² ≈ 3.43e-4、
     eps = 1e-5，所以"方差离 1"是 3.43e-04）
  ④ 交叉注意力加因果掩码：n_tgt == n_src 时掩码形状刚好合适 ⇒ **不报错**，
     只是每一行能看到的源位置少了一半（代价 1.00e+00）⇒ 显式拒绝
  ⑤ source_inputs 少一条链：dSource = dK·W_k + dV·W_v 是**两条链之和**
  ```
- 九项梯度校验四组配置全部落在 `1e-10` 量级（容差 `1e-6`，隔着四个数量级）；
  交叉注意力六项最大相对误差 `5.77e-11`，其中 `source_inputs` 是 `5.77e-11`。
- 代码：[../../day083/源码/smart-research-agent/smart_research_agent/encoder_decoder/layers.py](../../day083/源码/smart-research-agent/smart_research_agent/encoder_decoder/layers.py)、
  [depth.py](../../day083/源码/smart-research-agent/smart_research_agent/encoder_decoder/depth.py)

### 2.3 一条链：复制 N 份（day080）

- **本质**：五个阶段，前向只有三行。
  ```python
  attention = block_attention(block_params, current, attention_params, placement=placement)
  forward = encoder_block(block_params, current, attention, ...)
  current = forward.output
  ```
  反向的**全部难点在一行**：`current = layer_grads.grad_inputs`（换手）。
- **为什么**：因为"复制"这件事带来三个新读数，而且每一个都能手算。
  ```text
  参数量  块 342 + 注意力 144 = 486；整条链 4 × 486 = 1944
          flatten() 只压平块参数 ⇒ 4 × 342 = 1368 个数
  逐层读数  增益 ‖y_i‖/‖x_i‖、直通占比 ‖x‖/(‖x‖+‖b1‖+‖b2‖)、梯度范数
  逐层 ‖dx‖  0.317052 / 0.286225 / 0.257685 / 0.227080
              相邻比值 0.902771 / 0.900288 / 0.881232，几何平均 0.894712
  ```
  那条恒等式 `mean_step_ratio ** (N−1) == ‖dx_{N−1}‖ / ‖dx_0‖` 是**数一数个数**
  数出来的：`dx` 序列有 N 个数、只有 N−1 个相邻比值，而 `dy_N` **不在那个序列里**。
- **误区**：
  ```text
  ① 前向把 y_i 重新算一遍而不是原样传给下一层（差 1e-16 量级）——
     它让"与手写循环逐位一致"这条性质失去意义
  ② 反向漏掉换手：每一层都拿 dLoss/dy_N 当 grad_output ⇒
     第 0 层的 dW_in 相对差 **2.18e-01**，而形状全对、损失曲线看起来也在动
  ③ 范数用普通 sum：链长了会累积出 1e-13 量级偏差，而读数是跨层比较的（用 math.fsum）
  ④ "残差关之后梯度一定单调衰减"是**错的**——
     bare 那一列在 2 层时掉到 0.35、4 层时又涨到 1.54、8 层时才塌
  ⑤ 用 `is` 判"链上传递的是同一个值"：`==` 成立而 `is` 是 False
     （记录会重建一份等值元组）——判据必须与承诺对齐
  ```
- 堆叠实验（2 变体 × 6 档深度）：`residual` 的整体比一直在 `1.43 ~ 1.69` 之间摆
  （每层倍数极差 `1.441197 < 2` ⇒ 与深度无关）；`bare` 从 `2.10e-01` 塌到 `6.90e-05`
  （每层倍数极差 `11.097718`）。
- **一个必须写下来的差异**：生成的 PyTorch 脚本在本机实测 **2040** 个可训练参数，
  本课解析式 **1944**，差 `96 = N × 4d`——来自 `nn.MultiheadAttention` 的四个投影**带偏置**。
  "把它凑平是最坏的处理方式"：差异要能被**逐项解释**，而不是被消灭。
- 代码：[../../day083/源码/smart-research-agent/smart_research_agent/transformer_stack/layers.py](../../day083/源码/smart-research-agent/smart_research_agent/transformer_stack/layers.py)、
  [study.py](../../day083/源码/smart-research-agent/smart_research_agent/transformer_stack/study.py)

### 2.4 训练：五个旋钮与两个相（day081）

- **本质**："训练相 / 推理相"两段代码，而两段之间只差一行：
  ```python
  current, mask_i, scale_i = dropout_forward(forward.output, rate=..., seed=...)
  current = dropout_backward(current, mask_i, scale_i)      # 反向，顺序不能反
  ```
  五个旋钮：初始化、Dropout、学习率、调度、裁剪（外加早停）。
- **为什么**：因为本课要给一个**带随机性**的东西配上**逐位断言**，办法是让随机性可注入。
  ```text
  inverted dropout  训练时置零并放大 1/(1−p)；推理时什么也不做
                    ⇒ 推理路径与"没有 dropout 的模型"**逐位相同**
  mask_seed = seed + step × 1009 + layer × 31
                    ⇒ 同一个 (seed, step, layer) 唯一决定一张掩码
  "掩码固定 ⇒ 梯度可校验"   掩码固定之后 y = x ⊙ m · s 是线性对角算子，
                    梯度完全可用中心差分逐项核对（正确在 1e-6 以内；
                    先反传再乘掩码的错法与中心差分差 > 1e-3）
  ```
- **误区**：
  ```text
  ① "随机所以无法差分校验"这句话说错了：随机性属于掩码的生成，
     不属于这一次计算
  ② `dropout = 0` 时两种顺序都对（掩码全是 1）⇒ 该检查只在 rate > 0 时有分辨力
  ③ 判据不能落"最好的一步"：那是训练相里一个幸运掩码，换种子就变 ⇒ 落在 eval_loss
  ④ 初始化幅度决定"发散 / 不发散"：kaiming 的初始增益 7.756731 ⇒ lr = 0.1 下第 7 步发散
  ⑤ `kaiming / xavier` 在 fan_in == fan_out 时**不**相等，比值恒是 √2
  ⑥ 溢出发生在发散判据之前："损失涨到初始值的 1000 倍"这条判据
     在数值溢出面前永远不会被触发 ⇒ 三套数值护栏（逐分量 / 范数 / fsum）
  ⑦ 一次真实的漏传：`placement`——两条本该不同的曲线重合成一条，
     **"两条不同的配置给出同一个结果"是漏传最典型的信号**
  ```
- 反直觉的那一条：**"梯度小" ≠ "学不好"**。day079 留下的"post-LN 梯度衰减"问题
  在本课**没有被复现**——`post-LN` 用 `constant` 调度反而改善 `23.7270` 倍，
  而 `pre-LN` 只改善 `2.5249` 倍。
- 代码：[../../day083/源码/smart-research-agent/smart_research_agent/training_optim/dropout.py](../../day083/源码/smart-research-agent/smart_research_agent/training_optim/dropout.py)、

### 2.5 三个变体：同一个块，三种接法（day082）

- **本质**：`encoder_only` / `decoder_only` / `encoder_decoder` 只差三处
  （自注意力掩码、有没有第二路、训练目标），而**注意力算术一行都没有新写**。
- **为什么**：因为这一课把"因果"从一句代码变成一条**实测读数**。
  ```text
  扰动输入第 j 个 token（乘 1.5），重新前向，看输出第 i 行变多少：
    被掩码挡掉的 (i, j)   Δ **恰好 0.0**
    允许的 (i, j)         Δ 明显大于 0
  ```
  三条判据同时给：**逐位**（挡掉的格子 `== 0.0`）、**双向**（允许的格子里最小读数
  `allowed_floor > 0`，encoder_only 是 `5.061108e-03`）、**反证**（掩码换错立刻亮红，
  `decoder_only` 用全开掩码 ⇒ 越界 6 格）。
- **误区**：
  ```text
  ① 掩码给错了流：不会报错（形状合法），只是"看到了不该看的位置"
  ② 反向里没把掩码穿过去：前向因果完全正确，只有梯度里混进了"未来"的贡献
  ③ grad_source_inputs 没接回源序列：形状**完全合法**
  ④ `encoder_decoder + pads` 时 T5 的解码器读不到填充信息 ⇒
     显式拒绝，而不是悄悄把掩码丢掉
  ⑤ 判据拿"它自己那张掩码"当期望 ⇒ 一串因果掩码的编码器会**全绿**；
     期望必须由调用方构造，**不读 report.mask**
  ⑥ "不适用 ≠ 通过"：若把 applicable=False 记成"通过"，
     那么"把检查全删掉"与"它全都通过"在报告里长得一模一样
  ```
  最值钱的一个对照：`encoder_only` 与 `decoder_only` 的**参数量完全一样**（都是 1458）——
  "BERT 与 GPT 的差别不在参数量，只在接法"。
- 本机实测（`torch 2.14.0+cpu`，`heads = 1`）：PyTorch 参数量 `1722 / 1722 / 3984`，

### 2.6 读表：从"算"到"看"（day083）

- **本质**：前八天一直在**算**，day083 第一次只**看**——而"看"最容易出的错是
  **一张画错的图看起来同样正常**。因此这一课的全部工作是把"看"变成有判据的事。
- **为什么**：最值钱的一句话是
  ```text
  一行的熵 ≤ ln(这一行能看到的位置数)        ← Jensen 不等式，不是经验规律
  full（BERT）   第 0 行天花板 ln n（n = 4 时 1.386294）
  causal（GPT）  第 0 行天花板 ln 1 = 0，全表平均 (1/n)Σln(i+1) = 0.794513
  ```
  于是"GPT 的注意力比 BERT 尖"这句话里，**有一半是掩码造成的**——
  必须给三个数才可比：`entropy` / `ceiling` / `normalized_entropy = entropy / ceiling`。
  实测（3 层、2 头）：逐层熵 `0.7925 / 0.7943 / 0.7932`，归一化 `0.9975 / 0.9998 / 0.9983`，
  平均归一化熵 `0.9985`——**未训练模型的注意力几乎是均匀的**（它贴在天花板上）。
- **为什么还有第二件事**：残差把每层输出**加上**输入 ⇒ 信息经**两跳**到达输出，
  所以最后一层热力图会骗人。修正方式是滚动：
  ```text
  Â_l = α·A_l + (1−α)·I        ← 那一项 (1−α)·I 就是 day079 的残差
  R = Â_L ⋯ Â_1               ← 矩阵乘 ⇒ 路径被自动求和；α = 0 时 R = I
  ```
  实测（α = 0.5、3 层）：最后一层归一化熵 `0.998309` → 滚动后 `0.965952`，
  集中度变化 `+0.032358`（**更尖**）。
- **误区**：
  ```text
  ① 读的不是模型算的那一份权重：形状一样、行随机、熵也算得出来
     ⇒ 必须有一条断言钉住"读出来的"与"模型算的"**逐位相同**
  ② 两条读法混着比：多头缩放是 1/√d_head 而不是 1/√d_k（差 √heads 倍）
  ③ head_redundancy 比较两张**掩码不同**的表 —— 比的是"能看到多少"，
     不是"看了哪里" ⇒ 入口要求形状与掩码都相同
  ④ level_of 不校验"权重 ≤ 1"：两张没归一化的表加起来画出来会是
     "这个位置占了全部注意力"
  ⑤ 跨掩码比较不先归一化 ⇒ 比的是掩码
  ```
- 10 级文本热力图（`" .:-=+*#%@"`，第 k 级区间 `[k/9, (k+1)/9)`）之所以值得一条性质，
  是因为**渲染 → 解析必须逐级相同**——它挡住的是"把 1 与 0 画得一样"这类
  "只会让人看着图得出错的结论"的实现错误。
- 代码：[../../day083/源码/smart-research-agent/smart_research_agent/explainability/analyze.py](../../day083/源码/smart-research-agent/smart_research_agent/explainability/analyze.py)、
  [rollout.py](../../day083/源码/smart-research-agent/smart_research_agent/explainability/rollout.py)

### 3.1 走读的五个提问点

```text
① 为什么"位置编码"要插在注意力**之前**，而不是里面？
   因为它是一次**加法**，因此反向只多两条式子（dx 逐位、dTable 累加）；
   插在里面会让 day075 那层一行未改这条纪律失效
② 为什么"块保形"这条性质值得一条断言？
   因为链式前向的 carry 步骤"在数学上不可能失败"——如果它失败了，
   一定是代码里混进了别的运算（比如重算一遍）
③ 为什么"随机性"没有破坏可测试性？
   因为随机性被推到了**掩码的生成**里，而这一次计算本身是确定性的
   （掩码固定 ⇒ y = x ⊙ m · s 是线性对角算子）
④ 为什么"因果性"要用扰动来量，而不是读 `causal=True` 四个字？
   因为代码可以三处对不上：掩码传错了流 / 算对了但没传进去 / 反向里没穿过去
   —— 三种失败**都不会以异常的形式露面**
⑤ 为什么"熵"要跟天花板比？
   因为跨掩码的熵不可比：0.588 的熵差里，全部是掩码的账
```

**四个最值钱的推导（第 1:10 段要做的事）：**

```text
① 为什么对齐频率的正弦表"行范数恒定"且"内积只依赖位移"
   每一对 (sin, cos) 贡献 sin² + cos² = 1 ⇒ ‖PE(p)‖² = d/2
   sin(a)sin(b) + cos(a)cos(b) = cos(a − b) ⇒ 内积只依赖 p − q
② 位置选择任务的下界
   等变性 ⇒ g(x^{(k)}) = π_k·G；逐行损失；轨道平均；每行最优是**袋子分布**
   ⇒ (1/(n²V))·Σ_j Σ_k ‖G_j − o_k‖² 在 G_j = mean_k o_k 处取到 (n−1)/(n·V)
③ 残差为什么让梯度"不减值"
   前向 y = x + F(x)；反向 dx = dy + dF —— 那个 dy **不带任何雅可比**
   ⇒ 无论 F 的雅可比多么小，dy 这条通路都原样到达
④ 为什么要用"扰动"量因果性
   被掩码挡掉的 (i, j)：scores[i][j] 算了，但 exp / sum / 加权三步都不碰它
   ⇒ 改它不会改变任何一个中间量 ⇒ 输出逐位不变（Δ 恰好 0.0）
```

## 今日总结

复习不是"再看一遍"，而是**把离散的知识点压缩成少数几个可提取的心智模型**。
今天的内容可以压缩成五句话：

1. **一切可手算性来自"选对支点"**：`PE(0) = (0,1,0,1)`（day078）、
   `x = (1,2,3,4)` 的 LayerNorm（day079）、342 / 486 / 1944 的整数账（day080）、
   `101/141.43 = 0.714142`（day081）、`16/16` 与 `10/16`（day082）、
   `ln 4 = 1.386294`（day083）——期望值来自推导，而不是"上次跑出来的值"。
2. **一切可靠性来自边界处的显式校验**：位置越界拒绝（day078）、
   交叉注意力拒绝因果掩码（day079）、组件拼接的形状检查（day079/080）、
   `pads` 的显式拒绝（day082）——**"悄悄丢掉"是最危险的失败模式**。
3. **一切"不报错"的错误都要专门设一条读数**：`dTable` 覆盖、反向漏 `add`、
   漏换手、`placement` 漏传、掩码给错流、读错层——它们全都"形状正确、训练还在动"。
4. **一切可测试性来自"两处实现 + 一条断言"**：解析 vs 数值（六天各一次）、
   `heads=1` vs day075（day076）、`forward.output == 手写循环`（day080）、
   `self_records == block_weights`（day083）、六处逐位常量（第 4.2 节）。
5. **一切"更强/更差"的说法都要能被算出来或被限定**：位置编码的价值是 `0.125`
   （day078）、残差的价值是 4832 倍（day079）、LoRA 式的"每层倍数与深度无关"
   是 `1.441197 < 2`（day080）、"梯度小 ≠ 学不好"（day081）、
   "掩码的账占满了熵差"（day083）——**每一条都带着它的适用边界**。
