# 循环神经网络 RNN / LSTM：时间轴上的权重共享与 BPTT（day094 / M8-D5）

> 一本可随手翻的手册，与 `smart_research_agent/sequence_models/` 一一对应。
> 每一节的每个结论都能在包内找到对应函数；每个读数都能现场重跑。

## 1. 这一课要回答什么

day093 的卷积说：**同一组核被用到空间的每一个位置**。今天把同一句话搬到时间轴：

```text
时间轴权重共享  同一组权重被用到 T 个时刻    ⇒ 参数量与序列长度 T **完全无关**
隐状态          对"到目前为止的全部历史"的有损摘要
BPTT            与 day090 同一条纪律：梯度一律 `+=`（写成 `=` 只留下最后一步）
```

一句话本质：**同一组权重在时间轴的每一个时刻被重复使用。**
实现见 `sequence_models/layers.py`（层）与 `sequence_models/gradients.py`（反向）。

## 2. 两种循环单元

```text
rnn    h_t = act(W_h·h_{t−1} + W_x·x_t + b)                  一个状态 h
lstm   i,f,o = σ(…)，g = tanh(…)；c_t = f⊙c_{t−1} + i⊙g；h_t = o⊙tanh(c_t)   一对状态 (h, c)
```

| 单元 | 状态形状 | 参数量 |
|------|----------|--------|
| `rnn` | `(h,)` | `H·D + H·H + H` |
| `lstm` | `(h, c)` | `4·(H·D + H·H + H)` |

两个公式里**都没有 T**——这就是"时间轴上的权重共享"。
权重形状：RNN 的 `wx (H, D)` / `wh (H, H)`；LSTM 的 `wx (4H, D)` / `wh (4H, H)`，
`4H` 行按 **i / f / o / g** 分成四块（`types.GATES` 与 `types.GATE_ROW_BLOCKS`）。

### 2.1 一个刻意的例外：遗忘门偏置 = 1

`f = σ(b_f)`：`b_f = 0` 时 `f ≈ 0.5`（记忆每一步被砍掉一半），
`b_f = 1` 时 `f ≈ 0.731`（记忆通道一开始就基本连通）。
`initialize_lstm` 把遗忘门那一块偏置写成 `DEFAULT_FORGET_BIAS = 1.0`——
它是本课唯一一处**不由 LCG 决定**的数，写进常量也写进笔记。

## 3. 步数对齐：T 个输入 ⇒ T 个状态

```text
rnn_forward   返回 h₁ … h_T（T 个）；h₀ 是初值（缺省全零），**不出现在输出里**
lstm_forward  返回 T 个 h 与 T 个 c
```

把 `h₀` 也算进输出会得到 `T+1` 个状态。它**不会报错**：下游 `zip` 会静默截断，
于是"第 t 个状态"与"第 t 个输入"整体错位一格——症状是训练仍然在跑，
而"模型记不记得住"这个结论是假的。因此本包为此单列一族 `TimeStepError`。

## 4. 算子层：四个必然要用到的函数

| 函数 | 作用 |
|------|------|
| `matvec` | `W·x`（`W` 是 `(H, D)`，行是输出、列是输入） |
| `matvec_transpose` | `Wᵀ·g`（把回传梯度投影回输入空间，反向的一半） |
| `outer` | `g ⊗ x`（`dW` 的**每一时刻那一片**，累加发生在 `gradients` 里） |
| `gate_blocks` | 把 `4H` 的打分切成 `i / f / o / g` 四块 |

行是输出、列是输入——与 `torch.nn.Linear`（`weight` 形状 `(out, in)`）以及
day089 的 `Dense` 同口径。把 `matvec` 与 `matvec_transpose` 写反，
方阵时**形状仍然合法**，只有数值差分能发现。

## 5. BPTT：一条纪律，与 day090 / day093 逐字相同

```text
对 t = T … 1（倒序）：
    d_h  = grad_states[t] + 从 t+1 带上来的那部分
    dz_t = d_h ⊙ act'(z_t)                  ← 激活的导数是 day090 的
    dW_x += dz_t ⊗ x_t                      ← **累加**
    dW_h += dz_t ⊗ h_{t−1}
    db   += dz_t
    dx_t  = W_xᵀ·dz_t；h_{t−1} ← W_hᵀ·dz_t
```

写成 `=` 的后果不是报错，而是"只留下最后一步的贡献"。
本课的现场读数：三步都回传 `‖dW‖ = 3.014188`，只留最后一步 `1.503321`
——**只剩 49.9% 的量**，而报告里看不出是代码错了。

## 6. LSTM 的反向多了一条通道

```text
h_t = o ⊙ tanh(c_t)
  ⇒ d_o       = dh ⊙ tanh(c_t)
  ⇒ dc       += dh ⊙ o ⊙ (1 − tanh(c_t)²)     ← 这一条链最容易漏
c_t = f ⊙ c_{t−1} + i ⊙ g
  ⇒ d_f       = dc ⊙ c_{t−1}
  ⇒ dc_{t−1}  = dc ⊙ f                          ← **记忆通道：只乘 f**
  ⇒ d_i       = dc ⊙ g；d_g = dc ⊙ i
```

`dc_{t−1} = dc ⊙ f` 就是"梯度高速公路"的全部内容：
梯度沿记忆通道走**只乘遗忘门**，而不是乘 `tanh'·W_h`。
四个门的激活导数同样**不重写**——`sigmoid` 与 `tanh` 都在 day090 的那张表里。

## 7. 为什么 tanh-RNN 记不住远处

```text
∂h_T/∂h_0 = ∏_{t=1..T} (diag(act'(z_t)) · W_h)
|tanh'| ≤ 1  ⇒  ‖∂h_T/∂h_0‖ ≤ ‖W_h‖^T   ⇒ 随 T **指数衰减**
```

第 ⑦ 条性质把它量出来：`W_h = 0.5`、`T = 8` 时 carry `2.864e-03 ≤ 0.5⁸ = 3.906e-03`；
同一组设置下 LSTM 的 `‖∂L/∂c_0‖ = 1.000000`（`f = 1` ⇒ 记忆原样带回）。
**两者之差 `9.971e-01` 被写成一条下界判据**（`>= 0.5`）——
没有它，把 LSTM 写成"记忆通道不独立"的假 LSTM，前六条会全绿。

## 8. 七个失败族

| 族 | 什么时候抛 | 该谁去修 |
|----|-----------|---------|
| `ShapeError` | 输入维 / 隐层宽 / 权重行列对不上 | 改调用 |
| `ParameterError` | `hidden_size` / 序列长度 / 步数非法 | 改调用 |
| `NumericError` | `nan` / `inf` 混进状态或梯度 | 改数据或改实现 |
| `TimeStepError` | 返回 / 缓存的状态数与输入步数不是同一个 T | 改调用 |
| `BackwardError` | BPTT 的缓存与回传梯度不是同一次前向 | 改调用 |
| `GradientError` | 一次 BPTT 的梯度范数非有限或超过上界 | 改超参 |

`GradientError` **今天回来了**，理由与 day090 那一次不同：

```text
day090  抛它是因为"解析梯度与数值差分对不上"   （离线对账的结论）
day094  抛它是因为"梯度真的爆了"               （这一步就不该继续）
```

守卫是 `train.check_gradient_norm`：进入优化器之前先看范数。

## 9. 七条性质

| # | 性质 | 判据 |
|---|------|------|
| ① | 一步 = 手写递推 | 逐位相等 |
| ② | 三门钉死时记忆原样冻结 | 逐位相等 |
| ③ | T 步与 1 步同一组权重 | 逐位 + 整数 |
| ④ | T 个输入 ⇒ T 个状态 | 整数相等 |
| ⑤ | `∂c_T/∂c_0 = ∏f_t` | ≤ 1e-12 |
| ⑥ | 解析 BPTT = 数值差分 | ≤ 1e-9 |
| ⑦ | LSTM 的长程信号强于 tanh-RNN | **下界** ≥ 0.5 |

判据三类：**相等**、**不超过上界**、**不超过下界**。见 `sequence_models/verify.py`。

## 10. 五条边界

- 只做单层单向的两个单元（`rnn` / `lstm`）：不做双向、不做多层堆叠、不做 GRU。
- 不做批量（batch）维：一次前向处理一条序列。
- 不做 GPU / 向量化：纯 Python 的逐时刻实现，为的是可读与可对账，不是速度。
- 不做截断 BPTT：本课展开到全长（所有读数都在 `T ≤ 8` 的小序列上）。
- 不新增第三方依赖：不 import torch / numpy；PyTorch 只写在对照表里，不安装也不调用。

## 11. 与 Transformer 的正面比较

| | 循环（本课） | 注意力（day075） |
|---|---|---|
| 信息路径长度 | 相距 T 步要过 T 次乘法 | 任意两点一步直达 |
| 并行性 | 第 t 步依赖第 t−1 步 ⇒ **必须串行** | 一次算完全序列的两两打分 |
| 参数与序列长度 | 无关（时间共享） | 无关（权重不随位置变） |
| 位置信息 | 由"顺序"自带 | 必须显式加位置编码（day078） |

两者共享同一句话：**同一组权重被重复使用**。区别只在"共享的维度"与"能不能并行"。
