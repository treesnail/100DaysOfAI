## 一、速答（8 题，每题限时 1 分钟）

**1.** 用一句话说清 **"装上了"与"接上了"** 的区别，并指出本课用哪一行代码把后者变成可断言的。

**2.** 写出本课九段链的**顺序**（中文 + 英文阶段名各一遍）。

**3.** 本课的"清单"为什么必须用 `importlib` **真的解析**子包，而不是读一张手写表？

**4.** 一个包**没有 `__all__`** 时，本课怎么数它的"公开符号数"？为什么不能直接用 `dir(module)`？

**5.** 适配层（`adapters.py`）存在的**唯一理由**是什么？（用一句话回答，并说明"上游改了"时改动落在哪里。）

**6.** 护栏为什么必须排在**第一位**？如果它被放到"生成"之后，最坏后果是什么？

**7.** 打包阶段的两个"减法"分别叫什么、各自的读数是多少？为什么这两个数必须**分开报**？

**8.** 接地阶段的三组编号是什么？为什么"未引用 2"**不是**错误？

## 二、连线（1 题）

**9.** 把左侧的**阶段**与右侧的**承担能力 / 调用到的子系统**连起来：

```text
左侧（阶段）        右侧（承担能力 / 子系统）
a. guard            A. evaluation.rag_metrics（四条离线指标）
b. plan             B. retrieval.context.pack_context
c. retrieve         C. observability（CostTracker / Tracer）

e. generate         E. agent.planner.Planner（+ tools.calculator）
f. ground           F. retrieval.hybrid.build_hybrid_retriever
g. evaluate         G. retrieval.generation.RAGGenerator（+ MockLLM）
h. account / trace  H. retrieval.generation.GroundingReport
```

## 三、对照计算（3 题，写出代入过程）

**10.** 一次运行的四条指标读数是：

```text
金标准 ['k-3']；检索返回 3 条：k-3、k-2、k-6（k-3 排第一）
评估：召回 1.0000 | 精确 0.3333 | MRR 1.0000 | NDCG 1.0000
```

请分别写出召回、精确、MRR 的**算式**，并解释"为什么召回是满分、精确只有 1/3"。

**11.** 记账与手算要给出同一个数。已知：

```text
调用 2 次 | token 210（输入 196 + 输出 14）| 模型 gpt-4o-mini
记账 $0.00003780 | 手算 $0.00003780 | 相对差 0.000000e+00 ≤ 容差 1e-12
```

请说明"手算走的是公式、记账走的是价格表"这句话的含义，以及**为什么相对差是 0** 比"差很小"更强。

**12.** 规划阶段的工具自检读数是：

```text
工具自检 2 + 3 * (4 - 1) = 11 ✓
```

请解释这个算式的三个数字（2 / 3 / 4）各代表什么，并算出 11 的含义。

## 四、诊断（2 题）

**13.**（诊断）下面是两份清单报告的读数，请分别判断"**是否需要动作**"并说明理由：

```text
读数 A  覆盖 8/8 项能力 | 被认领 8 个包 | 无人认领 4 个（indexing、mcp_server、finetune、api）
读数 B  覆盖 7/8 项能力；未覆盖的：offline_evaluation
```

**14.**（诊断）一位同学把复算口径改成了"包含耗时与时间戳"，于是第三条性质
（`assembly_is_reproducible`）**永远失败**。请回答：

```text
（甲）这条性质失败的直接读数会是什么（差异项数 0 还是一大串）？
（乙）这属于哪个失败族？该谁去修？
（丙）正确的修法是什么？（提示：day096 是怎么处理"时钟"的）
```

## 五、推导（2 题）

**15.**（推导）判据方向。已知召回天然落在 `[0, 1]`，精确也落在 `[0, 1]`。

```text
（甲）本课把"召回"做成下界判据（>= 1.0）、把"幻觉引用数"做成上界判据（<= 0）。
      请说明这两条各自想反驳的是哪一类错误。
（乙）如果把"召回 1.0"写成相等判据（== 1.0），会不会失效？为什么本课仍选下界？
（丙）day095 记过一句"没有下界判据时，把两个规则写成同一个，报告会全绿"。
      请结合本课的七条性质，指出**哪一条**是那句老话在结项链上的落点。
```

**16.**（推导）复算摘要。

```text
摘要 f052e4a7dd78d232 = sha256(问题 + 九段记录 + 答案 + 指标 + 费用 + token + span 条数) 的前 16 位
```

请回答：

```text
（甲）为什么这七项足以判定"两次运行是不是同一条链"？
（乙）为什么"时间戳 / uuid / 耗时 / 日志文本"必须被排除在外？
（丙）如果把"span 条数"换成"每个 span 的耗时"，第二条性质会发生什么？
```
