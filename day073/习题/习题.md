## 一、向量与矩阵（第 1 ~ 6 题）

**1.**（手算）给定 `a = (1, 2, 3)`、`b = (4, 5, 6)`：

- `a·b = ?` `‖a‖ = ?` `cos(a, b) = ?`
- 找一个与 `a` 正交的非零向量（给出构造方法，而不是猜一个）。

**2.**（概念）为什么"点积大"不等于"两个向量方向一致"？请举一个反例说明
（提示：把某个向量放大 k 倍）。

**3.**（设计）本课把**零向量**的归一化设计成"直接报错"，而项目里另外两处实现
分别返回 `0.0` 与"原样返回"。请分别说出这三处的**使用场景**，并解释为什么
"三种答案都对"。

**4.**（动手）本课所有求和都用 `math.fsum` 而不是内置 `sum`。请回答：

- 两者的差别是什么？
- 写一段代码，找出一个让 `sum` 与 `fsum` 结果不同的浮点序列（提示：大小极端的数混在一起）。
- 这个差别与"检索里两处余弦必须一致"有什么关系？

**5.**（设计）`validate_matrix` 会拒绝"每行不等长"的输入。如果**不**校验，
一个 3×4 乘 3×3 的矩阵乘法会得到什么？为什么那个结果"看起来正常"？

**6.**（概念）`projection(u, v)` 返回的是一个**标量**而不是向量。请说明：

- 那个标量的数学含义是什么？
- 要把它变回向量需要多做什么？
- 为什么本课选择返回标量？

## 二、softmax 与数值稳定（第 7 ~ 10 题）

**7.**（手算）用公式算出 `softmax([0, 1])` 与 `softmax([0, 2])` 的精确表达式
（用 `e` 表示），并说明它们的关系。

**8.**（概念）"先减最大值"为什么**不改变** softmax 的结果？请用一行恒等式说明，
并说清它改变了什么。

**9.**（动手）验证两件事：

- `softmax([1000, 1001])` 在本实现下是 `(0.268941, 0.731059)`；朴素写法会得到什么？
- `math.log(0.0)` 在 Python 里是抛异常还是返回 `-inf`？本课的 `log_softmax`
  为什么不会撞上它？

**10.**（设计）温度 `T <= 0` 时本包**报错**，而不是"取默认值"。请说明这个选择的理由，
并指出"T = 0 的贪心语义"应该用什么表达。

## 三、概率（第 11 ~ 15 题）

**11.**（手算）对分布 `p = (0.5, 0.25, 0.25)`：

- `H(p) = ?`（用 `ln 2` 表示）
- `困惑度 = ?`
- `KL(p‖均匀 3 事件) = ?`

**12.**（概念）`entropy` 里对 `p_i = 0` 的项直接跳过（贡献 0），而不是写
`-p*log(p)`。后者在 `p = 0` 时会得到什么？为什么"一个 nan"比"一个错值"更麻烦？

**13.**（设计）`cross_entropy(p, q)` 在 `q_i = 0` 而 `p_i > 0` 时报错，
数学上这个值是多少？为什么本课不返回它？

**14.**（动手）采样函数 `sample_index` 吃一个由调用方给的 `u`。
请写一段代码：用 `uniforms(2000, seed=42)` 对 `p = (0.7, 0.2, 0.1)` 采样，
统计三个事件的频率，并说明"为什么这件事必须可复现"。

**15.**（概念）`variance` 按定义算 `E[(X − μ)²]`，而不是用等价公式 `E[X²] − μ²`。
请说明后者的**数值**问题（提示：搜索"灾难性抵消"）。

## 四、联合分布与贝叶斯（第 16 ~ 18 题）

**16.**（手算）对下表（行 = A，列 = B）：

```text
        B1     B2
A1     0.30   0.10
A2     0.20   0.40
```

- `P(A1) = ?` `P(B1) = ?`
- `P(B1|A1) = ?` `P(A1|B1) = ?`
- 两者相等吗？为什么（一句话说清条件概率的方向性）？

**17.**（设计）`posterior_a_given_b(index)` 在**不传先验**时用表的边缘 `P(A)` 作先验，
此时后验必然等于"列条件分布"。请说明：

- 这条自洽性为什么成立？
- 它能帮我们发现哪一类实现错误？

**18.**（概念）"证据为 0"与"似然为 0"两种情况下本课都选择了报错。
请分别说明这两种情况下**如果按公式硬算**会得到什么，以及为什么那个结果有误导性。

## 五、幂迭代与低秩近似（第 19 ~ 22 题）

**19.**（手算）对 `A = diag(2, 1, 0.5)`：

- 三个奇异值分别是多少？
- 秩 1 与秩 2 近似的相对误差（Frobenius 范数口径）各是多少？
- 秩 3 呢？为什么它必然是 0？

**20.**（概念）幂迭代的收敛判据是 `|1 − |cos(v, v_prev)|| <= tolerance`，
而不是逐分量比较。请说明为什么逐分量比较会失败（提示：`v` 与 `−v`）。

**21.**（设计）低秩近似里的 Gram–Schmidt 正交化**不能省**。如果省掉，
第二轮幂迭代会收敛到哪里？造成的后果看起来是什么样（有没有报错）？

**22.**（综合）请用一句话说明"低秩近似"与 day051 的 LoRA 是同一件事的两种说法，
并给出参数量的对比（`n × n` 全参数 vs 秩 `r` 的低秩分解）。

## 六、注意力（第 23 ~ 27 题）

**23.**（概念）把 `Attention(Q, K, V) = softmax(QKᵀ/√d_k)·V` 拆成四步，
并指出每一步用到的是本课哪一个算子。

**24.**（手算）`queries = ((1, 0, 0, 0),)`、`keys = ((1, 0, 0, 0), (0, 1, 0, 0))`：

- 打分矩阵（含缩放）是什么？
- 权重是多少？输出是什么（给 `values = ((1, 0), (0, 1))`）？

**25.**（设计）因果掩码本课用**显式掩码**（`masked_softmax_rows`），
而不用 `-inf`。请写出生产实现常见的那一行代码，并说明本课拒绝它的两条理由。

**26.**（动手）用演示脚本里的那组 Q/K/V：

- 不掩码时三行权重各是什么？平均熵与集中度是多少？
- 掩码之后第 0 行变成什么？为什么"看不到未来"可以写成"权重恰好为 0"？

**27.**（概念）多头的缩放系数是 `1/√(d/heads)` 而不是 `1/√d`。请说明为什么，
并回答"头与头之间有交互吗"。

## 七、为什么除以 √d_k（第 28 ~ 29 题）

**28.**（推导）设 `q`、`k` 的每个分量独立、均值为 0、方差为 `σ²`。
推导 `Var(q·k) = dσ⁴`（写清每一步用到的性质）。

**29.**（动手）跑 `sampled_dot_product_variance`：

- `d = 4 / 16 / 64 / 256` 时，实测方差与理论 `d/9` 差多少？
- **未缩放**的标准差从多少涨到多少？
- **缩放后**的标准差是多少？为什么它恒等于 `σ²` 而**不是** 1？
  （这一条最容易读错，请写清）

## 八、对照与工程（第 30 ~ 32 题）

**30.**（概念）`bridge` 的三种结论 `agrees` / `differs` / `rejected` 各是什么含义？
为什么不能把它们合并成一个布尔值？

**31.**（设计）本课在 `check_cross_entropy` 上踩了两个坑。请分别写清：

- "拿两串顺序不同的数去比"会得到什么、危害是什么；
- "把概率当 logits 传"会得到什么、为什么它**两个方向都可能出现**。

**32.**（写作）这一课**没有**给 `config.py` 加配置项，理由是"容差、温度、秩是
这一次计算的判据，应当进函数参数"。请评价这个取舍：
什么情况下它反而不合适？（提示：想一想"同一套判据要在一百个调用点保持一致"的场景。）
