## 第一章：为什么需要一个"块"

### 1.1 前四天各交出了一件事

```text
day075   一层可训练的自注意力          回答"怎么混合"
day076   把它切成 heads 份             回答"看什么"
day078   把"第几位"加进输入             回答"在哪"
day079   把上面三样拼成一个**块**        回答"怎么堆"
```

"块"这个单位之所以重要，是因为**Transformer 的全部结构都是它的复制与排列**：

```text
编码器   N × [ 自注意力 → 前馈 ]
解码器   N × [ 因果自注意力 → 交叉注意力 → 前馈 ]
```

于是"模型有多深"变成"这个块复制几份"，而"模型是什么形状"变成"块里有没有交叉注意力"。

### 1.2 三个子层，一句话各自的价值

```text
LayerNorm   每一行标准化     把"这一行整体加了多大常数、乘了多大正数"从要学的东西里划掉
前馈         逐位置 4d 往返    给每一行一个"在更宽的空间里做非线性"的机会
残差         y = x + F(x)     反向里多一条**不减值的路**——第 9 章量它值多少
```

前两个子层还有一个共同的、跨天的结论（第 7 章）：

> **LayerNorm 与前馈都是"逐行"算子，因此它们不破坏置换等变性。**
> 打破它的只有位置编码与掩码——day078 的那句话在这里被补完了。

### 1.3 于是今天的架构是"三子层 + 八条性质 + 一个深度实验"

```text
types.py    形状、两张口径表（六个阶段与九项梯度、九阶段与解码器）、八条性质、九条记录
layers.py   LN(+反向) / 前馈(+反向) / 残差 / 编码器块(+反向) / 交叉注意力(+反向) / 解码器块(+反向)
verify.py   九项块级校验 + 六项交叉校验 + 两项解码器校验、八条性质
depth.py    深度实验：三个变体的 ‖∂loss/∂x‖ 表（这一课的值钱结论）
```

三个正交的设计决定让这一课变得便宜：

```text
块的形状**不变**       输入与输出同形 → 块可以被复制任意份（一条断言：保形）
三个子层各自可验证       LN 三条、前馈一条、残差两条、交叉一条，互不依赖
残差是一个**开关**       关掉之后整段代码路径不变，只是那一项 +x 没有了（第 9 章的对照靠它）
```

## 第二章：六个阶段与那张图

### 2.1 编码器块（pre-LN）

```text
          ┌──────────────── 一个 Encoder 块 ────────────────┐
x ──► LN ──► 注意力 ──► ⊕ ──► LN ──► 前馈 ──► ⊕ ──► y        ⊕ = 残差
          └──────────────────────────────────────────────┘

① norm1    = LN(inputs)                ④ norm2    = LN(residual1)
② branch1  = attention(norm1)          ⑤ branch2  = ffn(norm2)
③ residual1= inputs + branch1          ⑥ output   = residual1 + branch2
```

### 2.2 post-LN 只差 LN 的位置

```text
post-LN   y = LN(x + F(x))      阶段顺序变成  branch1 → add1 → norm1 → branch2 → add2 → norm2
pre-LN    y = x + F(LN(x))      阶段顺序是    norm1 → branch1 → add1 → norm2 → branch2 → add2
```

同一批阶段名，只是 LN 转过一格——而**形状完全一样**。演示脚本第 1 节把两种顺序并排打印：

```text
pre-LN    norm1 → branch1 → add1 → norm2 → branch2 → add2
post-LN   branch1 → add1 → norm1 → branch2 → add2 → norm2
```

这正是第 9 章那个实验的全部意义：**一个只差"子层顺序"的改动，效果差三个数量级**。

### 2.3 解码器块（九个阶段）

```text
① norm1 → ② 因果自注意力 → ③ ⊕ → ④ norm2 → ⑤ 交叉注意力 → ⑥ ⊕ → ⑦ norm3 → ⑧ 前馈 → ⑨ ⊕
```

多出来的那一个子层是**交叉注意力**：`Q` 来自解码器、`K/V` 来自编码器的输出。
它是"编码器与解码器之间唯一的连线"，也是第 8 章那条静默错误的来源。

> 思考题：为什么解码器的自注意力**必须**因果，而交叉注意力**必须不**因果？
> 提示：前者面对的是"我正在生成的这一段"（未来还没生成），
> 后者面对的是"已经编码完毕的源序列"（它没有未来）。

## 第三章：LayerNorm —— 把两样东西从"要学的"里划掉

### 3.1 公式与手算锚点

```text
μ_i  = (1/d)·Σ_j x_ij                    每一行的均值
σ²_i = (1/d)·Σ_j (x_ij − μ_i)²           每一行的**有偏**方差（除以 d，与 PyTorch 一致）
x̂_ij = (x_ij − μ_i)/√(σ²_i + eps)         标准化
y_ij = γ_j·x̂_ij + β_j                     γ/β 是**逐维**的（长度 = 隐藏维）
```

手算锚点 `x = (1, 2, 3, 4)`：

```text
μ = 2.5        σ² = (1.5² + 0.5² + 0.5² + 1.5²)/4 = 5/4 = 1.25
x̂ = (−1.5, −0.5, 0.5, 1.5)/√1.25 = (−1.341641, −0.447214, 0.447214, 1.341641)
```

演示脚本第 2 节的实测是 `(-1.341635, -0.447212, 0.447212, 1.341635)`——
**与手算值差在第 6 位**，而那个差就是我们后面要说清的 `eps`。

### 3.2 三条性质：一条"精确"、两条"近似"

| 性质 | 判据 | 实测 |
|------|------|------|
| 每一行标准化 | 均值恰好 0；方差 = `σ²/(σ²+eps)` | 均值偏离 `2.22e-16`、方差偏离 `2.22e-16` |
| 平移不变 | `LN(x + c·1) == LN(x)` | 偏差 `5.77e-15`（eps=1e-12） |
| 正尺度等变 | `LN(λx) == LN(x)`，`λ > 0` | 偏差 `2.11e-11`（eps=1e-12） |
| 逐行独立 | `LN(πx) == πLN(x)`（**逐位**） | `True` |

第一条要展开说，因为它是这一课最容易被误判成 bug 的地方：

```text
eps > 0 时 x̂ 的方差**不是** 1，而是 σ²/(σ² + eps)
本课样本：eps = 1e-5 而 σ² ≈ 3.43e-4 → “方差离 1”是 3.43e-04
```

第一版把判据写成"方差应当为 1"，于是它亮红——而那是**数学**，不是误差。
修法是把判据改成"对每一行分别算期望值 `σ²_i/(σ²_i + eps)` 再比"，
并在证据里把两个数都印出来：

```text
检查 4 行：均值最大偏离 2.22e-16；方差与 σ²/(σ²+eps) 的最大偏离 2.22e-16
（而“方差离 1 多远”是 3.43e-04，它由 eps=1e-05 决定）
```

> 一条判据如果把"定义的一部分"当成"错误"，它训练出来的只会是"看到红先改判据"的坏习惯。
> 这也是为什么证据里必须出现 `eps` 的取值：**读者要能自己判断那个偏差是不是应该存在。**

### 3.3 为什么是 LayerNorm 而不是 BatchNorm

第 4 条性质给出了一条**逐位**的分界：LayerNorm 的统计量取自**同一行的所有维度**，
因此换行序只是把输出行换了序（`==` 成立）；BatchNorm 的统计量跨样本，
换行序会**改变每一行的输出**。

```text
LayerNorm   统计量作用在**特征维** → 逐行独立 → 不破坏置换等变性（day078 的那句话成立）
BatchNorm   统计量作用在**批维**   → 行与行耦合 → 训练/推理还要用两套统计量
```

而 day079 是"块要能被堆叠、还要能被小批量甚至单条序列调用"的一课——
逐行算的统计量在批大小 = 1 时照样有定义，跨批的没有。

## 第四章：前馈 —— 逐位置的两层网络

### 4.1 形状与比例

```text
pre = x·W_inᵀ + b_in        (n, d) → (n, 4d)
h   = act(pre)              逐元素
y   = h·W_outᵀ + b_out      (n, 4d) → (n, d)
```

`d_ff = 4d` 是原论文的取值，本课把它写成一个**派生量**而不是常数：

```text
BlockShape(hidden, ffn, tokens).ffn_ratio = ffn / hidden
本课样本：d = 6、d_ff = 24 → 4.0×；本块**新增**参数 4d + 2·d·d_ff + d_ff + d = 24 + 288 + 24 + 6 = 342
```

### 4.2 逐位置：一条逐位断言

`FFN(πx) == πFFN(x)`（**逐位**）——演示第 4 节实测 `True`。
它与第 3 章的 LayerNorm 合起来说明：

> **块里的前两个子层都是"逐行"的，因此它们不改变置换等变性这一件事。**
> day078 说"打破等变性的只有位置编码与掩码"，今天把这句话补成了"……只有位置编码与掩码"。

### 4.3 两种激活，一个可手算的数

```text
relu   max(0, x)                    在 0 处不可导（本包取**次梯度 0**）
gelu   0.5x(1 + erf(x/√2))          处处可导，且在 0 处的导数是 **0.5**
```

ReLU 的次梯度取 0 有一个具体的后果：被它关掉的神经元在反向里梯度**恰好是 0**。
这让"激活后零点占比"成为一个有意义的读数（`FFNCache.summary_line` 会打印它）。

反向里 ReLU 的导数是**分段常数**（0 或 1），而 GELU 的是一个光滑函数——

```text
dGELU/dx = 0.5(1 + erf(x/√2)) + x·e^{−x²/2}/√(2π)      在 0 处恰好是 0.5
```

两者都能被 `calculus.gradient` 逐点核对（测试里就是这么做的）。

## 第五章：残差 —— 反向里那条 +1 的路

### 5.1 前向一行、反向两处

```text
前向   y = x + F(x)
反向   dx = dy + dF          ← 那个 dy **不带任何雅可比**
```

在块里，这条 +1 的路出现**两次**（两个残差各一次），而写成代码就是两行加法：

```python
d_residual1 = add_matrices(norm2_grads.grad_inputs, checked_grad)   # ← 残差那条路
d_inputs = add_matrices(d_residual1, norm1_grads.grad_inputs)       # ← LN 那条链
```

**两行都是"漏掉不会报错"的**：形状全对、训练也真的在动，只是梯度少了一条路——
而在深堆叠里，那一条路正是梯度能不能活下来的原因（第 9 章量它）。

### 5.2 两条可断言的边界

**其一：两个分支都为 0 时块退化成恒等映射。** "两个"这个词是要紧的：

```text
只把前馈的输出层置零   → residual2 = residual1 = inputs + 注意力输出 ≠ inputs
两个分支都置零         → output = inputs（**逐位**）
```

演示第 5 节实测 `output == inputs → True`，而反向的读数 `‖dx‖/‖dy‖ = 1.000000`——
它**不**等于 1 才是意外；本课的证据里因此一起给出这个比值，用来回答"残差那条路占了多少"。

**其二：把分支整体缩小，`dx` 不会一起趋零。** 做法是把前馈的输出层乘上 `s = 1 → 1/16`：

```text
把前馈输出层压到 1/16：有残差 ‖dx‖ 变为原来的 1.13e+00、无残差变为 6.19e-02——两者相差 18.2 倍
```

有残差那一列**几乎没变**（1.13 倍，甚至略涨），因为 `dy` 那一项与 `s` 无关。

### 5.3 一处踩过的坑：注意力在不在"被检查的函数"里面

第一版的 `encoder_block` 把**算好的**注意力账当参数传进来，而 pre-LN 时注意力作用在
`LN(x)` 上——于是 `γ₁/β₁` 会改变注意力的输出：

```text
数值侧扰动 γ₁        传进来的那份注意力**不会变** ⇒ 分支一不变
解析侧用 attn 的梯度  却算进了"γ₁ → LN → 注意力 → 输出"那一条链
⇒ 两边算的不是同一个函数，norm1_gamma 那一项差 1e-1 量级
```

`1e-1` 是**最像 bug 的量级**：它比数值差分的分辨率（1e-11）大十个数量级，
又比"真的写错了"小一个数量级。而根因是一句结构上的话：**块没有拥有它的第一个子层**。

修法是加一个 `block_attention(params, inputs, attention_params, *, placement)`，
让"造注意力"与"用注意力"发生在同一个函数里：

```text
pre-LN   注意力作用在 LN(x) 上        post-LN   注意力作用在 x 上
```

改完之后四组配置（pre/post × 残差开/关）的九项校验全部落到 `1e-10` 量级。

## 第六章：九项梯度校验

### 6.1 名单与公式

```text
norm1_gamma   dGamma = Σ_rows dOut_norm ⊙ x̂（**按行相加**：gamma 被所有行共用）
norm1_beta    dBeta  = Σ_rows dOut_norm（纯求和，不经过 x̂）
ffn_w_in      dW_in  = (dPre ⊙ act')ᵀ · ln1_out
ffn_b_in      dB_in  = Σ_rows (dPre ⊙ act')
ffn_w_out     dW_out = dOutᵀ · hidden
ffn_b_out     dB_out = Σ_rows dOut
norm2_gamma   同上（但 dOut_norm 来自**块输出**那一路）
norm2_beta    同上
inputs        dx = dOut + dNorm1_inputs + dNorm2_inputs   ← **第一项就是残差那条 +1 的路**
```

### 6.2 四组配置的实测

```text
pre-LN + 残差开   9 项通过 | 最大相对误差 8.28e-11
pre-LN + 残差关   9 项通过 | 最大相对误差 5.09e-11
post-LN + 残差开  9 项通过 | 最大相对误差 3.61e-10
post-LN + 残差关  9 项通过 | 最大相对误差 3.92e-10
```

容差 `1e-6`，实测 `1e-10` 量级——**隔着四个数量级**，而"真的写错了"通常是 `1e-2` 以上。

### 6.3 四处口径必须两边一致

```text
损失口径      两侧都用 mean_squared_error（同一个函数）
placement     两侧都是同一个 pre/post
use_residual  两侧都是同一个残差开关
causal        两侧都是同一个因果开关——**而它会影响注意力的输出**
```

前三条是 day076 的教训，第四条是本课新增的（它对应 5.3 节那个坑）。
它们全部由**同一组参数**传给两侧，而两侧都走同一个 `block_attention` 与 `encoder_block`，
因此"忘了传"在结构上不可能发生。

### 6.4 交叉注意力的六项：唯一"两路"的地方

```text
w_query   dW_q = dQᵀ · target
w_key     dW_k = dKᵀ · source
w_value   dW_v = dVᵀ · source
w_output  dW_o = dOutᵀ · context
target_inputs    dTarget = dQ · W_q                 ← **只有一条链**
source_inputs    dSource = dK · W_k + dV · W_v      ← **两条链之和**（少一条不报错）
```

演示第 8 节的实测：

```text
cross 梯度校验 6 项：通过 6、失败 0 | 最大相对误差 5.77e-11
    w_query 3.07e-11、w_key 2.93e-11、w_value 3.79e-11、w_output 6.01e-12、
    target_inputs 3.70e-11、source_inputs 5.77e-11
```

而"同一个 `dRaw` 分给两个来源"这件事解释了一个形状上的不对称：
`dTarget` 与 target 同行数、`dSource` 与 source 同行数——**它们不必相等**。

## 第七章：八条性质

| 性质 | 前提 | 失败意味着 |
|------|------|-----------|
| `norm_rows_are_standardized` | 任何 LN | 标准化写错了（均值/方差没落到定义上） |
| `norm_is_invariant_to_a_constant_shift` | 任何 LN | 平移被当成了信息 |
| `norm_is_equivariant_to_positive_scaling` | 任何 LN | 尺度被当成了信息 |
| `norm_is_row_independent` | 任何 LN | 统计量跨行取了（**逐位**判据） |
| `feed_forward_is_position_wise` | 任何前馈 | 前馈跨行耦合了（**逐位**判据） |
| `residual_is_the_identity_when_the_branch_vanishes` | 两个分支都为零 | 残差那条路没生效 |
| `residual_keeps_a_unit_path_in_the_gradient` | 任何残差块 | 残差只在前向生效、反向漏了 |
| `cross_attention_must_not_be_causal` | 交叉注意力 | 跨路掩码被当成了默认值 |

演示第 9 节的实测汇总：

```text
性质检查 8 项：通过 8、失败 0
```

三条必须说清的地方：

```text
① 第 4、5 条用 == 断言（逐行算子不产生任何求和顺序的变化），
   而第 2、3 条只能容差比较（eps 让"精确恒等式"变成"近似"）。
② 第 6 条要求**两个**分支都为零——只零一个是不够的（5.2 节的那个坑）。
③ 第 8 条不只断言"会拒绝"：它把**加错的代价**也量出来。
```

## 第八章：交叉注意力**不能**加因果掩码

### 8.1 为什么它没有"未来"

```text
自注意力（解码器）   Q/K/V 都来自同一路 → 必须加因果掩码（位置 i 不许看 i 之后）
交叉注意力           Q 来自解码器、K/V 来自编码器 → 因果掩码**没有意义**
```

因果性是**同一段序列内部**的性质；交叉注意力的 `K/V` 是一段已经编码完毕的源序列，
它没有"未来"可言，加掩码只会把源序列的后半段删掉。

### 8.2 它的失效方式很坏

```text
n_tgt == n_src   掩码形状刚好合适 → **不报错**，只是每一行能看到的源位置少了一半
n_tgt >  n_src   掩码形状对不上   → 会报形状错误（那还算运气好）
```

演示第 9 节把这两种情形都量了出来：

```text
causal=True 是否被拒绝：True；
n_tgt == n_src == 4：掩码形状刚好合适 → **不报错**，而权重被改掉了 1.00e+00
```

`1.00e+00` 是"最大相对误差"的上界（权重被整行重写）——
**一个方阵掩码在 n_tgt == n_src 时"恰好"合适，而它造成的破坏是 100%。**

### 8.3 于是它是一条拒绝，而不是一句注释

```python
if causal:
    raise AssemblyError("交叉注意力不能被赋予因果掩码：……"
                        "注意这个错误在 n_tgt == n_src 时**不会**以形状错误的形式暴露出来，"
                        "因此本包在这里直接拒绝。")
```

这是本课新增的失败族 `AssemblyError` 的第一条用例。它存在的理由是前几天的失败都对应
"一个函数拿了坏参数"，而这一次是**两个各自合法的部件拼不成一个合法的整体**：

```text
ParameterError   layers = 0                    → 改一个数
AssemblyError    W_k 的列数与 source 不同宽      → 改"这两个部件怎么接"
AssemblyError    自注意力不是因果的              → 改调用方传进来的那一份账
AssemblyError    编码器输出与解码器不同宽        → 两个数各自都合法，拼起来不成立
```

## 第九章：深度实验 —— 残差值多少钱

> 这是这一课唯一"值钱"的结论，也是它最容易被讲成"经验之谈"的地方。
> 完整数据在 `docs/encoder_decoder.md` 第 10 节。

### 9.1 问题只有一个

```text
堆 N 层之后，最底层输入梯度的范数 ‖∂loss/∂x‖ 是多少？
```

三个变体，一次只改一个旋钮：

```text
pre_residual    y = x + F(LN(x))    现代实现的主流
post_residual   y = LN(x + F(x))    原论文的写法
bare            y = F(LN(x))        **把那一项 +x 关掉**（同一条代码路径）
```

### 9.2 实测

```text
变体           1 层        2 层        4 层        8 层        相对第 1 层（8 层）
pre_residual   0.146041    0.313533    1.101210    1.353129    9.27e+00
post_residual  0.374888    0.386643    0.350414    0.354252    9.45e-01
bare           0.228338    0.080797    0.351793    0.000438    1.92e-03
```

三个读法：

```text
pre        随深度**单调变大**（1.00 → 2.15 → 7.54 → 9.27）——那条 +1 路在每一层都完整地传回来
post       基本持平（1.00 → 1.03 → 0.93 → 0.94），但**不再增长**
bare       8 层之后只剩第 1 层的 1.92e-03——而它的中间点**并不单调**（4 层时是 1.54）
```

两个变体（pre 与 bare）在 8 层上的比值是 **4832 倍**，而它们的形状、参数量、
初始化完全一样——**唯一的差别就是那一行 `+x`**。

`bare` 那一列的**不单调**值得单独说一句：它在 2 层时掉到 0.35、4 层时又涨到 1.54、
8 层时塌到 1.92e-03。这说明

```text
"关掉残差之后梯度一定单调衰减"这句话是**错的**——
它取决于每一层随机到的雅可比谱，而这份表只有一颗种子
```

因此本课把判据定在**最深一层**（8 层上 `bare < pre/10`），而不是"逐层单调"。
这也解释了为什么判据是一条"总量"式的比较：**逐层形状是噪声，终点才是信号。**

### 9.3 这一章的三条边界

**其一：它回答的是"传得到不到"，不是"训得好不好"。**

```text
它回答      "梯度能不能传到最底层"（一个**数值**问题，与前向的损失无关）
它不回答    "这个堆叠能不能训好"——那要看损失曲线、学习率与数据
```

而且 pre 那一列的"梯度变大"**不一定是好事**：它同样可能是"梯度在放大"。
这一条读数只说明**那条路没有被掐断**。

**其二：post-LN 不是"坏的"。** 它是原论文的写法，而原论文用**学习率预热**来对付
它的梯度尺度问题——本课没有把预热放进实验，因此"post 衰减"这一列只说明
"它在没有预热时更难"。

**其三：这份表是一次观测。** 一颗种子、一个初始化幅度、一个深度序列——
要下"pre 一定更好"的结论需要多种子与统计检验（day076 的同一条纪律）。

## 第十章：解码器 —— 多出来的那一个子层

### 10.1 九个阶段

```text
① norm1 → ② 因果自注意力 → ③ ⊕ → ④ norm2 → ⑤ 交叉注意力 → ⑥ ⊕ → ⑦ norm3 → ⑧ 前馈 → ⑨ ⊕
```

三处 `⊕` 就是三条残差路，反向里因此有三处"漏掉不会报错"的加法（`decoder_block_backward`）。

### 10.2 一个副产品：编码器**会**收到梯度

交叉注意力的 `source` 那一路终点是 `grad_encoder_outputs`：

```text
"编码器只被训练一次、解码器只读它"这句话在**反向**里是不成立的
```

演示第 10 节把两路输入梯度都印出来（实测最大相对误差 `1.02e-10`、2/2 通过）。
这一条在工程上有一个具体含义：**冻结编码器时必须显式切断这一路**，
否则它会被解码器的损失悄悄更新——而"冻结"这件事在报告里往往只是一行配置。

### 10.3 一处必须写下来的边界

解码器块的自注意力是**从外面传进来的**（它必须已经是因果的），因此它的输入
不随 `gammas[0]` 变化——这一点与编码器块**刚好相反**（那里由 `block_attention` 保证）。
本课因此对解码器只查**两路输入**的梯度，不查三个 LN 的 γ/β：

```text
解码器块的新东西只有**接线**：三段子层的前向/反向都已被逐项验过（9 项 + 6 项）
```

这也是第一版解码器校验亮红的原因（`9.93e-01` 那一项）——同一个坑的第二次出现，
而它这次的形态是"检查里自己去造注意力、但造错了位置"。

## 第十一章：这一课踩到的三个坑

> 与前四天一样，这一节只记**真的踩过**的坑。

### 11.1 `eps` 不是误差（第 3.2 节）

第一版把"每一行标准化"判成"方差应当为 1"，于是它在 `eps = 1e-5` 时亮红。
修法不是调容差，而是**把定义写进判据**：期望值是 `σ²/(σ²+eps)`。

带走的结论：**判据必须与定义对齐**——否则它训练出来的只是"看到红先怀疑判据"。

### 11.2 注意力不在"被检查的函数"里面（第 5.3 节）

`norm1_gamma` 那一项差 `1e-1`，根因是块没有拥有它的第一个子层。
修法是 `block_attention`——**同一个构造函数**负责"造"与"用"。

带走的结论：**数值侧不能看到的东西，解析侧也不能算进去。**
"把一份算好的中间结果传进来"是一个很自然、也很危险的写法。

### 11.3 同一个坑的第二次出现（第 10.3 节）

解码器校验第一版亮红的是 `decoder_inputs`（`9.93e-01`），而它这次的原因是
"检查里自己去造注意力，但造的位置不对"（没有按 pre-LN 的契约造在 `LN(x)` 上）。

带走的结论：**一个坑修好之后，要在同一个包的每一处都搜一遍它的同族写法。**
这一条与 day078 的"判据要能反向检验"是同一类纪律的两个方向。

## 第十二章：今日总结

| 设计决策 | 背后的原理 | 落地位置 |
|----------|-----------|----------|
| 块的输入输出**同形** | 否则它没法被复制任意份 | `encoder_block` 的保形断言 |
| LN 的 γ/β 是**逐维**的 | 标准化的对象是特征维 | `NormCache` 的长度检查 |
| 统计量取自**行内** | 逐行算子不破坏置换等变性 | `layer_norm` |
| `eps` 记在记录里 | 它是"方差是不是 1"的答案的一部分 | `NormCache.epsilon` |
| ReLU 在 0 处取次梯度 0 | "关掉的神经元梯度恰好是 0"才是一个可读的读数 | `activation_backward` |
| 残差是一个**开关** | 关掉它只改一处代码路径（第 9 章的对照靠它） | `add_residual(use_residual=)` |
| 反向里的两处 `+` | 漏掉不会报错，只会少一条不减值的路 | `encoder_block_backward` |
| 注意力**在块内部**造 | 否则数值侧看不到 γ₁ 的链（坑 11.2） | `block_attention` |
| 九项校验按名单对齐 | 缺项的报告在"全绿"时看起来一样 | `GradientReport` |
| 交叉注意力的权重是**长方形** | 行来自 target、列来自 source | `CrossShape.weights_shape` |
| 跨路掩码是一条**拒绝** | 它在 n_tgt == n_src 时不报错（代价 1.00e+00） | `AssemblyError` |
| 新增失败族 `AssemblyError` | "两个合法部件拼不成整体"与"参数越界"修法不同 | `errors.py` |
| `dEncoder` 被显式给出 | "冻结编码器"必须显式切断这一路 | `DecoderGradients` |
| 深度实验三个变体只差一个开关 | 一次只改一个旋钮 | `depth_study` |
| 本课不加配置项 | 判据留在代码里，diff 才说得清"哪一次换了口径" | 见 6.3 |
