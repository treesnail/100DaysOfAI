## 第二章：两个主题的复盘（本质 → 为什么 → 误区）

每个主题按同一套心智模型复盘。**试着先看小标题自己复述，再展开对照**——
先复述后阅读，是提取练习的正确顺序。

### 2.1 神经网络基础（day089）

- **本质**：一条链，三句话。
  ```text
  一个神经元  z = Σ wᵢxᵢ + b ；a = act(z)          一次点积 + 一个偏置 + 一个非线性
  一层        y = x·Wᵀ + b                        权重 (out, in)，与 nn.Linear 同口径
  一个损失    mse = mean((p − t)²)；ce = −log softmax(z)[k]
  ```
- **为什么**：因为整条链上**唯一**产生非线性的地方是激活函数。这条不是一个比喻——
  它是一次矩阵乘：把恒等激活堆三层，`W = W₃W₂W₁`、`b = W₃W₂b₁ + W₃b₂ + b₃`，
  演示里多层输出与合成单层的最大偏差是 `8.882e-16 <= 1e-12`。
- **误区**：
  ```text
  ① 把值域检查放在含 ±1000 的网格上做严格开区间断言
     —— sigmoid(-1000) 会**饱和**到 0.0，那是定义域代价，不是越界（错报）
  ② 把 softmax 当逐元素激活（它需要一整行；标量版本会静默返回 1.0）
  ③ 初始化用 zeros 就去比较"学得好不好"（它让每个神经元完全相同，对称性不破）
  ④ 把 xavier 的分母为 0 当成"随机崩了"（它是"这一层没有宽度"）
  ⑤ 交叉熵从概率起步（概率下溢成 0 时 −log(0) 没有定义）
  ```

### 2.2 反向传播（day090）

- **本质**：一条规则 + 一条纪律。
  ```text
  规则   dL/dx = (dL/dy) · (dy/dx)          上游梯度 × 局部导数
  纪律   一个值被用了 k 次 ⇒ 它的梯度是 k 条路径之和（一律 +=）
  ```
- **为什么**：因为**纪律那半句写错时程序不会报错**。`y = x·x` 正确梯度是 `2x`；
  用 `=` 代替 `+=` 得到 `x`——形状对、数值有限、训练仍会下降，只是偏小。
  这就是 `ChainError` 独立成族的理由：它要改的是接线，不是公式。
- **误区**：
  ```text
  ① 把"局部导数"当成上游梯度（乘法的局部导数是**另一个乘数的前向值**）
  ② 逐元素反向只传输出（gelu 的导数需要**输入** x·e^{−x²/2} 那一项）
  ③ 把 softmax 当成逐元素激活（它是一整行一起变；形状对、数值错）
  ④ 把 softmax 的雅可比真的建出来（反向只需要 Jᵀv，O(n) 就够）
  ⑤ 认为"交叉熵梯度对了"就说明"softmax 雅可比对了"
     —— 两者相乘之后**中间项全部抵消**，雅可比错了也看不见
  ⑥ 重复 backward 不清零（梯度叠加，"这一步"变成"这两步之和"）
  ⑦ 把 softmax_jacobian 的入参当成 logits（它要的是**概率**；见 5.4）
  ```

## 第三章：一次前向 + 一次反向的全链路走读

以 day090 演示里那张网（`3 → 5 → 2`、32 个参数、隐藏层 relu）为例，走一遍。

### 3.1 前向（day089 的算子）

```text
输入 x (2×3)
  → Dense₁：x·W₁ᵀ + b₁       W₁ (5,3)   → (2×5)    ← 缓存：输入 x、激活前值 z₁
  → relu：逐元素              → (2×5)              ← 缓存：输出 h₁
  → Dense₂：h₁·W₂ᵀ + b₂      W₂ (2,5)   → (2×2)    ← 缓存：输入 h₁
  → （恒等：输出层无激活）
  → mse(ŷ, t) = 0.344065402687
```

### 3.2 反向（day090 的算子）

```text
dL/dŷ = 2(ŷ − t)/N                          ← mse_grad（N = 全部元素个数 = 4）
  → Dense₂ 的反向：dW₂ = dYᵀ·H₁、db₂ = Σ dY、dH₁ = dY·W₂
  → （恒等：直接通过）
  → Dense₁ 的反向的**激活那一半**：dZ₁ = dH₁ ⊙ relu'(Z₁)
                                     ← 逐元素，且**用激活前的 Z₁**（relu 只看符号）
  → Dense₁ 的反向：dW₁ = dZ₁ᵀ·X、db₁ = Σ dZ₁、dX = dZ₁·W₁
```

### 3.3 五个提问点（每一处都能单独答错）

```text
① 为什么要缓存 z₁（激活前值）？       因为 relu 的导数看的是**符号**，gelu 的导数看的是 x 本身
② dH₁ 的求和指标是哪一个？            Σ over 输出维（5）；写成按行收就得到"形状对、数值错"
③ dW₂ 的求和指标是哪一个？            Σ over 样本维（2）⇒ 形状 (2,5)
④ relu 把哪些位置变成 0？             演示里第 0 个神经元两个样本上都关掉 ⇒ dW 整行为 0、db₀ = 0.0
⑤ 为什么两条独立实现能逐位一致？       同一组权重、同样形状约定、同样 fsum、同样激活公式
```

### 3.4 十处接线（前向 ↔ 反向的对应）

```text
前向                    反向                        缓存的哪一样
x·Wᵀ + b          ↔     dW、db、dx                 这一层的**输入**
relu / gelu       ↔     逐元素乘局部导数            激活**前**的值
softmax（逐行）    ↔     逐行 JVP                    激活**后**的值
mse               ↔     2(p−t)/N                    预测与目标
cross_entropy     ↔     p − onehot                  打分
```

一句话：**前向的每一个算子，反向都要问它"局部导数是谁、需要哪一样中间量"**。
这两问就是这一天的全部内容。

### 4.2 三种"求和的指标"（这一层最容易记混的三件事）

```text
一层 dW    Σ over **样本维** i      dW[j][k] = Σᵢ dY[i][j]·X[i][k]      ⇒ (out, in)
一层 db    Σ over **样本维** i      db[j]    = Σᵢ dY[i][j]               ⇒ (out,)
一层 dX    Σ over **输出维** j      dX[i][k] = Σⱼ dY[i][j]·W[j][k]       ⇒ (rows, in)
softmax    Σ over **同一行**   j    (Jᵀv)ᵢ = pᵢ(vᵢ − Σⱼpⱼvⱼ)              ⇒ (n,)
```

### 4.5 "恰好 0"与"接近 0"不是一回事

```text
恰好 0（相等判据，精确判据）        接近 0（上界判据，容差判据）
mse(P, P) = 0.0                    恒等塌缩偏差 <= 1e-12
relu'(0) = 0.0                     逐点导数相对误差 <= 1e-6
关掉的神经元梯度 = 0.0              JVP 恒等式偏差 <= 1e-12
softmax 雅可比每行和 = 0            MLP 参数梯度相对误差 <= 1e-5
```

本课的 `GradientCheck`（day087~090 同源）用一个 `upper_bound` 字段把两类分开：
**有它时判据是"≤"，没有时才是"=="**。把两类混成一个判据，就会出现
"偏差恰好是 0（因为输入全是 0）被当成通过"这种事。

## 第八章：最值钱的三个推导与 day092 的衔接

### 8.1 恒等塌缩（day089）

```text
y = x·W₁ᵀ + b₁ ，z = y·W₂ᵀ + b₂
⇒ z = x·(W₂W₁)ᵀ + (b₁W₂ᵀ + b₂)
⇒ 多层（全恒等）== 一个仿射映射
```

它的价值不在改写，而在**反证**：只要有一层带激活，这条等式立刻失效。
"多层比一层强"的全部来源就是那个非线性。

### 8.2 softmax 的 JVP（day090）

```text
(Jᵀv)ᵢ = Σⱼ pⱼ(δⱼᵢ − pᵢ)vⱼ = pᵢvᵢ − pᵢΣⱼpⱼvⱼ = pᵢ(vᵢ − ⟨p,v⟩)
```

它的价值在**代价**：显式雅可比是 O(n²)，这一式是 O(n)。
把 `v = 1` 代进去还能立刻得到"每一行之和为 0"。

### 8.3 交叉熵的梯度（day090）

```text
∂(−log p_k)/∂z = p − onehot(k)
```

它的价值在一个**盲区**：这条式子不经过 softmax 的雅可比，
因此"雅可比写错"在这里看不见。它解释了为什么必须**单独**验雅可比。
