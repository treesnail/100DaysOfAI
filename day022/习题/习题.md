## 一、选择题（每题只有一个正确答案）

**第 1 题.** 关于 MCP Server 的两种传输方式与容器化的关系，下列说法正确的是：

A. stdio 传输最适合容器化，因为容器天然隔离进程  
B. SSE 传输最适合容器化，因为容器是为独立网络服务设计的，而 stdio 需要 Client 与 Server 共享标准输入输出管道  
C. 两种传输方式容器化难度相同，只是端口配置不同  
D. MCP 协议规定容器部署必须使用 stdio 传输

**第 2 题.** Dockerfile 中下列指令排序，最符合镜像分层缓存原则的是：

A. `COPY . .` → `RUN pip install -r requirements.txt`  
B. `RUN pip install -r requirements.txt` → `COPY requirements.txt ./`  
C. `COPY requirements.txt ./` → `RUN pip install -r requirements.txt` → `COPY smart_research_agent/ ./`  
D. `COPY smart_research_agent/ ./` → `COPY requirements.txt ./` → `RUN pip install -r requirements.txt`

**第 3 题.** 容器内运行的 SSE Server 绑定 `127.0.0.1:8000`，宿主机执行 `docker run -p 8000:8000 ...` 后从宿主机 `curl localhost:8000/health`，最可能的结果是：

A. 正常返回 200，因为端口已映射  
B. 连接超时或被拒绝，因为 127.0.0.1 只接受容器内部回环连接，宿主机转发来的请求对容器而言是外部连接  
C. 返回 404，因为路径未注册  
D. 取决于 Docker 的版本

## 二、判断题（判断对错，并简述理由）

**第 4 题.** 判断：stdio 模式的 MCP Server 在任何场景下都不适合放进容器。

**第 5 题.** 判断：Dockerfile 中 `EXPOSE 8000` 声明之后，宿主机的 8000 端口就能直接访问容器内服务。

## 三、问答题

## 四、编程题

要求：

1. 在 `describe_capabilities()` 返回的 `prompts` 列表中补充对应的 `PromptDescriptor`（`arguments` 至少包含 `{"name": "topic", "required": True}`）。
