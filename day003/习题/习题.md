## 一、单选题

### 第 1 题

A. Agent 是一种参数量更大的 LLM，因此能做的事情更多

C. Agent 是经过强化学习微调后、专门用于调用工具的 LLM
D. LLM 和 Agent 是同义词，只是不同公司的叫法不同

### 第 2 题

A. LLM 根据上文 Thought 自行推测出的工具执行结果

D. 只要设置了 `max_steps`，Agent 就一定能给出正确答案

## 二、判断题

### 第 4 题

判断对错：思维链（Chain-of-Thought）提示法能让 LLM 获取训练数据之外的实时信息（例如今天的天气），因为"一步步思考"提高了模型的能力上限。

### 第 5 题

判断对错：在骨架阶段，把 `ReactAgent.run()` 写成 `return ""`（返回空字符串）与写成 `raise NotImplementedError("...")` 效果等价，因为两者都表示"功能尚未实现"。

## 四、编程题

### 第 8 题

在 day003 源码快照的 `smart_research_agent/agent/react_agent.py` 基础上（**不修改原文件**），请新建一个 Python 脚本完成以下任务：

1. 定义一个 `SimpleLLM` 类，它有一个 `chat(messages: list[str]) -> str` 方法，按预设的回复列表依次返回回复（回复用完后返回固定兜底字符串）。
2. 写一个**迷你版 ReAct 循环**函数 `mini_react(llm, max_steps: int) -> str`：循环最多 `max_steps` 次，每次调用 `llm.chat()`；如果返回值以 `"Final Answer:"` 开头，则返回答案部分并结束循环；否则把该返回值当作 Action 记录到一个轨迹列表中。循环耗尽后返回 `"达到最大步数限制"`。
3. 用以下两组预设回复分别驱动你的循环，打印每组的返回结果和轨迹长度：
   - 组 A：`["Action: 搜索", "Action: 计算", "Final Answer: 答案是 42"]`
   - 组 B：`["Action: 搜索", "Action: 再搜索"]`，`max_steps=3`

要求：不使用任何第三方库；体会"熔断"和"轨迹记录"这两个概念在最简陋代码中的形态。
