# day054 习题：RLHF / DPO 原理 —— 从"该怎么答"到"更偏好哪种答法"

> 对应教程：[../教程/教程.md](../教程/教程.md)
> 建议用时：30~45 分钟。答案在 [../习题答案/习题答案.md](../习题答案/习题答案.md)。

题目分为四类：**速答**（1~6）、**对照**（7~9）、**诊断**（10~13）、**推导与动手**（14~18）。

---

## 一、速答

1. 偏好数据的三个字段 `prompt` / `chosen` / `rejected` 各是什么？为什么说偏好数据
   是"第一种没有唯一正确答案"的数据？

2. 本课把"更偏好哪一种"拆成了哪五个维度？为什么要**把维度写在每一条数据里**，
   而不是标注者心里各自有数？

3. DPO 的 `margin` 由哪四个对数概率算出来？为什么它**不含 β**？

4. 为什么未训练时 DPO 的 loss 恰好等于 `ln 2`？这条"起点检查"能发现哪一类接线错误，
   又为什么**发现不了** 5.2 里那个梯度符号错误？

5. DPO 的"隐式奖励"是什么？由它推出的三个推论里，哪一个解释了"参考模型必须冻结"？

6. KL 的三个估计器 `k1` / `k2` / `k3` 各有什么问题？本课为什么三个都报？

---

## 二、对照

7. 把 RLHF（PPO）与 DPO 的目标并排写出，并说明两者的差别本质上是
   "偏好是怎么进到策略里的"。

8. 本课的 `preference_accuracy` 与 day053 的评估有什么共同点？为什么它**必须用留出数据**？

9. `reward.over_optimization_flags` 与 `strategy.ALIGNMENT_RISKS` 里的"过优化"是什么关系？
   为什么 `DEFAULT_KL_BUDGET` 定义在 `reward` 而不是 `dpo_trainer`？

---

## 三、诊断

10. 某次训练一开始 loss 就是 `0.8`（而不是 `ln 2 ≈ 0.6931`）。请说出**三种**可能原因。

11. 一条偏好样本的 `chosen` 与 `rejected` 规范化后完全相同，但训练照常跑完、loss 也降了。
    请解释：为什么这恰恰是一个"看起来正常"的失败？

12. 有人把 DPO 梯度写成"chosen 的每个位置累加 `(+g)·(softmax − onehot)`"（把符号写反了）。
    请说明：为什么 loss 从 `ln 2` 出发会一路**涨**，而代码没有任何地方报错？

13. 一份偏好数据的 `chosen_longer_fraction = 0.83`。请说明：为什么"直接判定这是长度偏置"
    可能是错的？`length_bias_report` 靠什么来分辨？

## 四、推导与动手

14. 给定 `β = 1`、四个对数概率 `l_c = −2`、`l_r = −3`、`r_c = −2.5`、`r_r = −2`。
    请算出：① `margin`；② `dpo_loss`；③ `dpo_gradient`。

15. 证明：`dpo_loss_from_margin(0, beta)` 对任意 `β > 0` 都等于 `ln 2`。

16. 证明：`sigmoid(x) + sigmoid(-x) = 1`（提示：按 `x ≥ 0` 与 `x < 0` 分情况，
    或直接通分）。

17. 用本包的公开 API 写一段 5 行以内的代码，打印出"一条偏好对的隐式奖励差"
    与"它是否被判对"。

18. 本课把"过优化"做成一个**读数**（`over_optimization_flags`）而不是一条"必须无过优化"
    的性质。请说明：为什么这个现象应该被印出来、而不是被一条性质删掉？并举一个本仓库里
    真实存在的类似例子。
