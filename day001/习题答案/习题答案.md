## 练习 1 答案：新增 `max_retry_count` 配置字段

### 修改 `smart_research_agent/config.py`

```python
class Settings(BaseSettings):
    """应用配置模型."""

    model_config = SettingsConfigDict(
        env_file=".env",
        env_file_encoding="utf-8",
        extra="ignore",
    )

    project_name: str = "智研 AI 助手"
    debug: bool = False
    log_level: str = "INFO"
    openai_api_key: str | None = None
    default_model: str = "gpt-4o-mini"
    max_retry_count: int = 3          # 新增
```

### 修改 `tests/test_config.py`

```python
import os

from smart_research_agent.config import Settings


def test_settings_default_values():
    settings = Settings()
    assert settings.project_name == "智研 AI 助手"
    assert settings.default_model == "gpt-4o-mini"
    assert settings.debug is False
    assert settings.max_retry_count == 3      # 新增断言


def test_settings_env_override(monkeypatch):
    monkeypatch.setenv("MAX_RETRY_COUNT", "5")
    settings = Settings()
    assert settings.max_retry_count == 5
```

> 说明：`monkeypatch.setenv` 会临时设置环境变量，`Settings()` 重新解析时会读到该值。

## 练习 2 答案：日志目录可配置

### 修改 `smart_research_agent/config.py`

```python
class Settings(BaseSettings):
    ...
    log_dir: str = "logs"             # 新增
```

### 修改 `smart_research_agent/utils/logger.py`

```python
from pathlib import Path

from smart_research_agent.config import settings

LOG_DIR = Path(settings.log_dir)      # 从配置读取
LOG_DIR.mkdir(exist_ok=True)
```

### 修改 `.env.example`

```text
# 运行配置
DEBUG=false
LOG_LEVEL=INFO
LOG_DIR=logs
```

### 验证

创建 `.env` 并设置：

```text
LOG_DIR=logs_dev
```

运行入口：

```bash
python -m smart_research_agent.main
```

检查是否生成了 `logs_dev/smart_research_agent.log`。
