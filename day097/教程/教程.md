## 第二章：M7 复盘（本质 → 为什么 → 误区）

每个主题按同一套心智模型复盘。**试着先看小标题自己复述，再展开对照**——
先复述后阅读，是提取练习的正确顺序。

### 2.1 注意力：一次点积（day073 / day075）

- **本质**：一次打分 + 一次加权求和。
  ```text
  scores = Q·Kᵀ / √d_k        （每一次打分是一次点积；除以 √d_k 是尺度归一）
  A      = softmax(scores)     （每一行是一个概率分布 ⇒ 行和为 1）
  out    = A·V                 （用打分当权重，对 V 做加权求和）
  ```
- **为什么**：因为"每一行是一个分布"这条不是比喻——day088 把它写成一条**可断言的命题**
  `attention_rows_are_distributions`，并在 `transformer_core.assert_rows_are_distributions`
  里现场验算。"可微分的检索" `attention_is_differentiable_retrieval` 则是把这条式子
  与 RAG 检索并排看：检索是"硬"的 Top-K，注意力是它的**连续可导版本**。
- **误区**：
  ```text
  ① 把权重行和为 1 当成"模型学到的"（它是 softmax 的定义，不是训练的结果）
  ② 缩放因子写成 √d 而不是 √d_k（d 是整个宽度，多头下每一头只看到 d_k）
  ③ 把打分（logits）当成概率传给下游（day090 第十一章真的踩过，见 4.3）
  ④ 在"一行全零"的输入上调注意力（它会让打分全 0、softmax 给出均匀分布——
     "均匀分布看起来像模型还没学到"，因此 transformer_core 直接拒绝这种输入）
  ```

### 2.2 多头、位置与堆叠（day076 / day078 / day079 / day080）

- **本质**：三句工程动作。
  ```text
  多头   D 维在**投影内部**切成 h 份 ⇒ 每一份 d_k = D/h，各自算一次注意力再拼回
  位置   把"第几个 token"注入表征：正弦/余弦（固定）或可学习（参数）
  堆叠   一层 = 注意力子层 + 前馈子层，各自带残差与 LayerNorm
  ```
- **为什么**：多头`multi_head_splits_inside_projection` 的关键词是"**在投影内部**"——
  不是把输入切成几段各喂一个头，而是**先把整份输入投影成 Q/K/V，再从投影结果里切**。
  切错了不会报错：形状对、数值错。
- **误区**：
  ```text
  ① 把多头当"把输入切段"（正确的是把 Q/K/V 切头）
  ② 以为位置编码可有可无（没有它，注意力对"打乱顺序"完全不变——
     day088 有一条命题 position_encoding_breaks_permutation 专门钉这件事）
  ③ 把 LayerNorm 与 BatchNorm 的轴搞混（LayerNorm 沿**特征**，BatchNorm 沿**批**；
     day095 把这条写成一条可对账的等式，见 3.6）
  ④ 残差与 LayerNorm 的顺序（Pre-LN / Post-LN）随手写（它不改形状，只改训练稳定性）
  ```

### 2.3 训练、变体、可解释（day081 / day082 / day083）

- **本质**：给整摞块装上"可以训"的开关，并看清它学到什么。
  ```text
  day081  Dropout（两个相）、学习率调度（先升后降）、梯度裁剪、早停（带 min_delta）
  day082  Encoder-only（BERT）/ Decoder-only（GPT）/ Encoder-Decoder（T5）三类变体
  day083  注意力热力图：把"模型在看哪里"变成可读的读数
  ```
- **为什么**：day081 的四个旋钮在 day095 被**系统扫了一遍**（消融表），而 day082 的三类
  变体直接决定了上游项目该拿哪一种模型来做什么任务（生成 / 判别 / 转换）。
- **误区**：
  ```text
  ① 早停不带 min_delta（浮点噪声被当成"进展"，早停永不触发——day081 与 day095 各记一次）
  ② 只看训练损失、不看推理损失（dropout 会把训练损失抬高，只看一把尺子会把代价看反）
  ③ 把注意力热力图当"解释"（它是相关性，不是因果——day083 只把"关注区域"做成读数）
  ```

### 2.4 Hugging Face 与推理优化（day085 / day086 / day087 / day088）

- **本质**：从"自己实现"到"读别人的实现"，再到"把推理算成一笔账"。
  ```text
  day085  hf_source       源码精读：split_heads / merge_heads 等实现细节与自己的对上
  day086  hf_integration  进程内跑 HF 模型：InProcessModel / text_generation / feature_extraction
  day087  inference_optim KV Cache（复用是逐位精确）/ 量化（误差被半步长界住）/ 批处理计划
  day088  principle_map   四层 12 条命题 → 实现 → 六个应用，整张图可校验
  ```
- **为什么**：day087 的两个读数是这一阶段的工程核心——
  `cache_reuse_is_bitwise_exact`（缓存复用与"重算"逐位相同）与
  `quantization_error_bounded_by_half_step`（量化误差不超过半个步长）。
  它们把"推理加速"从"感觉快了"变成**两条可断言的命题**。
- **误区**：
  ```text
  ① 把 KV Cache 当成"变快"的魔法（它换来的是显存，cache_bytes 是一个公式）
  ② 量化只报"精度掉了多少"（正确做法是报误差的**上界**：半个步长）
  ③ 把原理图当口号（day088 的纪律：每条命题必须指得到一个能 import 的函数，
     artifact 指不到的箭头是装饰）
  ```

## 第三章：M8 复盘（本质 → 为什么 → 误区）

### 3.1 神经网络基础（day089）

- **本质**：一条链，三句话。
  ```text
  一个神经元  z = Σ wᵢxᵢ + b ；a = act(z)          一次点积 + 一个偏置 + 一个非线性
  一层        y = x·Wᵀ + b                        权重 (out, in)，与 nn.Linear 同口径
  一个损失    mse = mean((p − t)²)；ce = −log softmax(z)[k]
  ```
- **为什么**：让"多层"区别于"一层"的**唯一**来源是激活函数。把恒等激活堆三层，
  `W = W₃W₂W₁`，多层输出与合成单层的最大偏差是 `8.882e-16 <= 1e-12`——这是"深度本身
  不产生非线性"的一次可复现读数（在第 4 章的对照表里）。
- **误区**：
  ```text
  ① 用含 ±1000 的网格做 sigmoid ∈ (0,1) 的严格断言（饱和被误报成越界）
  ② 把 softmax 当逐元素激活（它需要一整行；标量版本会静默返回 1.0）
  ③ 初始化用 zeros 去比"学得好不好"（它让每个神经元完全相同，对称性不破）
  ④ 交叉熵从概率起步（概率下溢成 0 时 −log(0) 没有定义）
  ```

### 3.2 反向传播（day090）

- **本质**：一条规则 + 一条纪律。
  ```text
  规则   dL/dx = (dL/dy) · (dy/dx)          上游梯度 × 局部导数
  纪律   一个值被用了 k 次 ⇒ 它的梯度是 k 条路径之和（一律 +=）
  ```
- **为什么**：因为**纪律那半句写错时程序不会报错**。`y = x·x` 正确梯度是 `2x`；
  用 `=` 代替 `+=` 得到 `x`——形状对、数值有限、训练仍会下降，只是偏小。
  这就是 `ChainError` 独立成族的理由：它要改的是接线，不是公式。
- **误区**：
  ```text
  ① 把"局部导数"当成上游梯度（乘法的局部导数是**另一个乘数的前向值**）
  ② gelu 的反向只传输出（导数里有 x·e^{−x²/2}，输出里没有 x）
  ③ 把 softmax 当逐元素激活（一整行一起变；形状对、数值错）
  ④ 认为"交叉熵梯度对了 ⇒ 雅可比对了"（中间项被抵消，雅可比错了看不见）
  ⑤ 把打分当概率传给 softmax_jacobian（**连报错都没有**，读数只剩"每行和 = 1.5e1"）
  ⑥ 用"损失在下降"证明"梯度是对的"（一个整体偏小的梯度同样给出一条下降曲线）
  ```

### 3.3 优化器（day092）

- **本质**：一步 = 学习率 × 更新规则，而且四个动作的顺序是写死的。
  ```text
  取 lr（调度在优化器内部） → 裁剪（整体范数） → 更新规则 → 衰减（耦合在规则前 / 解耦在规则后）
  ```
- **为什么**：因为"衰减在裁剪之前""解耦当梯度用"这两种顺序错**都不会报错**，
  只会让那个系数不再等于你设的值。耦合 L2 与解耦在一步之后只差第二位小数
  （`0.850000` 对 `0.855000`），但它们是两个不同的东西。
- **误区**：
  ```text
  ① 把 Nesterov 写成普通动量（两条轨迹都"看起来正常"⇒ 所以要一条**下界**判据，
     读数 3.226e-01 >= 1.0e-06）
  ② 把动量与学习率混着调（动量第一步与 sgd 完全相同，作用从**第二步**才开始）
  ③ 认为 AdamW = Adam + L2（解耦衰减不随梯度尺度变化——这是选 AdamW 的全部理由）
  ④ 早停不带 min_delta（见 3.1 的 day081 纪律）
  ```

### 3.4 卷积（day093）

- **本质**：同一组权重，用在每一个位置。
  ```text
  参数量 = C_out·(C_in·k_h·k_w) + C_out     与图的大小无关
  out    = ⌊(H + 2p − d·(k−1) − 1)/s⌋ + 1
  感受野  r₀ = 1；r ← r + (k − 1)·∏s
  ```
- **为什么**：两层 3×3 与一层 5×5 的感受野相同（都是 5），而参数从 25 降到 18，
  中间还多了一次非线性——这是"用小核堆深"的两个直接理由。
  6×6 的图直连 18 维全连接头要 666 个权重，一层 `conv(1→2, k=3)` 只要 20 个。
- **误区**：
  ```text
  ① 把 d_kernel 与 d_image 写反（形状仍然完全正确，数值全错 ⇒ 只有数值差分能发现，
     读数 1.579e-10 <= 1.0e-09）
  ② 认为"卷积"要翻转核（深度学习里实际是**互相关**，核不翻转：PyTorch 也是互相关）
  ③ 用偶数核 + "same" 填充（没有解 ⇒ WindowError；same 还要求步长 1）
  ④ 池化窗口盖不满输入时"丢掉最后一块"（实际下采样率与以为的不同，下游尺寸全错位）
  ```

### 3.5 RNN / LSTM（day094）

- **本质**：同一组权重，用在每一个时刻。
  ```text
  rnn    params = H·(D + H + 1)         与序列长度 T **完全无关**（T=1/3/8 都是 12）
  lstm   params = 4·H·(D + H + 1)       那个 4 = 四个门各一套权重
  c_t = f ⊙ c_{t−1} + i ⊙ g            记忆通道（**加法**通道）
  ∂c_T/∂c_0 = ∏ f_t                     梯度沿它走**只乘 f**，几乎不衰减
  ```
- **为什么**：因为 `dW` 必须**累加**——三步都回传 `‖dW‖ = 3.014188`，
  只留最后一步只剩 `1.503321`（49.9%）。它不报错，只让梯度整体偏小，
  看起来像"学习率设小了"。
- **误区**：
  ```text
  ① 把 h₀ 算进输出（得到 T+1 个状态，下游 zip 静默截断 ⇒ "第 t 个状态"与
     "第 t 个输入"整体错位一格，而它不会报错）
  ② BPTT 只留最后一步 dW（见上）
  ③ 漏掉 "dc += dh ⊙ o ⊙ (1 − tanh(c_t)²)" 这条链（梯度仍有限、仍在下降，
     只有数值差分能发现少了一项）
  ④ 把 W_h 乘反（dx = W_xᵀ·dz 写成 W_x·dz；H == D 时形状仍合法）
  ```

### 3.6 训练技巧与正则化（day095）

- **本质**：给一条能跑的链装上四个旋钮，并第一次把"两相"做成可断言的事。
  ```text
  BatchNorm  固定一个特征，在**批**上算 μ/σ   （N 条样本 → 1 对统计量）
  LayerNorm  固定一条样本，在**特征**上算 μ/σ （day079 的实现，本课**调用**它对账）
  训练相     用这一批的 μ/σ   ；推理相  用 running（**必须由调用方给出**，否则 PhaseError）
  训练相反向 三项（μ/σ 也依赖 x）；推理相反向 只剩一项
  ```
- **为什么**：`batch_norm_forward(X) == transpose(layer_norm(transpose(X)))` 在这条纪律下
  **逐位成立**（读数 `0.000e+00 <= 1.0e-12`）——两条公式只是同一条在两条轴上的写法。
  而"两相必须不同"用一条**下界**判据（读数 `1.678e+00 >= 5.0e-01`）钉死。
- **误区**：
  ```text
  ① 把 BatchNorm 插在"单条样本"上（批大小为 1 ⇒ 方差恒为 0 ⇒ 输出被压成常数 β；
     三条不同配置给出**同一个损失**，而数值差分当时仍然全绿）
  ② 推理相也用本批统计量（两相写成一相，只有下界判据与推理相反向那一条会红）
  ③ 方差用无偏（除以 N−1）而不是有偏（除以 N）（与 PyTorch / day079 口径不一致）
  ④ 只报训练损失（dropout 的代价被看反——本课两把尺子一起报）
  ```

### 3.7 PyTorch 高级与综合实践（day096）

- **本质**：把"训练"也变成一条可复算的管线，只有七段。
  ```text
  dataset → sampler → dataloader → device → train → checkpoint → inference
  ```
- **为什么**：因为**恢复训练必须逐位相等**——"第 3 轮落盘后恢复训到第 6 轮"与
  "一口气训到第 6 轮"，114 个参数的最大绝对差是 `0.0`。它不是"差不多"，而是
  同样的 (数据序, 学习率, 优化器状态) 必须给出同样的结果。这条断言跨了四个模块。
- **误区**：
  ```text
  ① 恢复时忘了装回优化器跨步状态（损失更**低**，看起来"恢复得很好"）
  ② 恢复后重新 Sampler(seed)（数据顺序变了，程序无法察觉）
  ③ 把 dropped 公式照抄成 n − b × 批数（保留尾批时给出"负 2 条样本"这种不可能的数）
  ④ 把"放不下显存"做成异常（它该由 fits 暴露——"装不下"是一个可被上层处理的决策输入）
  ⑤ 检查点哈希覆盖了指标与历史（"我补写了一行日志"变成"权重变了"的假警报）
  ```

## 第四章：三条贯穿线的复盘

### 4.1 主线一：一次点积 → 一次反向 → 一条训练管线

```text
一次点积（M7）        一次反向（M8-D1/D2）      一条训练管线（M8-D3 ~ D7）
   注意力打分           上游梯度 × 局部导数        七个阶段 + 四个轴
   ↑ 依赖 day073         ↑ 依赖 day074 的尺子       ↑ 依赖 day092 的优化器
   Q·Kᵀ/√d_k             dL/dx = Σ 各路径之和        dataset…inference
```

同一件事在三个阶段有同一个"影子"：

| 阶段 | 那个反复出现的量 | 它在哪里第一次被写成可断言的结论 |
|------|------------------|----------------------------------|
| 一次点积 | 行和为 1 的分布 | day088 `attention_rows_are_distributions` |
| 一次反向 | 累加（+=） | day090 `ffn_backward` 与生产实现逐位 0 个 |
| 一条管线 | 逐位相等（== 0） | day096 `resume_matches_uninterrupted` 读数 0.0 |

### 4.2 主线二：判据体系的演进

判据从两类长到三类，再在 day096 被用满。**判据类型不是装饰——它决定"哪一类错误能被反驳"。**

```text
M7（day087 / day088）  两类：相等（==）与不超过上界（<=）
   day088 的 CrossCheck 带一个 upper_bound 字段：**有它时判据是"≤"，没有时才是"=="**
   （这就是两条性质不能合成一条判据的全部理由）
M8 前段（day089 ~ day091）  沿用两类
day092 引入第三类：**下界**（>=）
   理由：这一课有一半内容在说"两个规则不是一回事"——只写上界判据时，
   "把 Nesterov 写成普通动量""把解耦写成耦合"都会让报告**全绿**
day093 是 M8 里唯一没有下界判据的一天（它没有"两个东西必须不同"的断言）
day094 / day095 各有一条下界；day096 有一条下界 + 一条上界 + 五条相等
```

M8 七天"七条性质"的判据分布（全部来自每天的 `verify` 现场读数）：

| 天 | 主题 | 相等 | 上界 | 下界 |
|----|------|------|------|------|
| day092 | 优化器 | 3 | 2 | 2 |
| day093 | 卷积 | 4 | 3 | 0 |
| day094 | RNN / LSTM | 4 | 2 | 1 |
| day095 | 训练技巧与正则化 | 4 | 2 | 1 |
| day096 | PyTorch 高级与综合实践 | 5 | 1 | 1 |

读法：**下界那一列是"不能少的断言"的计数。** day092 需要两条（Nesterov ≠ 动量、
解耦 ≠ 耦合），day093 一条都不需要，到 day096 收敛成一条——但正是那一条
（并集覆盖 `>= 1.0`）钉住了"一条样本都不能漏"。

而 day096 的"相等"这一类里还有一个细节：**七条性质里有五条读数是 `== 0`**
（差异项数、批数差、逐位往返、恢复、批推理与逐条），
一条上界（设备字节相对差 `<= 1e-09`），一条下界（分片覆盖 `>= 1.0`）。

### 4.3 主线三：失败族的演进史

失败族的分法从 day073 起就只有一条：**按"谁的错、该谁去修"分**，而不是按"哪一行抛的"。

```text
day075  transformer_core.errors    核心三族：ShapeError / ParameterError / NumericError
                                   （外加专门的一族 GradientError，以及 TransformerError 基类）
day089  neural_basics              前向与损失：GradientError 连续缺席（第八天）
day090  backprop                   八族；GradientError **第一次被真的抛出**
day092  optimizers                 五族（新增 StateError / StepError）；GradientError 缺席
day093  conv_net                   五族（新增 WindowError / BackwardError）；GradientError 第三次缺席
day094  sequence_models            六族（新增 TimeStepError）；GradientError **第二次回来**
day095  regularization             四族（**新增 PhaseError**）；GradientError 再次缺席
day096  torch_pipeline             五族（**新增 DeviceError 与 CheckpointError**）；GradientError 缺席
```

`GradientError` 的"在场 / 缺席"是**可断言的常量**（`RETURNED_FAMILY` / `ABSENT_FAMILY`），
而它在 M8 里每一种理由都不重复：

```text
day090  RETURNED_FAMILY = "GradientError"，ABSENT_FAMILY = None
        理由：解析梯度与数值差分对不上 ⇒ "这次训练从头到尾都不可信"，必须当场停下
day092  ABSENT_FAMILY   = "GradientError"
        理由：消费梯度、不计算梯度（梯度是上一步交来的输入）
day093  ABSENT_FAMILY   = "GradientError"
        理由：算了梯度，但对账是**离线校验**，结论进性质表，不改变控制流
day094  RETURNED_FAMILY = "GradientError"，ABSENT_FAMILY = None
        理由：算了梯度，而且梯度真的会爆 ⇒ **运行期守卫**（这一步就不该继续）
day095  ABSENT_FAMILY   = "GradientError"
        理由：守卫**已经装好了**（day094 装的），本课只是调用它
day096  RETURNED_FAMILY = "CheckpointError"，ABSENT_FAMILY = "GradientError"
        理由：今天成为一等公民的是检查点族（五件套缺一件、哈希对不上），梯度守卫照旧只是被调用
```

**"缺席要可断言"的意义在这里**：一个"今天没有这一族"的结论，如果不写成常量，
就无法与"我忘了加"区分开。同一族在八天里在场或不在场八次，
每一次的理由都写进了各课 `errors.py` 的 `RETURNED_FAMILY_REASON` / `ABSENT_FAMILY_REASON`
并被对应的测试逐字断言。

## 第五章：原理 → 应用（把底层结论接回主线项目）

这一章回答 curriculum 的第二条目标：**串联底层原理与 SmartResearch Agent 上层应用**。
下表的每一行都是"一句底层结论 → 它在项目里的用法"，落点全部是 day096 快照里真实存在的包。

| 上层能力（包） | 用到了哪一个底层结论 | 底层结论 → 上层用法 |
|----------------|----------------------|---------------------|
| RAG 与 Embedding：`rag_ops` / `retrieval` / `vectorstore` | 相似度是**方向**：余弦是归一化点积，与向量长度无关，零向量记 0.0（day088 命题 `cosine_is_normalized_dot`、`embedding_similarity_is_direction`） | 向量化后按**方向**排序取 Top-K（`retrieval` 的检索器），而不是按模长——长度是"说了多少"，方向才是"像不像" |
| 索引与分块：`chunking` / `indexing` | 打分与排序同构：检索打分与注意力打分都是"归一化点积 + 排序"（`rank_ordering_matches_attention_peaks`） | 分块决定"比较的粒度"，索引决定"比较的规模"；同一句"按峰值排序"既解释注意力峰值，也解释检索排名 |
| Agent 的推理底座：`multi_head` / `transformer_core` | 注意力是"可微分的检索"、每一行是分布；多头把投影**在内部切成子空间**（`attention_is_differentiable_retrieval`、`multi_head_splits_inside_projection`） | 上游 LLM 的推理能力就是这条式子堆出来的：Agent 的"读上下文"与 RAG 的"取文档"是同一件事的连续版与离散版 |
| 微调与对齐：`alignment` / `dpo` / `finetune` / `peft` / `sft` | 偏好对 (chosen, rejected) 可以直接优化，不需要单独的奖励模型；参数高效微调只学一小份新参数（SFT / LoRA / DPO） | 输出风格与安全性的对齐：用领域偏好数据直接调策略，而不必先训一个奖励模型再上 RL |
| 评估：`evaluation` / `finetune_eval` | **没有绑定信息的分数不是证据**——同一批数字换了数据集就不可比（内容指纹回答"这两个分数能比吗"） | 微调前后、RAG 改动前后的对比报告必须绑定同一套数据与指标，否则"涨了 2 个点"是一句无证据的话 |
| 服务化与流水线：`api` / `serving` / `mlops` | 显存与预算是**算术**：参数 + 激活 + 优化器状态（Adam 约 3× 参数）；放不下由 `fits` 暴露而不是崩溃 | 部署前的资源规划与"降 batch / 换精度 / 分片"的决策顺序，先算账再上线 |
| 推理与数据管线：`torch_pipeline` / `inference_optim` | KV Cache 复用**逐位精确**、缓存字节是公式；恢复训练**逐位相等**（数据序 + 优化器状态 + 从 k+1 继续） | 推理缓存换来显存、换来吞吐；训练检查点换来"可恢复"——两者都是"用状态换成本"的同一笔账 |

一句话收口：**M7 给了"模型能表达什么"，M8 给了"模型怎么学会、怎么跑起来"；
而第五章这张表说明，两者的每一个底层结论在上层都有一个具体的落点。**

## 第七章：误区清单（带证据位置）

```text
① 把多头理解成"把输入切段" —— 正确做法是把 Q/K/V **在投影内部**切头（day088 命题）
② 以为位置编码可有可无 —— 没有它会打乱顺序不变（day088 第 2 章）
③ 把 LayerNorm 与 BatchNorm 的轴搞混 —— 一个是特征轴、一个是批轴（day095 第 2 章）
④ 把 KV Cache 当"变快的魔法" —— 它换来显存，cache_bytes 是一个公式（day087）
⑤ 认为"损失在下降"就证明"梯度对" —— 整体偏小的梯度同样下降（day090 第 10 章）
⑥ 把 softmax 当逐元素激活 —— 一整行一起变，形状对、数值错（day090 第 7 章）
⑦ 把打分当概率传给 softmax_jacobian —— 连报错都没有，每行和只剩 1.5e1（day090 第 11 章）
⑧ 用 = 代替 += 做梯度累加 —— 梯度偏小，看起来像"学习率设小了"（day090 第 2 章）
⑨ 把 Nesterov 写成普通动量 —— 两条轨迹都"看起来正常"，要靠下界判据钉（day092 第 4 章）
⑩ 恢复训练忘了装回优化器状态 —— 损失更**低**，是"结果更好看"的假象（day096 第 7 章）
⑪ 把 BatchNorm 用在批大小为 1 的输入上 —— 方差恒为 0，整层被压成常数（day095 第 3 章）
⑫ 把"放不下显存"做成崩溃 —— 它该由 fits 暴露，是一个可处理的决策输入（day096 第 5 章）
⑬ 认为"卷积"要翻转核 —— 深度学习里是互相关，PyTorch 也是（day093 第 3 章）
⑭ 把 h₀ 算进 RNN 输出 —— 得到 T+1 个状态，下游静默错位一格（day094 第 4 章）
```

## 第九章：最值钱的三个推导与走向结业项目

### 9.1 softmax 的 JVP（day090）

```text
(Jᵀv)ᵢ = Σⱼ pⱼ(δⱼᵢ − pᵢ)vⱼ = pᵢvᵢ − pᵢΣⱼpⱼvⱼ = pᵢ(vᵢ − ⟨p,v⟩)
```

它的价值在**代价**：显式雅可比是 O(n²)，这一式是 O(n)。
把 `v = 1` 代进去还能立刻得到"每一行之和为 0"（读数 `8.327e-17`）。

### 9.2 恒等塌缩（day089）

```text
y = x·W₁ᵀ + b₁ ，z = y·W₂ᵀ + b₂
⇒ z = x·(W₂W₁)ᵀ + (b₁W₂ᵀ + b₂)
⇒ 多层（全恒等）== 一个仿射映射
```

它的价值不在改写，而在**反证**：只要有一层带激活，这条等式立刻失效。
"多层比一层强"的全部来源就是那个非线性——而反向里"关掉的神经元不学习"靠的也是它。

### 9.3 恢复训练逐位相等（day096）

```text
恢复 = 载入 params + 装回优化器跨步状态 + 从 epoch k+1 继续（order(k+1) 逐位相同）
```

它的价值在一个**失败模式**：三件事缺任何一件，损失都会**更低**或"看起来差不多"，
而不是崩溃。因此恢复必须用相等判据（`== 0`），而不是"损失差不多"。

### 9.4 走向结业项目（day099 / day100）

```text
day090  能算、能验      前向 + 反向 + 三条独立路径对账
day092  往哪走、走多远  优化器把梯度变成一次更新
day093/094  两种权重共享  空间（卷积）与时间（循环）
day095  四个旋钮        归一化 / 随机丢 / 调度 / 早停
day096  七个阶段        数据 → 设备 → 检查点 → 推理的工程管线
day097  今天要做的      把 M7 与 M8 串成一张地图，并接回主线项目的上层能力
day099  结业项目        把 Agent / MCP / RAG / 微调 / 评估 / API 联调成一个可运行的系统
```

### 三个悬念

今天最值得带走的一句话，与 M7 / M8 开头那两句对着看：

```text
M7  注意力 = 一次打分的点积 + 一次加权的求和；多头、位置、残差与堆叠都是在这一行两边做工程
M8  反向传播 = 上游梯度 × 局部导数，然后累加——前半句是链式法则、后半句是纪律；
    而一条训练管线 = 把数据、设备、状态、读数都变成可复算的算术
day097  这两句话是同一件事的两端：**M7 决定"能不能表达"，M8 决定"能不能学会、能不能复现"**；
        把它们接起来的，是那个在前向提供非线性、在反向充当开关的激活函数
```

而这一阶段的判据，也正好是那三张对账表：

```text
相等  0.000e+00（恢复训练逐位、手写反向 vs 自动微分、BN = 转置 LayerNorm）
上界  1.579e-10 <= 1e-09（卷积反向）、2.222e-10 <= 1e-09（BPTT）、0.000e+00 <= 1e-09（设备字节）
下界  1.000e+00 >= 1.0（分片覆盖）、1.678e+00 >= 5e-01（两相不同）、3.226e-01 >= 1e-06（Nesterov ≠ 动量）
```

**三类判据同时能被读出数、并且都能被反驳，才叫"这一阶段的东西真的串起来了"。**
