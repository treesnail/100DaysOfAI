## 一、一页速答

**1.**
```text
z = Σᵢ wᵢxᵢ + b          一次点积 + 一个偏置
a = act(z)               一个非线性
参数量 = inputs + 1      （权重 + 偏置）
```
三件事里"非线性"那件是唯一的：拿掉它，多层会塌缩成一层。

**2.**
```text
relu        d/dx = 1 if x > 0 else 0        只需要**输入的符号**
leaky_relu  d/dx = 1 if x > 0 else 0.01     只需要**输入的符号**
sigmoid     d/dx = σ(x)(1 − σ(x))           **只需要前向输出**（σ 就是输出）
tanh        d/dx = 1 − tanh²(x)             **只需要前向输出**
gelu        d/dx = 0.5(1+erf(x/√2)) + x·e^{−x²/2}/√(2π)   **需要输入**
```
只有 `sigmoid` 与 `tanh` 能"只用输出"；`gelu` 是唯一必须拿到输入的那个——
它的导数第二项里有 `x·e^{−x²/2}`，而输出里没有 `x`。

**3.**
```text
J[i][j] = p_i(δ_ij − p_j)        每一行之和恰为 0
```
（`Σⱼpᵢ(δᵢⱼ − pⱼ) = pᵢ(1 − Σⱼpⱼ) = pᵢ·0`；演示读数 `8.327e-17`。）

**4.**
```text
(Jᵀv)ᵢ = pᵢ(vᵢ − ⟨p,v⟩)
```
中间量从 `n²`（显式 n×n 雅可比）降到 `n`（一次内积 + 一次逐元素乘）。

**5.**
```text
∂(−log p_k)/∂z = p − onehot(k)
```
它把 **softmax 的雅可比**消掉了：两者相乘之后中间项全部抵消。
因此"雅可比写错"在这条梯度上看不见——这正是必须单独验雅可比的理由。

**6.**
```text
dW[j][k] = Σᵢ dY[i][j]·X[i][k]      求和指标是**样本维** i     ⇒ 形状 (out, in)
db[j]    = Σᵢ dY[i][j]              求和指标是**样本维** i     ⇒ 形状 (out,)
dX[i][k] = Σⱼ dY[i][j]·W[j][k]      求和指标是**输出维** j     ⇒ 形状 (rows, in)
```

**7.**
```text
inputs           每一层的**输入**       → Dense 的反向（dW = dYᵀ·X 要乘 X）
pre_activations  激活**前**的值          → 逐元素激活的反向（gelu' 里有 x·e^{−x²/2}）
outputs          激活**后**的值          → softmax 的反向（softmax 的输出就是它自己的概率）
```

**8.**
```text
规则   上游梯度 × 局部导数（链式法则）
纪律   累加（+=）：一个值被用了 k 次，梯度是 k 条路径之和
```

**9.**
```text
A 手写反向        能发现：无（它就是要被验的那一份）
B 图自动微分      能发现 A 的公式抄错；**不能**发现"约定整体错了"（与 A 共享约定）
C 数值差分        能发现约定错误；但慢（2n 次求值）、只到 1e-9、不可导点无定义
```

**10.** 因为"一次对不上的梯度意味着**这次训练从头到尾都不可信**"。
如果它只是报告里的一行"分歧 1"，调用方可以选择读完之后继续跑——
而继续跑的结果是一个"损失确实在下降"的模型，它可能正在往错误的方向走。
day073 的 `math_foundations` 把梯度对照记成**报告**（它不改变控制流）；
day075 分出 `GradientError` 那一族是为了让调用方**当场停下**；
而直到 day090（第一次同时有两条独立路径）这一族才第一次被真的抛出。

**11.**


## 五、推导题

**17.（推导）恒等塌缩**

```text
y = x·W₁ᵀ + b₁        （W₁ 形状 (m, k)，x 是行向量、长度 k，y 长度 m）
z = y·W₂ᵀ + b₂        （W₂ 形状 (n, m)，z 长度 n）

代入：
z = (x·W₁ᵀ + b₁)·W₂ᵀ + b₂
  = x·W₁ᵀW₂ᵀ + b₁W₂ᵀ + b₂
  = x·(W₂W₁)ᵀ + (b₁W₂ᵀ + b₂)          ← 用 (AB)ᵀ = BᵀAᵀ

因此 W = W₂·W₁（形状 (n, k)）、b = b₁·W₂ᵀ + b₂（长度 n）。∎
```

```text
（甲）这条推导讲的是**前向**：它说明"没有非线性时，深度不增加表达力"。
      而反向讲的是"能不能学"：梯度能不能从输出一路传回输入，
      取决于**每个算子的导数**。把两天放在一起讲，是因为两条线只有一个交点——
      那个激活函数：在前向它提供非线性（于是深度有意义），
      在反向它是唯一的"开关"（relu 的导数在负半轴恰好是 0，
      于是"关掉的神经元"不参与更新）。同一处决定了表达力与可学性。
（乙）插一个 relu 之后 y = relu(x·W₁ᵀ + b₁) 不再能写成 x·W'ᵀ + b' 的形式——
      失效点在"把 relu 打开括号"的那一步（非线性算子不满足可加性/齐次性）。
      本课对此有一条**正向实现**的反面证据：只要有一层带激活，
      collapse_identity_mlp 就抛 ParameterError。
（丙）day090 的第 6 条性质 mlp_backward_matches_numerical：
      读数是"32 个偏导数、最大相对误差 5.813e-11（容差 1e-5）"，
      并且它的证据行里同时印着"chain_forward vs day089 mlp_forward 逐位不一致 0 个"——
      即"前向一致"与"反向一致"被写在了同一条结论里。
```

**18.（推导）softmax 雅可比与交叉熵梯度的"抵消"**

```text
设 p = softmax(z)，即 pᵢ = e^{zᵢ} / Σₖ e^{zₖ}
要证  ∂(−log p_k)/∂zⱼ = pⱼ − δ_{jk}

第一步：∂p_k/∂zⱼ = p_k(δ_{kj} − p_j)          （softmax 的雅可比）
第二步：∂(−log p_k)/∂zⱼ = −(1/p_k)·∂p_k/∂zⱼ
                        = −(1/p_k)·p_k(δ_{kj} − p_j)
                        = −(δ_{kj} − p_j)
                        = p_j − δ_{kj}
而 δ_{kj} = δ_{jk}，故结论成立。∎
```

```text
（甲）结论 `p − onehot(k)` 里**没有出现 J**（第二步里 p_k 与 (1/p_k) 直接约掉了）。
      这意味着：softmax 的**单独**雅可比写错时，这条梯度的读数**不会变**——
      因为在计算这条梯度时并没有用到那张矩阵。
（乙）能通过。他会算出一条完全正确的 `p − onehot(k)`（如果他按这条化简式实现），
      或者即使他实现了雅可比、只要最后化简了，结果也一样。
      因此"交叉熵的梯度与数值差分一致"**不能**证明他的雅可比是对的。
（丙）所以必须把雅可比**单独**验一次：day090 的第 3 条性质
      （softmax_jacobian_matches_numerical）拿本包的解析雅可比与 day074 的
      **数值雅可比**逐点比（3 行、26 个元素，最大相对误差 3.681e-11），
      并同时读 day074 那份独立实现的结论（agrees）。
      这条性质与第 5 条（交叉熵梯度）测的**不是同一件事**，
      而只有前者能发现雅可比的错误——这就是"必须多验一遍"的严格含义。
```
