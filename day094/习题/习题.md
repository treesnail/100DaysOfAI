# day094 习题：循环神经网络 RNN / LSTM —— 同一组权重，用在每一个时刻

> 共 18 题：8 速答 + 1 连线 + 3 对照计算 + 2 诊断 + 2 推导 + 2 情景题。
> 建议先合上教程与源码自己作答，再对 [习题答案](../习题答案/习题答案.md)。
> 涉及数字的题目请写出计算过程。

## 一、速答（8 题）

1. 循环网络相对全连接的"全部秘密"是哪一句话？它直接带来了参数量上的什么性质？

2. 同样是权重共享，卷积与循环有一个根本差别。请说出这个差别，以及它对"能不能并行"的影响。

3. 参数量公式 `H·(D + H + 1)` 与 `4H·(D + H + 1)` 里，哪一个因子来自"四个门"？偏置项是哪一个？

4. `rnn_forward` 返回的状态数应该是多少？如果把初值 `h₀` 也算进输出会得到几个状态，
   而后果是什么（为什么"不会报错"）？

5. 为什么遗忘门偏置被初始化成 1 而不是 0？请用 `σ(0)` 与 `σ(1)` 的具体数说明它对记忆的影响。

6. `∂c_T/∂c_0` 等于什么？为什么这条通道被称为"梯度高速公路"？

7. BPTT 里 `dW` 用的是 `+=` 还是 `=`？写成另一个的后果是什么（为什么"不会报错"）？

8. `GradientError` 在 day094 是"回来了"还是"缺席"？它这一次被抛出的理由与 day090 那一次
   有什么不同？

## 二、连线（1 题）

9. 把算子 / 函数与它的职责连起来：

```text
名称                   职责
matvec                 a. 把 4H 的打分切成 i / f / o / g 四块
matvec_transpose       b. W·x（行是输出、列是输入）
outer                  c. 把回传梯度投影回输入空间（反向的一半）
gate_blocks            d. g ⊗ x，dW 的每一时刻那一片
check_gradient_norm    e. 进入优化器之前看一次梯度范数，越界就抛 GradientError
rnn_carry_norm         f. 量"信号从末步回到起点还剩多少"
```

请写出对应表，并指出哪两个函数是一对"转置"——把它们写反时会有什么症状。

## 三、对照计算（3 题）

10. 给定 `D=2, H=3`，请分别算出 RNN 与 LSTM 的参数量（写出代入的值），
    并回答：序列长度 `T` 从 1 变成 8 时，这两个数会不会变？

11. 一个 LSTM 单元，`H=1`，权重全部为 0，四个偏置分别是 `b_i = −40`、`b_f = +40`、
    `b_o = +40`、`b_g = 0`，初值 `c₀ = 0.75`。请逐步算出第 1 步的：
    - `i`、`f`、`o`、`g` 各是多少
    - `c₁` 是多少
    - `h₁` 是多少（并解释为什么它恰好等于 `tanh(c₁)`）

12. 第 ⑦ 条性质的两侧：
    - RNN 侧：`W_h = 0.5`、其余为 0、`h₀ = 1`、`T = 8`，
      请推导 `‖∂h_T/∂h_0‖` 的**上界**（写出每个因子的界）
    - LSTM 侧：`f = 1`、`T = 8`，`∂c_T/∂c_0` 等于多少？
    最后说明为什么这条性质必须是"下界"判据。

## 四、诊断（2 题）

13. **现象**：训练在跑、损失在降，但降得比自己预期慢很多；形状检查全部通过，
    梯度里也没有 `nan`。你把每个时刻的梯度打印出来，发现只有**最后一步**那一份。
    最可能的原因是什么？本课的哪一条测试 / 哪一条性质会（或不会）发现它？

14. **现象**：`rnn_forward` 返回了 `T+1` 个状态，而输入有 `T` 步。下游代码没有报错，
    只是 loss 一直停在 0.69 附近。
    请说出两件事：这个错位具体把哪两个量对错了？本课的哪一族错误 / 哪一条性质是为它准备的？

## 五、推导（2 题）

15. 推导：为什么把 `W_h` 置零之后，`∂L/∂c_0` 恰好等于 `∏_{t} f_t`（逐分量）。
    请从 `c_t = f⊙c_{t−1} + i⊙g` 与 `h_t = o⊙tanh(c_t)` 两条式子出发，
    说明"隐状态那条链"被切断之后还剩哪几项。

16. 推导：tanh-RNN 的长程衰减。已知
    `∂h_t/∂h_{t−1} = diag(act'(z_t))·W_h` 且 `|tanh'| ≤ 1`。
    请证明 `‖∂h_T/∂h_0‖ ≤ ‖W_h‖ᵀ`（用"矩阵范数的次乘法性"一句话即可），
    并算出 `‖W_h‖ = 0.5`、`T = 8` 时的上界数值。
