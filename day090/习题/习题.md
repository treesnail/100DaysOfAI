## 一、选择题（7 题）

**1.** 反向传播的"规则"与"纪律"分别是：

- A. 规则是"梯度必须累加"，纪律是"上游梯度 × 局部导数"
- B. **规则是"上游梯度 × 局部导数"，纪律是"累加（`+=`）"**
- C. 两条都是"累加"
- D. 规则是"先算损失再求导"，纪律是"用数值差分校验"

**2.** 把 `y = x·x` 的反向写成 `x.grad = dZ * x`（而不是 `x.grad += dZ * x`），后果是：

- A. 抛 `ChainError`
- B. 形状不对，抛 `ShapeError`
- C. **不报错，只给出一个偏小的梯度（在 `x = 3` 处得到 3 而不是 6）**
- D. 梯度符号反了，训练会发散

**3.** `gelu` 的反向需要**激活前的值**（`pre_activation`），而 `sigmoid` / `tanh` 只需要输出。
原因是：

- A. `gelu` 不是逐元素激活
- B. `gelu` 的导数里有 `x·e^{−x²/2}` 这一项，**输出 `y` 里没有 `x` 这个信息**
- C. `gelu` 的值域不是开区间
- D. `gelu` 在前向里用了 `erf`，因此反向必须重算一遍

**4.** `relu` 在 `x = 0` 处的导数取 0（次梯度），这条约定带来的一条**可断言**的结论是：

- A. 所有梯度都不会超过 1
- B. **关掉的神经元（激活前值 ≤ 0）在反向里梯度恰好是 0**
- C. `relu` 的输出一定非负
- D. 一层里不会出现全零的 `dW` 行

**5.** `softmax` 的雅可比 `J[i][j] = p_i(δ_ij − p_j)` 有一行和为 0 的性质，因为：

- A. 雅可比是对称矩阵
- B. **Σ_j p_i(δ_ij − p_j) = p_i(1 − Σ_j p_j) = p_i·0**
- C. 每个元素都是 `p_i(1 − p_i)`
- D. softmax 的输出之和为 1，与雅可比无关

**6.** `∂(−log p_k)/∂z = p − onehot(k)` 这条式子最值得注意的地方是：

- A. 它需要一个 n×n 的雅可比
- B. **它把 softmax 的雅可比消掉了，因此"雅可比写错"在交叉熵的梯度上看不见**
- C. 它只在 `k = 0` 时成立
- D. 它必须从概率起步，不能从 logits 起步

**7.** 本课"三条独立路径对账"里的三条路径是：

- A. 手写反向 / 数值差分 / 二阶差分
- B. **手写反向 / 图自动微分 / 数值差分**
- C. 手写反向 / PyTorch / 数值差分
- D. 解析梯度 / 符号微分 / 数值差分

```python

# 这份实现：grad_weight[j][k] = Σ_i X[i][j]·dY[i][k]   （即 Xᵀ·dY）

    tuple(
        math.fsum(input_row[j] * grad_row[k] for input_row, grad_row in zip(inputs, grad_output))
        for k in range(out_features)
    )
    for j in range(in_features)

```

## 四、推导题（3 题）

**16.**（推导）softmax 的 JVP 恒等式。
设 `p = softmax(z) ∈ Rⁿ`（`Σ_i p_i = 1`）、`J[i][j] = p_i(δ_ij − p_j)`，`v ∈ Rⁿ` 任意。
请证明：

```text
(Jᵀv)_i = p_i(v_i − ⟨p, v⟩)
```

并说明：这个变形把中间量从多少个降到多少个（用 n 表示）；
以及"`J` 每一行之和为 0"这条性质，从你写下的最后一步里能不能直接看出来。

请分别推导 `∂L/∂W`、`∂L/∂b`、`∂L/∂X`（用 `dY`、`X`、`W` 表示），
并**数一数**每一步里"求和的指标是哪一个"。
最后说明：如果把 `∂L/∂X` 写成"按 `W` 的行收"，形状为什么仍然对。
