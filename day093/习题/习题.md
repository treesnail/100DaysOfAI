# day093 习题：卷积神经网络 CNN —— 同一组权重，用在每一个位置

> 共 18 题：8 速答 + 1 连线 + 3 对照计算 + 2 诊断 + 2 推导 + 2 情景题。
> 建议先合上教程与源码自己作答，再对 [习题答案](../习题答案/习题答案.md)。
> 涉及数字的题目请写出计算过程。

## 一、速答（8 题）

1. 卷积相对全连接的"全部秘密"是哪一句话？它直接带来了参数量上的什么变化？

2. `conv2d` 在本包里是**互相关**还是**数学卷积**？请说出这个约定与 PyTorch 的关系。

3. `same` 填充在什么条件下才精确成立？为什么"偶数核 + 步长 1"没有解？

4. 为什么池化要求窗口**整除地**盖满输入，而不是"丢掉最后一块"？后者的危险在哪？

5. 多通道卷积里的"通道维加权求和"可以用哪一个已经学过的操作来理解？

6. 卷积反向的三块梯度 `dK` / `dB` / `dX` 各自的形状是什么（与什么同形）？

7. `d_kernel` 与 `d_image` 互为"转置"。如果把它们写反，形状会错吗？谁会先发现？

8. `GradientError` 在 day093 第三次缺席，理由是什么？它与 day090 的"必须当场停下"有何不同？

## 二、连线（1 题）

9. 把算子与它的职责连起来：

```text
算子                 职责
output_size          a. 把 valid / same / 整数解析成具体补边数
resolve_padding      b. 只接受整数补边，算一次尺寸公式
feature_size         c. 单通道互相关
pad2d                d. 逐层递推感受野（r ← r + (k−1)·∏s）
conv2d               e. 解析填充之后再套尺寸公式（调用方不用自己解析）
receptive_field      f. 对称常量补零
```

请写出"算子 → 职责"的对应表，并指出哪两个函数是"解析"与"计算"的分工。

## 三、对照计算（3 题）

    - `s=1, p=1, d=1`

    最大值 +0.389712。请解释**为什么通道 0 会整张全零**，并说明"多通道"的意义。

12. 感受野：请分别算出下面两种方案的感受野与参数量（单输入单输出通道、不含偏置），
    并回答"哪个更划算"：

    - 一层 5×5 卷积

## 四、诊断（2 题）

    你传的是 `padding="same"`。最可能的原因是什么？本课是怎么修的（哪一个函数）？

## 五、推导（2 题）

    请说明每一项的来源，并算 `C_in=3, C_out=8, k=3` 时的参数量。

    并用"逐层区间传播"再算一遍，确认两条路径给出同一个数。
