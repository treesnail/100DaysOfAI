## 第一部分：选择题

### 第 1 题（Git 对象模型）

在 Git 中，当你执行 `git checkout -b feature-x` 创建新分支时，Git 实际做了什么？

- A. 复制整个项目目录到一个新的隐藏文件夹
- B. 创建一个新的 commit 对象标记分支起点
- C. 创建一个指向当前 commit 的指针文件，并移动 HEAD
- D. 把工作区所有文件打包成 blob 存入对象库

### 第 2 题（Docker 分层缓存）

以下 Dockerfile 片段中，哪一种写法能最大化利用构建缓存？

- A. `COPY . .` 然后 `RUN pip install -r requirements.txt`
- B. `COPY requirements.txt ./` 然后 `RUN pip install -r requirements.txt`，再 `COPY` 源码
- C. `RUN pip install pydantic` 放在所有 COPY 之前
- D. 每条 COPY 和 RUN 交替写，不分顺序

### 第 3 题（覆盖率）

某函数的行覆盖率为 100%，分支覆盖率为 60%，这说明：

- A. 测试一定充分，可以放心重构
- B. 所有代码行都被执行过，但有部分 if/else 分支未被测试
- C. 有 40% 的代码行没被执行
- D. 函数返回值有 40% 概率是错的

## 第四部分：编程题

### 第 9 题（编写测试）

在 `tests/` 下新建 `test_main.py`，为 `smart_research_agent/main.py` 的 `main()` 函数写单元测试。

要求：

1. 使用 `caplog` fixture 捕获日志输出；
2. 断言 `main()` 执行后日志中包含项目名"智研 AI 助手"；
3. 断言 `main()` 的返回值是 `None`。

提示：`caplog.set_level("INFO")` 可以设置捕获级别；`caplog.text` 包含所有捕获到的日志文本。

### 第 10 题（改造脚本）

当前 `scripts/push.sh` 无条件推送 `main` 分支。请改造它，使其满足：

1. 自动推送**当前所在分支**，而不是写死 `main`；
2. 推送前检查工作区是否有未提交的改动，如果有则提示用户先提交；
3. 保持幂等性和失败即停原则。
