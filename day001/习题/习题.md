## 练习 1：为配置模型新增字段

在 `smart_research_agent/config.py` 的 `Settings` 类中新增一个配置项：

```python
max_retry_count: int = 3
```

要求：

1. 字段类型为 `int`，默认值为 `3`。
2. 可以通过 `.env` 文件覆盖，例如 `MAX_RETRY_COUNT=5`。
3. 在 `tests/test_config.py` 中补充一条测试，验证默认值和 `.env` 覆盖值都能正确解析。

## 练习 2：让日志目录可配置

当前 `smart_research_agent/utils/logger.py` 中的 `LOG_DIR` 是硬编码的 `Path("logs")`。

请改造为：

1. 在 `Settings` 中新增 `log_dir: str = "logs"`。
2. `logger.py` 中读取 `settings.log_dir` 作为日志目录。
3. `.env.example` 中加入 `LOG_DIR=logs` 示例。
4. 验证切换 `.env` 中的 `LOG_DIR` 后，日志输出到新目录。

## 练习 3：跑通代码规范流水线

1. 确保虚拟环境已激活，开发依赖已安装：
   ```bash
   pip install -e ".[dev]"
   pre-commit install
   ```
2. 运行 pre-commit 检查：
   ```bash
   pre-commit run --all-files
   ```
3. 如果有报错，根据提示修复，直到全部通过。
4. 运行测试并查看覆盖率：
   ```bash
   pytest tests/ -v
   ```
