# day100 课后习题

> 主题：结业项目整合（二）—— 把一次能跑的运行交付成四份能被复算的产物
> 前置：day099（九段链 + 12 个候选子包的清单）
> 建议：先不看 `习题答案/习题答案.md`；诊断与推导题请在纸上把读数算出来再对答案。

题量：18 题 = 10 速答 + 1 连线 + 3 对照 + 2 诊断 + 2 推导。

---

## 一、速答（10 题）

**1.** `graduation` 包把"交付"拆成哪四份产物？每份各回答一个什么问题？

**2.** `DemoTranscript.comparable()` 里**包含**哪四样东西，**不含**哪几样？为什么"不含"这一列才是要点？

**3.** 运行摘要（`capstone` 的 `SystemRun.digest`）与剧本摘要（`DemoTranscript.digest`）覆盖的字段有何不同？为什么今天不复用运行摘要？

**4.** `inventory.discover_subpackages()` 在无 `__all__` 的子包上如何数"公开名字"？为什么不用 `vars()` 数？

**5.** `InventoryReport` 的 `__post_init__` 做了一条什么闭合检查？它能抓到哪两类错误？

**6.** 课程总结的八个计数里，哪几个是"数出来 / 折出来"的、哪一个是"声明"？

**7.** 能力自评的量程有哪四档？每一档对应的一条证据分别是什么？

**8.** `CapabilityScore.__post_init__` 的第二条闭合检查是什么？它拒掉了哪一类"看起来正常"的分数？

**9.** 后续规划的缺口有哪两种？各自来自哪一次真实读数？

**10.** 七条性质里哪一条是**下界**、哪一条是**上界**？为什么这两条不能写成相等判据？

## 二、连线（1 题）

把左列的模块与右列的职责连起来（每项只连一次）。

```text
左列（模块）        右列（职责）
types.py            用 pkgutil + importlib 数遍全部一级子包
inventory.py        剧本生成 + 重放（两次逐位比）
demo.py             从真实缺口推出规划（缺口集合 == 规划项集合）
assessment.py       4 份交付物 / 4 级量程 / 7 条性质 / 10 条笔记 / 5 条边界
roadmap.py          8 项能力逐项评级：证据 → 量程
summary.py          把清单折成一份可核对的课程总结
verify.py           七条性质与三类判据（相等 / 上界 / 下界）
study.py            五张表（交付物 / 清单 / 自评 / 规划 / 性质）
```

## 四、诊断（2 题）

**17.** 某同学给 `assessment.level_for` 传了这样一组参数：

```python
assessment.level_for(owners_present=2, owners_total=2, symbols=5, stage_ok=True)
```

他期望得到 `LEVEL_DELIVERED`（3），但函数返回 `LEVEL_BUILT`（1）。
请指出他错在哪，并说明为什么**必须**返回 1 而不是 3。

**18.** 某同学写的剧本重放报告里出现了这样一行：

```text
重放：第一次摘要 3f1a... / 第二次摘要 9c2b... | 逐位相同=False | 差异 3 项
```

他检查了三遍"剧本内容没改"，仍然不一致。请给出**最可能的**三处病因，
并说明为什么 `DemoTranscript.comparable()` 这个口径本身能帮他定位。

## 五、推导（2 题）

且 `SYMBOL_FLOOR = 8`。承担子包与它们的公开名字数如下：

```text
security 8   agent 11   retrieval 124   evaluation 20
observability 8   tools 5   llm 12   vectorstore 95
```

```text

context_packing     retrieval
grounded_generation retrieval + llm
offline_evaluation  evaluation
cost_and_tracing    observability + llm
tool_execution      tools
```

（最高评级 / 已交付项数 / 最少证据条数）分别等于多少。
