## 一、差分与误差阶数（第 1 ~ 5 题）

**1.**（手算）对 `f(x) = x³` 在 `x = 2` 处，用 `h = 1e-3`：

- 前向差分 `(f(2+h) − f(2))/h = ?`（给到 6 位小数）
- 后向差分 `(f(2) − f(2−h))/h = ?`
- 真值 `f'(2) = ?` 两者的误差各是多少？

**2.**（推导）写出中心差分 `(f(x+h) − f(x−h))/(2h)` 的两条泰勒展开，
并说明"`h f''(x)` 那一项被减掉"这个说法具体是怎么发生的。

**3.**（概念）为什么"误差阶数"只在**截断误差主导区**有意义？
如果用 `h = 1e-12` 与 `h = 1e-14` 两条读数去算阶数，会得到大约多少？为什么那个数字没有意义？

**4.**（动手）跑一遍 `step_size_study(exp, 1.0, math.e)`：

- 前向、中心差分的**实测阶数**分别是多少？
- 中心差分的误差在哪一步触底？最大误差出现在哪一步？
- 最后两列（`误差/h` 与 `误差/h²`）在哪些行是常数？为什么它们在那里应当是常数？

**5.**（设计）二阶差分 `(f(x+h) − 2f(x) + f(x−h))/h²` 需要什么形状的失败？
也就是说，为什么本课的测试在它上面**显式传了 `step=1e-4`**，而不是用缺省的 `1e-6`？
（提示：分母是 `h²`。）

## 二、梯度与方向导数（第 6 ~ 10 题）

**6.**（手算）`f(x, y) = 3x² + y² + xy`，在 `(0.7, −0.4)` 处：

- `∂f/∂x = ?` `∂f/∂y = ?`
- `‖∇f‖ = ?`
- 沿 `(1, 1)` 的方向导数（单位方向）是多少？

**7.**（概念）`directional_derivative` 会把方向**归一化**。如果不归一化，
"沿 `(2, 0)` 的方向导数"= 沿 `(1, 0)` 的方向导数的多少倍？为什么这会让"方向导数"失去意义？

**8.**（推导）用柯西–施瓦茨不等式说明：在所有**单位**方向里，`D_u f` 的最大值等于 `‖∇f‖`，
且在 `u = ∇f/‖∇f‖` 处取到。

**9.**（动手）跑演示脚本第 3 节：

- 沿 `(1, 0)`、`(0, 1)`、`(1, 1)`、`∇f` 四个方向的方向导数各是多少？
- 扫 36 个固定方向取最大值，为什么它**严格小于** `‖∇f‖`？差值是什么的量级？

**10.**（概念）`gradient` 对 `n` 维输入要做多少次函数求值（中心差分）？
这个数字解释了"为什么生产里不用数值梯度，只在验证时用"——请把它与 day064 的向量检索规模联系起来。

## 三、链式法则与反向传播（第 11 ~ 17 题）

**11.**（手算）`d/dx sin(exp(2x))` 在 `x = 0` 处等于多少？请用"局部导数之积"写出三段。

**12.**（概念）链式法则里最容易写错的一件事是"在哪个点取值"。请以
`f = x²`、`g = x + 1`、复合为 `g(f(x))` 为例说明：
`2(x+1)` 与 `2x+1` 哪个对？错的写法在 `x = 3` 处会给出多少（正确值是 8）？

**13.**（手算）对 `y = x·x`、`x = 3`：

- 计算图上有几个节点？分别是什么运算？
- `x` 的梯度是多少？请说明"两条边各贡献一份 3"里的"两份"分别来自哪里。

**14.**（设计）本课把梯度累积写成 `+=` 而不是 `=`。如果写成 `=`：

- `x·x` 在 `x = 3` 处的梯度会变成多少？
- 这个错误在训练里看起来像什么？为什么它比"抛异常"更难查？

**15.**（概念）`backward()` 里的 `propagate` 接收的是**本节点的梯度**。
如果误写成读左操作数的 `self.grad`：

- 在什么形状的图上会**恰好给出正确结果**？
- 为什么"恰好正确"比"直接错"更危险？

**16.**（动手）为什么 `topological_order` 要用**迭代**而不是递归实现？
请估算：一条 2000 层的加法链在递归实现下会发生什么？
（提示：Python 缺省递归上限是 1000。）

**17.**（设计）`zero_grad()` 存在的必要性是什么？
"第二次 `backward()` 会把梯度叠上去"这个行为，在日志里看起来像什么？

## 四、优化器（第 18 ~ 24 题）

**18.**（手算）SGD：`θ = (1, 2)`、`g = (0.5, −0.25)`、`lr = 0.1`，一步之后 `θ = ?`

**19.**（手算）动量法（**累加型**）：`β = 0.9`、`lr = 0.1`、梯度恒为 `1`，起点 `0`。

- `v₁ = ?`、`v₂ = ?`
- 前两步的位移分别是多少？
- 如果把 `β` 改成 `0.99`，`v` 的稳态幅度（`g/(1−β)`）会变成多少？这一步对"等效学习率"的影响是什么？

**20.**（概念）本课的动量是"累加型"（`v ← βv + g`），而另一种常见写法是 EMA 型
（`v ← βv + (1−β)g`）。两者能互相换算吗？换算的方式是什么？
"混着用"会造成什么后果，而它在日志里看起来像什么？

**21.**（手算）Adam：`lr = 0.1`、`β₁ = 0.9`、`β₂ = 0.999`、`g = 1`。

- `m₁`、`v₁`（未修正）分别是多少？
- 两个修正因子 `1 − β₁¹`、`1 − β₂¹` 是多少？
- 修正之后第一步的位移是多少？如果不做修正会是多少（给到小数点后两位）？

**22.**（推导）梯度恒定（恒为 `g`）时，证明 `m̂/√v̂ = sign(g)`，从而每步位移都是 `lr`。

**23.**（动手）跑演示脚本第 8 节：

- 碗形地形上三种优化器的最终损失各是多少？谁最低？
- 峡谷地形上谁最低？
- 用一句话说清"哪个优化器更好"这个问题为什么离开地形就没有意义。

**24.**（设计）`global_norm` 与 `clip_by_value` 都会改变梯度。
请给出一个输入，使得前者**不改变方向**、后者**改变方向**，并说明各自适合什么场景。

## 五、学习率调度（第 25 ~ 29 题）

**25.**（手算）`step_decay(base_lr = 0.1, drop_every = 3, gamma = 0.5)`：
`t = 1, 3, 4, 6, 7, 9` 时的学习率分别是多少？

**26.**（手算）`cosine(base_lr = 0.1, total_steps = 5, min_lr = 0)`：
`t = 1, 2, 3, 4, 5` 时的学习率分别是多少？（提示：`cos(0)=1`、`cos(π/4)=0.7071`、`cos(π/2)=0`）

**27.**（设计）`cosine_schedule` 的分母用 `T − 1` 而不是 `T`。
请说明用 `T` 时第 `T` 步的学习率是多少（以 `base = 0.1`、`T = 10` 为例），
并解释为什么这种偏差"不会被任何人注意到"。

**28.**（设计）`warmup_cosine` 的第 1 步是 `base_lr/warmup`，而**不是** 0。
如果写成 0，日志里会出现什么现象？它会被误读成什么？

**29.**（概念）本课把"常数调度"叫作**基线**而不是"旧方案"。
请说明：如果没有常数调度作为对照，`warmup_cosine` 的实验结果能说明什么、不能说明什么？

## 六、梯度对照与工程（第 30 ~ 34 题）

**30.**（概念）`gradcheck` 只有 `agrees` 与 `differs` 两种结论，
而 `bridge` 有三种（多了 `rejected`）。请说明 `rejected` 在 `bridge` 里指什么，
以及为什么它在 `gradcheck` 里**不可能出现**。

**31.**（手算）对打分 `z = (1, 2)`：

- `softmax(z) = ?`（给到 6 位小数）
- 完整雅可比 `∂p_i/∂z_j` 的四个元素分别是多少（用 `p_i(δ_ij − p_j)`）？
- 验证每一行之和是否为 0。

**32.**（推导）已知 `L = −log p_y`，请用链式法则证明
`∂L/∂z_j = p_j − onehot(y)_j`（提示：`∂L/∂p_y = −1/p_y`，再用第 31 题的雅可比）。
并回答：为什么"雅可比写错"时这个结论**看起来仍然正确**？

**33.**（设计）`GRADIENT_TOLERANCE = 1e-8` 这个数字是怎么定出来的？
请写出分辨率公式 `eps·|f|/(2h)`，并算出 `|f| = 30`、`h = 1e-6` 时的值。
如果容差取 `1e-12` 会发生什么？

**34.**（写作）本课**没有**给 `config.py` 加配置项（容差、步长、学习率曲线都是函数参数）。
请评价这个取舍：什么情况下它反而不合适？
（与 day073 第 32 题是同一个问题——但请结合"步长"这个新参数重新回答一次。）
