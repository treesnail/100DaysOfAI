# day101 课后习题

> 主题：把 100 天的材料编成一份可检索、可复算的索引
> 前置：day099（九段链）、day100（四份交付物）
> 建议：先不看 `习题答案/习题答案.md`；诊断与推导题请在纸上把 token 与分数算出来再对答案。

题量：18 题 = 10 速答 + 1 连线 + 3 对照 + 2 诊断 + 2 推导。

---

## 一、速答（10 题）

**1.** 本课的语料有哪两种？各自从哪里来（各有多少份）？

**2.** 为什么文档名必须带种类前缀（`doc:backprop` / `subpackage:backprop`）？不带会发生什么？

**3.** 为什么本课**不引入分词库**？二元组分词的代价是什么？

**4.** `tokenize("反向传播")` 与 `tokenize("好")` 分别返回什么？依据是哪两条规则？

**5.** 为什么分词用**一个**交替正则，而不是"先扫 ASCII、再扫中文"？

**6.** `InvertedIndex.__post_init__` 里那条"文档名必须排序"的护栏，挡住了哪一类失败？

**7.** 检索的两条排序规则是什么？第二条为什么必须存在？

**8.** `Hit` 里为什么同时要有 `score` 与 `matched`？少了 `matched` 会怎样？

**9.** "空查询"与"查了没命中"在本课里分别怎么处理？为什么它们必须分开？

**10.** 七条性质里哪两条是**下界**、哪一条是**上界**？把下界写成相等会在什么时候误报失败？

---

## 二、连线（1 题）

把左列的模块与右列的职责连起来（每项只连一次）。

```text
左列（模块）        右列（职责）
errors.py           分词（ASCII 词 + 中文二元组）+ 倒排索引 + 复算摘要
types.py            从 docs/*.md 与子包 docstring 收一份语料
corpus.py           一次确定性检索：score = 命中词数 / 查询词数
index.py            7 条性质与三类判据（相等 / 上界 / 下界）
query.py            2 种语料 / 1 套分词口径 / 7 条性质 / 10 条笔记 / 5 条边界
verify.py           6 个失败族（回来的 TokenError + 继续缺席的 GradientError）
study.py            四张表（语料 / 索引 / 检索 / 性质）
```

## 三、对照（3 题）

**13.** 对照下面两句话，说明"可复算"为什么比"检索质量好"更像本课的判据：

```text
A: "同一份语料两次编出同一份索引、同一查询两次给出同一份命中"
B: "排在最前面的那一条通常是对的"
```

**14.** 对照本课的两个"拒绝"（`CorpusError` 里的重名、`IndexBuildError` 里的未排序），
说明它们各自挡住的是"输入的问题"还是"工序的问题"。

**15.** 对照 day100 的四份交付物与今天的四张表，说明"产物"与"读数"在这两天里各自扮演什么角色。

## 四、诊断（2 题）

**16.** 某同学把 `docs/` 下的一份手册改名为 `backprop2.md`，但忘了改子包名。
他跑了一遍，语料里出现了两条名字都以 `backprop` 开头、却都不是他要找的那一份。
请指出他这一步**真正**改坏了什么，以及本课的哪一条检查会当场变红。

**17.** 某同学写了一个自制的分词器（按空格切），跑出一份"看起来能用"的索引：
查询 `"反向传播"` 返回 0 条命中。请给出**最可能的**原因，并说明本课的哪一条性质
会让这个问题在"跑起来之前"就被发现。

## 五、推导（2 题）

**19.** 已知分词规则如下（`MIN_WORD_LEN = 2`，`NGRAM = 2`）：

```text
ASCII 词    [A-Za-z0-9_]+  小写化，长度 >= 2
中文串      长度 >= 2 时切成全部相邻二元组；长度 1 的整段作为一个 token
token 顺序  按正文顺序（一个交替正则扫一遍）
```

请写出下面两段正文的 `tokenize` 结果与 `token_count`：

```text
① "向量 维度 不一致"
② "Course_Index a 反向"
```

**20.** 一次检索里，查询被切成 2 个词：`反向` 与 `梯度`。三份材料的倒排情况是：

```text
doc:a  含 {反向, 传播, 梯度}
doc:b  含 {反向}
doc:c  含 {梯度}
```

请写出：

```text
① 三份材料各自的分数（写出算式）
② 排序后的名单（写清并列时谁在前，依据是哪条规则）
③ 第 ⑤ 条性质 scores_within_bounds 的读数
```
