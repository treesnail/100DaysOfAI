## 一、选择题（7 题）

**1.** 关于 KV 缓存，正确的说法是：

- A. 它让前向**变精确**（少算一次就少一次误差）
- B. 它把每步的计算量从 O(T) 降到 O(1)，代价是 O(T) 的显存
- C. 它把 K/V 存成 hidden state，用的时候再投影一次
- D. 它只在训练时有用

**2.** 缓存的字节数公式是：

- A. `L · T · h · bytes`
- B. `2 · L · T · h · bytes`
- C. `2 · T · h · bytes`（与层数无关）
- D. `L · T · h · bytes / 2`

**3.** 用缓存的 decode 与整段重算必须：

- A. 数值相近即可（允许 1e-6 的差）
- B. **逐位**相同（`==`，不是容差）
- C. 只在第一层相同
- D. 只有在 `T=1` 时相同

**4.** decode 一步只喂一个 token 时，**位置**应该：

- A. 永远是 0（因为这一行只有一个 token）
- B. 由**缓存长度**决定（第 t 步的位置是 t）
- C. 由 batch 大小决定
- D. 由隐藏维决定

**5.** 关于量化误差的上界 `scale/2`，正确的说法是：

- A. 它是一条经验规律，实测常常超过它
- B. 它是从"取整误差 ≤ 0.5 格"推出的；它依赖"每个元素都落在量程内"与 `scale ≠ 0` 两条前提
- C. 它只对 int4 成立
- D. 它与位数无关

**6.** 同一个位数下，把粒度从 `per_tensor` 换成 `per_channel`：

- A. 一定能把误差降到原来的 1/16
- B. 在**行与行的动态范围差得很大**时明显减小误差，而在每行分布相同时几乎不减小
- C. 只影响显存，不影响误差
- D. 只在 int4 下有效

**7.** 关于"连续批的总步数 = 最长的那条请求"：

- A. 恒成立
- B. 只在**请求条数 ≤ 批大小（槽位够用）**时成立；否则实际步数更长
- C. 只在批大小为 1 时成立
- D. 只在长度全都相同时成立

## 四、推导题（3 题）

**16.**（推导）缓存的收益与代价。
设序列长度为 `T`、层数为 `L`、隐藏维为 `h`、每元素 `b` 字节。
（a）写出"不缓存"与"缓存"两种做法下**打分次数**（`q·k`）的表达式，并证明后者是前者的 `2/(T+1)` 倍。
（b）写出"不缓存"与"缓存"两种做法下**投影次数**的表达式（每步每层投影几行），并说明两者相差多少倍。
（c）写出缓存的**显存**代价（用 `L, T, h, b` 表示），并说明为什么"缓存一定更好"在显存紧时不成立。

**17.**（推导）对称量化的误差上界。
设一块元素的最大绝对值为 `A`、位宽为 `b`，对称量化的格距为 `s = A / (2^{b-1} − 1)`，
量化值 `q = round(x / s)`、反量化 `x̂ = q · s`。
（a）证明对任意 `x ∈ [−A, A]` 有 `|x − x̂| ≤ s/2`。
（b）说明当输入里出现 `inf` 时这条证明在哪一步失效。
（c）若 `A = 0`（整块同值），`s` 等于多少、`x̂` 等于多少，为什么本包选择**拒绝**而不是照做。

**18.**（推导）预算内最长能做多长。
设权重占 `W` 字节、预算为 `B`、批大小为 `n`、前馈中间维为 `f`、每元素 `b` 字节。
缓存与激活都**线性**于序列长度 `T`。
（a）写出总量 `total(T)` 的表达式。
（b）证明 `T_max = ⌊(B − W) / (n·f·b + 2·L·h·b)⌋` 满足 `total(T_max) ≤ B < total(T_max + 1)`。
（c）说明为什么"只查 `T_max` 放得下"不足以验证这个最大值（给出一个反例）。
