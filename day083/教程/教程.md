## 第二章：两条读法

### 2.1 模型真实的权重 vs 多头读法

```text
self_records    模型**真实**看到的权重（头数 1）
                直接取自 day082 的 block_weights / decoder_self_weights / cross_weights
head_records    **同一组投影**在多头划分下的读法（用 day076 的 multi_head_attention 重算）
```

两者有四处差别，而每一处都会让"混着比"变成一件错事：

```text
① 缩放不同      单头 1/√d_k；多头 1/√(d_k/heads)  ⇒ 打分尺度差 √heads 倍（day076 的 scale_ratio）
② 作用位置不同   head_records 作用在**某一层的输入**上（单头路径重放到那一层）
③ 块类型不同     day079 的 encoder_block / decoder_block 要求 day075 的 AttentionForward，
                 而多头那份是 MultiHeadForward ⇒ **两处不能直接拼**
④ 唯一的接缝     head_records(heads=1) 必须**逐位**等于 self_records
```

第 ③ 条是本课发现的**接口事实**，值得写下来：day085 会看到 Hugging Face 的
`T5Attention` 同时支持 `n_heads` 与因果掩码——那是因为它把"分头"放在**投影内部**
（`view(...).transpose(...)`），而不是换一个块类型。

### 2.2 第 ④ 条接缝抓到了本课的第一个 bug

第一次运行它的时候，结果是：

```text
heads = 1 在第 0 层逐位相等、在第 2 层**不相等**
```

这说明 `head_records` 读的**不是**第 2 层的输入，而是"把模型输入直接喂给第 2 层"。
第一版的写法是：

```python
normed, _cache = layer_norm(inputs, gamma=..., beta=...)     # ← inputs 是**模型**的输入
forward = multi_head_attention(attentions[layer], normed, heads=heads)
```

它为什么看起来完全正确？因为形状对（LN 保形）、行随机、熵与天花板都算得出来、
热力图也画得出来——**所有读数都合理，只是它们属于另一个问题**。
修法是一行：

```python
current = _stream_input_at_layer(checked, checked_inputs, layer, source=source,
                                 placement=resolved_placement)
```

`_stream_input_at_layer` 按 day082 的**单头**路径重放到那一层，
因此 `heads = 1` 与模型真实权重逐位相同（第 9 章会把这件事写成一条纪律）。

### 3.1 为什么是文本，而不是一张图

```text
③ 它零依赖        不需要 matplotlib，任何终端都能看
```

### 3.2 10 级与图例（演示脚本第二节）

```text
  层 0 · 头 0 | 4×4 | 流 self | 熵 0.7905（天花板 0.7945，归一化 0.9950）
         0   1   2   3
    0 |@   | 峰值 1.0000 @ 0 （第 0 行）
    1 |==  | 峰值 0.5206 @ 0 （第 1 行）
    2 |-:- | 峰值 0.3747 @ 0 （第 2 行）
    3 |.:::| 峰值 0.2930 @ 1 （第 3 行）
  等级（10 级，从 0 到 1）：' .:-=+*#%@'（第 0 级是空格）
```

这张图里有三件事值得指出：

```text
第 0 行只有一格（@）      因果掩码：它只能看到自己 —— **掩码的形状直接画出来了**
同一行里的空格            那是"第 0 级"：权重恰好为 0（被掩码挡住）或 < 1/9
图例印在每一段输出里      读者要能自己判断那个字符代表多少
```

第 2 条的细节值得再走一步：`h@` 与空格的区别不只是"大小"，而是
**"被挡住"与"很小"**。它们在这张图上看起来一样（都是空白），
因此本课另有一条判据专门把两者分开（第 8 章第 2 条性质：掩码外必须逐位为 0）。

### 3.3 等级是**有损**的，因此要能对回去

```text
第 k 级的区间是 [k/9, (k+1)/9)，level_of 用**向下取整**
渲染 → 解析 ⇒ 必须**逐级**相同（不是"看起来差不多"）
```

```python
assert render.parse_heatmap(render.heatmap_block(record)) == render.normalized_levels(record)
```

它挡住的是"把 1 与 0 画得一样"这类实现错误——那种错误**只会让人看着图得出错的结论**：

```text
坏写法    cell = "#" if value > 0.5 else " "
          ⇒ 0.49 与 0.01 画得一样，而 0.51 与 0.99 也画得一样
```

### 3.4 一处会被骗的地方：权重不能大于 1

```python
def level_of(value, *, tolerance=0.0) -> int:
    if resolved < -tolerance or resolved > 1.0 + tolerance:
        raise NumericError("权重落在 [0, 1] 之外：一个权重是分布里的一项，它不可能大于 1")
```

看起来是形式主义，而它挡住的是一个具体的骗局：

```text
把两个头的权重**加起来**之后忘了归一化 ⇒ 1.5
画出来    int(1.5 × 9) = 13 → 被夹到 9 ⇒ 最右边一列全是 @
看起来    "这个位置占了全部注意力"（而实际上那是一张没归一化的表）
```

## 第四章：熵要跟天花板比（本课最值钱的一句）

### 4.1 为什么不是经验规律

```text
一行的熵 ≤ ln(这一行能看到的位置数)        ← Jensen 不等式
```

一个支集大小不超过 `k` 的分布，其 Shannon 熵的最大值在**均匀**时取到，等于 `ln k`。
因此这条不等式**不需要实验去证实**——它是数学事实。样本（`n = 4`）：

```text
  full    | 天花板 1.386294        （ln 4）
  causal  | 天花板 0.794513        （(1/4)·(ln1 + ln2 + ln3 + ln4))
  因果 / 全开 = 0.573120（n 越大越接近 1）
```

### 4.2 于是"尖"这件事被拆成两半

`HeadProfile` 因此同时留下三个数：

```text
entropy              平均每行熵
ceiling              平均每行天花板
normalized_entropy   entropy / ceiling ∈ [0, 1]      ← **跨层、跨变体可比的那把尺子**
```

演示脚本第九节把两个变体并排放在同一把尺子上：

```text
  encoder_only     | 第 0 层：熵 1.380526 | 天花板 1.386294 | 归一化 0.995839 | 判词 接近均匀
  decoder_only     | 第 0 层：熵 0.792550 | 天花板 0.794513 | 归一化 0.997528 | 判词 接近均匀
```

**这张小表是本课的结论**：

```text
熵的差        1.380526 − 0.792550 = 0.587976        ← 看起来 GPT 尖得多
归一化之后    0.997528 − 0.995839 = 0.001689        ← 几乎一样
```

那 0.588 里**全部是掩码的账**：因果掩码把第 0 行的天花板压到 `ln 1 = 0`，
整张表的天花板被压低了 42.7%。归一化之后两者都在 0.996~0.998——
也就是"**几乎均匀**"。

### 4.3 于是带走了两条边界

```text
① 未训练模型的注意力几乎均匀（归一化熵 ≈ 0.996~0.998）
   ⇒ "尖"是**训出来的**：本课读的是 day082 的确定性初始化，
     要让注意力真的变尖需要 day081 的四个旋钮（初始化 / 调度 / 裁剪 / dropout）
② 跨掩码比较之前必须先归一化
   ⇒ 否则比的是掩码，而不是模型
```

第 ① 条是本课**如实写下来**的一条边界（而不是"顺手不提"）：
它把"可解释性"放回了它该在的位置——**它量的是当下的参数，不是任务的成绩**。

## 第五章：六个读数（都能手算）

均匀表（`n = 4`、全开掩码）的六个读数：

| 读数 | 值 | 手算依据 |
|------|----|----------|
| `entropy` | `1.386294` | `ln 4` |
| `ceiling` | `1.386294` | `ln 4`（全开） |
| `normalized_entropy` | `1.0` | 熵贴到天花板 ⇒ 完全均匀 |
| `peak_weight` / `peak_index` | `0.25 @ 0` | 每一格都是 `1/4` |
| `support` | `16` | 全部格子 > 阈值 `1e-6` |
| `frobenius` | `1.0` | `√(16 × (1/4)²) = √1` |
| `diagonal_mass` | `0.25` | 平均每行看自己的比例 |
| `sparsity` | `0.0` | `1 − 16/16` |

而**行随机矩阵的 Frobenius 范数落在 `[1, √n]`**：

```text
每一行都均匀（1/n）   Σa² = n·(1/n) = 1     ⇒ √1 = 1（下界）
每一行都独热           Σa² = n·1 = n        ⇒ √n = 2（上界，n = 4）
```

于是"有多尖"这件事可以被**一个标量**看到：越接近 2 越尖。

### 5.1 演示脚本第三节的逐层读数

```text
  层 0 · 平均 2 头 | 熵 0.7925 / 天花板 0.7945 | 归一化 0.9975 | 峰值 1.0000 @ 0 | 支撑 10/16 | Frobenius 1.4450 | 接近均匀
  层 1 · 平均 2 头 | 熵 0.7943 / 天花板 0.7945 | 归一化 0.9998 | 峰值 1.0000 @ 0 | 支撑 10/16 | Frobenius 1.4435 | 接近均匀
  层 2 · 平均 2 头 | 熵 0.7932 / 天花板 0.7945 | 归一化 0.9983 | 峰值 1.0000 @ 0 | 支撑 10/16 | Frobenius 1.4445 | 接近均匀
  汇总：3 个读数 | 平均归一化熵 0.9985 | 最尖 0.9975（层 0）| 最散 0.9998（层 1）
```

两处细节：

```text
支撑 10/16      因果掩码下每层只有 10 个格子是允许的（1+2+3+4）——支撑集正好等于它
峰值 1.0000 @ 0 那是**第 0 行**（它只能看到自己 ⇒ 权重恰好 1.0），不是"模型很自信"
```

第 2 条值得多看一眼：如果没有掩码，`峰值 1.0000` 会被读成"某个位置吸走了全部注意力"；
而在这里它只是**因果掩码第 0 行的必然结果**。这也是为什么本课坚持
"熵要跟天花板比"——同一条纪律把峰值也变成了"要看它落在哪一行"。

### 5.2 头间冗余（逐格余弦）

```text
  层 0 | 非对角余弦 0.9947 0.9947
  层 1 | 非对角余弦 0.9998 0.9998
  层 2 | 非对角余弦 0.9972 0.9972
  非对角平均：0.997268
```

`0.997268` 说明：**在这一点上（随机初始化）两个头几乎在看同一件事**。
它**不能**说明"多头没有用"（那要看训练之后），也不能说明"模型不好"。

这个读数还有一条已知边界，本课把它写下来而不是藏起来：

```text
余弦度量的是"两张表的形状像不像"：它**不区分**"看同一个位置"与"看同一片区域"
⇒ 因此它只作为一条读数，`dead_heads` 用的是另一条（归一化熵）
```

### 5.3 偏移质量（"它看的是相邻位置吗"）

```text
  偏移 k=0 | k=1 | k=2
  层 0：0.517519 | 0.356631 | 0.321163
  层 1：0.522113 | 0.359689 | 0.290811
  层 2：0.519803 | 0.350054 | 0.317717
```

`k = 0` 是自看自，`k = 1` 是看前一个位置（**归纳头**常出现在这里，
day075 的 induction 任务与 day076 的可达性读数都指向它）。
三条斜线的质量在同一量级，说明在初始点上并没有"专门看前一个位置"的头。

一条口径要写下来：**因果掩码下 `k >= i` 的格子不存在**，
因此第 0 行会拉低平均——那是掩码的账，看这张表时要记得。

## 第六章：滚动——残差就是那条直通路

### 6.1 为什么"最后一层的热力图"会骗人

单看最后一层时，"第 3 层没在看第 0 个位置"看起来像"它不重要"。
而残差把每一层的输出**加上**了输入 ⇒ 第 3 层看第 1 层、第 1 层看第 0 层，
于是第 0 个位置的信息经过**两跳**就到了输出。滚动就是把这件事写下来：

```text
Â_l = α·A_l + (1−α)·I_l            每个因子都会"顺手把输入带过去"
R   = Â_L · Â_{L−1} · … · Â_1       矩阵乘 ⇒ 路径被自动求和
```

那一项 `(1−α)·I` 不是技巧，而是 day079 的 `y = x + F(x)` 里那个 `+x`
**在注意力层面的样子**。`α = 0` 时 `R = I`——所有质量都在对角线，信息一跳都没走。

### 6.2 三条可断言的性质

```text
① R 仍然行随机                每个因子行随机（凸组合）⇒ 乘积行随机
② 掩码挡掉的格子仍然逐位为 0    下三角 × 下三角 = 下三角，而且那些 0 是**精确的**
③ α = 0 时 R = I              一条把"这个公式在做什么"说清的判据
```

第 ② 条最值钱：它把 day082 的"因果性是逐位的 0"**传到了滚动之后**。
演示脚本第六节：

```text
  滚动（α=0.5，3 层） | 4×4 | 流 self | 熵 0.7675（天花板 0.7945，归一化 0.9660）
  α = 0 时为单位阵：True
  掩码外逐位为 0 的格子数与最大读数：(6, 0.0)
  最后一层的归一化熵：0.998309
  滚动（α=0.5，3 层）的归一化熵：0.965952
  集中度变化：+0.032358（更尖）
```

`+0.032358` 说明滚动之后**比最后一层更集中**——这正是"多跳之后信息更聚焦"
的读数。而本课必须补一句边界：**它可能是负数**（一个已经很尖的模型，
多个因子相乘会把质量摊开），因此本课如实给出三个数，判词留给调用方。

### 6.3 `preserves_causal_zeroes` 与 `mask_respected_after_rollout`

两个函数看着重复，其实口径不同：

```text
preserves_causal_zeroes        只看上三角
                               因果表：(6 个格子全 0) ⇒ True
                               全开表：上三角本来就没有 0 ⇒ **恒为 False**
mask_respected_after_rollout   看**掩码说的每一格**，返回 (格子数, 最大读数)
                               因果表：(6, 0.0)；全开表：(0, 0.0)
```

报告里用的是**按掩码**的那一版，因为那一版对两种掩码都说得通；
而"全开表上被查 0 个格子"这个读数要**如实印出来**——
否则"通过"会显得比实际更强（与 day082 的"不适用 ≠ 通过"同源）。

## 第七章：六条性质

```text
rows_are_distributions            每一行非负、和为 1、有限
masked_entries_are_exact_zero     掩码外的格子 `== 0.0`（沿用 day082 的判据）
entropy_within_ceiling            每一行熵 ≤ ln(这一行能看到的位置数)
heatmap_round_trip                渲染 → 解析 ⇒ 逐级相同
rollout_is_stochastic             行随机 + 掩码外逐位为 0
deterministic                     两次渲染/滚动逐位相同
```

演示脚本第七节的证据（6 条记录、24 行）：

```text
  全绿：True | 主体：records=6 heads=6
  [通过] rows_are_distributions | 6 条记录、96 个格子 | 最大的行和误差 1.110e-16（容差 1e-09）
  [通过] masked_entries_are_exact_zero | 掩码外共 36 个格子，最大读数 0.000000e+00（逐位为 0）
  [通过] entropy_within_ceiling | 24 行 | 最大的'熵−天花板' 0.000e+00 | 最紧的一行还剩 0.000e+00
  [通过] heatmap_round_trip | 6 条记录、24 行全部逐级相同（10 级是有损的）
  [通过] rollout_is_stochastic | α=0.5 | 3 层 | 最大的行和误差 0.000e+00（容差 1e-12）| 掩码外 6 个格子最大读数 0.000000e+00（逐位为 0）| 上三角全 0：True
  [通过] deterministic | 两次渲染逐字符相同：True | 两次滚动逐位相同：True（6 条记录、4 行）
```

### 7.1 每一条都有一条"它会亮红"的反证

```text
第 1 条    它的分辨力在**构造期**：AttentionRecord 直接拒绝坏行和（测试里钉住）
第 2 条    把被挡的一个格子填成 0.001 ⇒ 亮红
第 3 条    掩码只允许 1 个位置、而权重却散在两个位置上 ⇒ 亮红
第 4 条    它的"会亮红"那一面在**解析侧**：不认识的字符当场拒绝
第 5 条    某一层的被挡格子非 0 ⇒ 滚动之后仍非 0（而且被放大）
第 6 条    在无随机数的实现里必然通过（因此它是"如实说明"，不是判据）
```

### 7.2 两条"不可能失败"的性质为什么不删掉

```text
它通过     与     它被删掉     必须可区分
```

因此本课的做法是**把信息量如实印出来**：

```text
第 1 条    印出实测的最大行和误差（1.110e-16）——读者能看出它离容差有多远
第 6 条    印出两次比较的布尔值——读者能看出这条通过有多"廉价"
```

同一条纪律在 day082 出现过：`encoder_only` 的 `mask_zeroes_are_exact`
印的是"掩码外共 **0** 个权重"，而不是把它藏起来。

## 第八章：今日总结

| 设计决策 | 背后的原理 | 落地位置 |
|----------|-----------|----------|
| 读权重而不是重算 | 可解释性最容易出的错是"读的不是模型算的那一份" | `extract.self_records` |
| 两条读法分开放 | 多头会改变投影划分与缩放（`1/√d_head`） | `self_records` / `head_records` |
| `heads=1` 逐位相等 | 两处实现之间唯一能比的地方 | `single_head_matches` |
| 分头读法重放到那一层 | 否则读的是"把输入直接喂给第 k 层" | `_stream_input_at_layer` |
| 图是文本 | 能进 diff、能被断言、零依赖 | `render.py` |
| 10 级 + 明确的区间 | "能看出差别"是热力图存在的全部理由 | `level_of` / `LEVELS` |
| 渲染 → 解析逐级相同 | 画错的图看起来同样正常 | `round_trip` |
| 权重不能 > 1 | "两个头相加忘了归一化"会画出满屏 `@` | `level_of` |
| **熵要跟天花板比** | 因果掩码把天花板压到 `ln 1 = 0` | `HeadProfile.normalized_entropy` |
| 归一化之后才跨变体比 | 那 0.588 全是掩码的账 | 第 4.2 节 |
| 未训练模型的边界如实写 | "尖"是训出来的（day081 的四个旋钮） | 第 4.3 节 |
| 对角质量只对自注意力 | 交叉那一流的列是**源位置** | `profile_of` |
| 头间余弦要求同掩码 | 否则比的是"能看到多少" | `head_redundancy` |
| 滚动带 `(1−α)·I` | 那就是 day079 的残差 | `_blend` |
| 掩码零模式传到滚动之后 | 下三角 × 下三角 = 下三角 | `mask_respected_after_rollout` |
| 两个零读数都要印 | 全开表上被查 0 个格子 | 第 7.2 节 |
| 反证写进测试 | "它通过"只有在"它会失败"被证明后才有信息 | 第 7.1 节 |
