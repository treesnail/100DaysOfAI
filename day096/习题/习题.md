# day096 课后习题（M8-D7：PyTorch 高级与综合实践）

共 16 题，覆盖七个阶段的地图（`dataset / sampler / dataloader / device / train /
checkpoint / inference`）、数据集的两条不变式（不可变 + 内容指纹）、DataLoader 的三个读数
（批数 / 丢弃 / 尾批）、工作进程分片的"互不相交 + 并集为全集"、设备与显存的三块字节算术、
检查点五件套与哈希的覆盖范围、**恢复训练为什么必须逐位相等**、推理相与可注入时钟，
以及七条性质的三类判据与五个失败族。

建议完成时间：90~105 分钟。

## 第一部分：选择题

### 第 1 题（七个阶段的地图，第一章）

关于 `types.STAGES` 与 `PIPELINE_AXES`，下列哪一项**最准确**？

- A. 七个阶段是 `dataset / sampler / dataloader / device / train / checkpoint / inference`；
  四个轴是 `batch / worker / device / time`；两张名单都写在代码里并在导入期做
  `set(...) == set(...)` 的闭合断言——读报告时"这个数字属于哪一段"不该靠记忆
- B. 七个阶段是七个 Python 文件，一个文件对应一个阶段，文件删掉阶段就消失
- C. 四个轴是 `cpu / cuda / mps / tpu`，与设备强绑定
- D. 阶段表只是文档，写进代码会导致导入变慢，因此不应该放进 `types.py`

### 第 2 题（数据集与指纹，第二章）

关于 `TabularDataset` 与 `dataset_fingerprint`，下列哪一项**最准确**？

- A. 数据集是可变对象，允许在训练中途补齐标签；指纹只覆盖样本条数
- B. 数据集是 `frozen` 的（切分返回新对象）；指纹是规范化 JSON 的 `sha256` 前 16 位，
  **顺序参与计算**；它回答的是"这两个分数能不能比"
- C. 指纹与顺序无关，因为 `sort_keys=True` 会把列表也排序
- D. 只要两个数据集的指纹不同，就说明它们的条数一定不同

### 第 3 题（DataLoader 的三个读数，第三章）

24 条样本、`batch_size = 7`、`shuffle=True`。下列哪一项**最准确**？

- A. `drop_last=True` → 批数 4、丢弃 3；`drop_last=False` → 批数 4、丢弃 0
- B. `drop_last=True` → 批数 3、丢弃 3；`drop_last=False` → 批数 4、丢弃 0；
  批数公式分别是 `n // b` 与 `ceil(n / b) = (n + b − 1) // b`
- C. 两种配置的批数都是 3，因为最后一个不满的批永远被丢掉
- D. `drop_last=False` 时丢弃数是 `n − b × 批数`，等于 −2

### 第 4 题（工作进程分片，第四章）

关于 `shard_indices(size, *, workers, worker_id)` 与第 ② 条性质，下列哪一项**最准确**？

- A. 分片只需要"看起来均匀"；覆盖不足属于性能问题，不需要断言
- B. `worker k` 的分片是 `{ i : i % workers == k }`；它必须满足两个条件：
  **并集为全集**（下界判据，覆盖率 `>= 1.0`）与**互不相交**（相等判据，重叠项数 `== 0`）
- C. 分片必须按"连续一段"切（前 n/workers 条给 worker 0），否则不叫分片
- D. "并集为全集"应该用上界判据（覆盖率 `<= 1.0`）

### 第 5 题（设备与检查点，第五 / 第六章）

下列哪一项**最准确**？

- A. `plan_device` 在预算不足时抛异常，因为"放不下"是非法状态
- B. `total = params + activations + optimizer_multiplier × params`；预算不足由
  `fits=False` 与一条警告暴露；检查点的 `params_sha256` / `optimizer_sha256`
  **只覆盖权重与优化器状态**，不包含 `metrics.json` / `history.jsonl`
- C. 检查点清单的哈希应该覆盖全部五个文件，这样"文件被改过"才能被发现
- D. `optimizer_multiplier` 缺省为 1，对应 SGD 不含任何动量

### 第 6 题（恢复与推理，第七 / 第八章）

下列哪一项**最准确**？

- A. 恢复训练只要把权重读回来就行；优化器状态可以重新初始化，因为 Adam 会自己收敛
- B. 恢复 = 载入 `params` + 装回优化器跨步状态 + 从 `epoch k+1` 继续（`order(k+1)` 逐位相同）；
  三条缺一不可，因为**每一种缺法都只会让结果"看起来更好或差不多"，不会报错**
- C. 恢复后应该从 `epoch k` 重新训，这样能把中断那一轮补完整
- D. 推理也应当走训练相，这样 BN 能用本批统计量，精度更高

## 第四部分：简答题

### 第 14 题（第五章 5.2、第六章 6.2、第七章、第八章 8.2）

下面四个设计决定都很容易被"改得更直观"，但每一个都有明确代价。请逐一说清三件事：
**这个决定是什么 / 改成"直观做法"会怎样 / 用什么手段守住**，并注明对应章节或函数。

1. 预算放不下时**不抛异常**，只把 `fits` 置为 `False`；
2. 检查点清单的哈希**只覆盖权重与优化器状态**，不覆盖 `metrics.json` / `history.jsonl`；
3. 推理延迟必须用**可注入的时钟**，而不是直接调 `time.perf_counter()`；
4. 恢复训练的判据是**相等**（`== 0`）而不是"损失差不多"。
