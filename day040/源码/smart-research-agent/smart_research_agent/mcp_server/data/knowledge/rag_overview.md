# RAG 概述

RAG（Retrieval-Augmented Generation，检索增强生成）是一种把「信息检索」与
「语言模型生成」相结合的架构。它先从一个外部知识库中检索出与问题相关的文档片段，
再把片段作为上下文喂给生成模型，让模型据此作答。

相比单纯依赖模型内部知识的做法，RAG 的核心优势是：

1. **答案可溯源**：每一处关键事实都能对应到检索到的文档，便于人工核对。
2. **降低幻觉**：模型被显式约束在检索到的上下文内作答，凭空编造的概率大幅下降。
3. **低成本更新**：知识更新无需重新训练模型，向知识库增删文档即可。

典型流程分两个阶段：

- **离线建索引**：文档切块 → embedding 编码 → 写入向量库。
- **在线查询**：查询编码 → 向量检索召回 Top-K → 拼装提示词 → 生成答案。

评估时应把检索环节与生成环节分开度量：检索用 recall / precision / MRR / NDCG，
生成用 LLM-as-a-judge 评估忠实度（faithfulness）。
