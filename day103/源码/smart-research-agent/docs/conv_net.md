# 卷积神经网络 CNN：权重共享与空间反向（day093 / M8-D4）

> 一本可随手翻的手册，与 `smart_research_agent/conv_net/` 一一对应。
> 每一节的每个结论都能在包内找到对应函数；每个读数都能现场重跑。

## 1. 这一课要回答什么

day089 的 `Dense` 是"每个输入位置用一个独立的权重"。卷积第一次引入**空间上的权重共享**：

```text
权重共享  同一组核在输入的不同位置被重复使用   ⇒ 参数量 O(H·W) → O(k²)
局部连接  每个输出只看一个 k×k 窗口              ⇒ 感受野
多通道    在通道维再做一次加权求和               ⇒ C_in → C_out
```

一句话本质：**同一组权重在输入的不同位置被重复使用。**
实现见 `conv_net/ops.py`（算子）与 `conv_net/layers.py`（层）。

## 2. 算子层：四个必然要用到的函数

| 函数 | 公式 / 作用 |
|------|-------------|
| `output_size` | `⌊(H + 2p − d·(k−1) − 1)/s⌋ + 1`（只接受整数补边） |
| `resolve_padding` | 把 `valid` / `same` / 整数解析成具体补边数 |
| `feature_size` | 先解析填充、再套尺寸公式（调用方不用自己解析） |
| `conv2d` | 单通道互相关：`y[i,j] = Σ x[i·s+u·d, j·s+v·d]·K[u,v]` |

**一个必须写下来的约定**：深度学习里的"卷积"实际是**互相关**（核不翻转）。
PyTorch 的 `nn.Conv2d` 也是互相关。本包沿用这个约定。

### 2.1 `same` 只在奇数核、步长 1 时精确成立

`same` 的补边数是 `(d·(k−1))//2`。要求解析出的输出尺寸恰好等于输入；
偶数核 + 步长 1 会得到 `size − 1`，因此当场抛 `WindowError`，
而不是默默给出一个"少一列"的特征图。

## 3. 池化：降采样，且窗口必须整除地盖满

```text
max   窗口取最大值（对微小平移不敏感）
avg   窗口取均值（对噪声更平滑）
```

窗口与步长盖不满输入时抛 `WindowError`。"取前几块、把不平整的部分丢掉"这种兜底
**不会报错**，只会让实际下采样率与你以为的不同——本包不接受它。

## 4. 感受野：堆两层 3×3 等于一层 5×5

```text
r₀ = 1；r ← r + (k − 1)·∏s
```

| 层序列 | 感受野 | 参数量（单通道） |
|--------|--------|------------------|
| 一层 3×3 | 3 | 9 |
| 两层 3×3 | 5 | 18 |
| 三层 3×3 | 7 | 27 |
| 一层 5×5 | 5 | 25 |

**感受野相同，而两层小的参数更少**——这是"小核堆深"的第一个理由（另一个是多了非线性）。

## 5. 多通道卷积在做什么

```text
对每一个输出通道 c_out：
    y = Σ_{c_in} conv2d(x[c_in], K[c_out][c_in]) + b[c_out]
    y = activation(y)
```

"通道维上的加权求和"就是一次**全连接式的混合**。这也是为什么 `conv2d` 只做单通道：
多通道只是把单通道的结果按不同的核加起来（`layers.conv_block_forward`）。

## 6. 反向：三块梯度的形状口诀

| 梯度 | 形状 | 含义 |
|------|------|------|
| `d_kernel` | 与 kernel **相同** | 每个核元素被用到的次数（加权和） |
| `d_bias` | 与 bias 相同（标量） | 这个输出通道被用到的总强度 |
| `d_image` | 与 image **相同** | 每个输入位置对损失的贡献（所有输出位置累加） |

`d_kernel` 与 `d_image` **互为"转置"**：把 `grad_out` 当权重、把输入当被求和项，
还是反过来。写反了**形状仍然正确**——因此只有一把独立的尺子能发现它：
day074 的**数值差分**。这就是第 ⑤ 条性质。

实现见 `conv_net/gradients.py`（`conv2d_backward` / `conv_block_backward` / `pool2d_backward`）。
激活的反向导数**不重写**，直接调用 day090 的 `backprop.gradients.elementwise_backward`。

## 7. 池化反向

```text
max   把梯度给到窗口最大值那一格（其余为 0）
avg   把梯度均分给窗口内每一格（总和不放大）
```

## 8. 一个小 CNN 的完整链

```text
1×6×6 → conv(1→2, k=3, same, relu) → maxpool(2) → flatten(18) → dense(18→2) → logits
```

三个接缝都在 `conv_net/network.py` 里被钉住：

```text
① 卷积与池化    conv 的输出（含 pre_activation 缓存）直接喂给池化
② 池化与全连接  池化后的每张特征图按行优先压平、通道序拼接 ⇒ dense 的输入
③ 反向          dense 的 d_flat 拆回各通道 ⇒ 逐通道池化反向 ⇒ 卷积反向
```

参数压平沿用 day090 的契约：`flatten_params` / `unflatten_params` 顺序写死，
还原时用**参数本体当形状表**，长度对不上当场抛 `ShapeError`。

## 9. 七条性质

| # | 性质 | 判据 |
|---|------|------|
| ① | `conv2d` = 手写滑窗点积 | 逐位相等 |
| ② | 卷积是线性算子 | ≤ 1e-12 |
| ③ | `same` 让输出同尺寸 | 整数相等 |
| ④ | 尺寸公式与实际形状一致 | 整数相等 |
| ⑤ | 解析梯度 = 数值差分 | ≤ 1e-9 |
| ⑥ | 池化 = 窗口极值 / 均值 | ≤ 1e-12 |
| ⑦ | 感受野递推 = 逐层区间传播 | 整数相等 |

判据两类：**相等**与**不超过上界**。见 `conv_net/verify.py`。

## 10. 三条边界

- 只做单/多通道二维卷积：不做 3D、分组、空洞卷积的工程优化。
- 不做 GPU / 向量化：纯 Python 滑窗，为的是可读与可对账，不是速度。
- 不新增第三方依赖：不 import torch / numpy；PyTorch 只写在对照表里，不安装也不调用。
