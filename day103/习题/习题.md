# day103 习题：把 100 天的模块编成一张依赖图

> 对应教程：[../教程/教程.md](../教程/教程.md)
> 对应手册：[../源码/smart-research-agent/docs/import_graph.md](../源码/smart-research-agent/docs/import_graph.md)
> 建议用时：30~45 分钟。答案在 [../习题答案/习题答案.md](../习题答案/习题答案.md)。

题目分为四类：**速答**（1~6）、**对照**（7~9）、**诊断**（10~13）、**推导与动手**（14~18）。

---

## 一、速答

1. 本课把什么当成"节点"？`__init__.py` 与普通 `.py` 在节点命名上有什么不同？

2. 两类边 `absolute` 与 `relative` 的区别是什么？为什么相对导入要"减掉 level - 1 层点"？

3. 为什么本课**不 import** 被扫描的模块，而是用 `ast` 读 import 语句？请说出**两条**具体好处，
   并举出本仓库里一个"只有这种读法才能看见"的例子。

4. `sccs()` 与 `cycles()` 有什么区别？`topological_order()` 的长度为什么会**小于**模块数？

5. "下游闭包"与"上游闭包"各回答什么问题？为什么本课坚持把方向写成必填语义？

6. 本课"回来的族"与"缺席的族"分别是哪一个？各自给出一条理由。

---

## 二、对照

7. 把本课的七条性质与 day102 的七条性质对照：哪几条是"同一个问题的同一句话"，
   哪几条是本课**特有**的？

8. 本课有一条**子进程测试**（两个不同的 `PYTHONHASHSEED` 必须给出同一个摘要）。
   它和 day101 的"倒排表文档名必须排序"、day102 的"族按包名升序 × 源码顺序排"
   是不是同一条纪律？请说明它们各自在防什么。

9. `require_acyclic()` 与 `topological_order()` 的关系是什么？为什么前者要独立成一族
   （`CycleError`），而不是记进 `GraphBuildError`？

## 三、诊断

10. 某次运行 `import_targets_resolve` 报"未解析 2 条"。请说出**三种**可能原因及各自该改哪里。

11. 有人把 `resolve_candidates` 的排序键从 `(-len(item), item)` 改回 `len(item), reverse=True`。
    请构造一个会出问题的例子，并说明现象（提示：`from . import a, b`）。

12. `tools/image_analysis.py` 里那一行 `from smart_research_agent.api.app import default_llm`
    写在**函数体内部**。请解释：为什么它没有让程序在导入期死锁，
    而依赖图里却出现了 `api ↔ tools` 这个环？

13. 一个模块 `smart_research_agent.foo.bar` 的 `from ...baz import X`（三个点）会解析到哪里？
    如果 `foo` 已经在包根，这一条会解析到空串——那时 `ImportRef.internal` 应该是 `True` 还是 `False`？为什么？

## 四、推导与动手

14. 给定三个模块：`a → b`、`b → c`、`c → a`。请写出：
    - `sccs()`（分量与成员排序）；
    - `condensation_edges()`；
    - `topological_order()`（长度是多少？）。

15. 证明：如果图里没有环，那么 `topological_order()` 的长度等于节点数。

16. 用本包的公开 API 写一段 5 行以内的代码，打印出"`utils` 这个子包的上游闭包大小"
   与"它的下游闭包大小"，并说明为什么两个数很不对称。

17. 写一条**新的**性质（不要求实现进源码），要求：
    - 它是一条**下界**判据；
    - 它检查"`utils` 被多少个子包依赖"（即它的上游跨包邻居数）；
    - 说明它的失败意味着什么。

18. 本课把"依赖图可能不是 DAG"当成一个**读数**而不是一次失败。
    请再举一个**本仓库里真实存在**的类似例子（可以是 day101 / day102 的），
    说明"什么情况下一个看起来像缺陷的现象应当被印出来、而不是被一条性质删掉"。
