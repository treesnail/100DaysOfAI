# day105 习题：把 100 天钉死的常量编成一份台账

> 对应教程：[../教程/教程.md](../教程/教程.md)
> 对应手册：[../源码/smart-research-agent/docs/constant_ledger.md](../源码/smart-research-agent/docs/constant_ledger.md)
> 建议用时：30~45 分钟。答案在 [../习题答案/习题答案.md](../习题答案/习题答案.md)。

题目分为四类：**速答**（1~6）、**对照**（7~9）、**诊断**（10~13）、**推导与动手**（14~18）。

---

## 一、速答

1. 本课把什么当成"一条常量"？请举出**三种**"看起来像常量、本课却不收"的写法，并各说一句理由。

2. 两类取值形态 `literal` 与 `opaque` 分别是什么？为什么它们**必须**分开记？
   请用一句"如果不分开会怎样"来说明。

3. 四类同名关系（`unique` / `consistent` / `conflict` / `incomparable`）的判定顺序是什么？
   为什么"先判能不能比、再判比出来是什么"这一步不能换？

4. 为什么本课**不**写一条"同名必须同值"的性质？那条性质会在什么时候变红？
   本课给"同名不同值"留了什么出口？

5. 本课第 ③ 条性质（`conflicts_are_sound`）走的是哪条独立的路？
   它与 `parse.fingerprint` 分别看什么？这条性质能抓住哪一类错误？

6. 本课"回来的族"与"缺席的族"分别是哪一个？各自给出一条理由。

---

## 二、对照

7. 把本课的七条性质与 day104 的七条性质对照：哪几条是"同一个问题的同一句话"，
   哪几条是本课**特有**的？

8. 本课有一条**子进程测试**（两个不同的 `PYTHONHASHSEED` 必须给出同一个摘要）。
   它和 day101 的"倒排表文档名必须排序"、day103 的"候选按 `(-len, name)` 排"、
   day104 的"模块按名字排序"是同一条纪律吗？请说明本课防的**具体是哪一种容器**。

9. day104 的 `symbol_catalog` 与 day105 的 `constant_ledger` 都读**模块级**作用域。
   它们的**问题**与**材料口径**各有什么不同？为什么同一个名字在两条产物里会得到不同结论
   （例如一个 `ABSENT_FAMILY` 在 day104 里是一个"承诺"，在本课里是一组"取值冲突"）？

## 三、诊断

10. 某次运行 `conflicts_are_sound` 报"不成立 3 个"。请说出**三种**可能原因及各自该改哪里。

11. 有人把 `canonical_value` 里那句"集合先排序再拼接"删掉了，直接对 `literal_eval` 的结果取
    `repr`。请构造一个会出问题的例子，并说明现象（提示：`PYTHONHASHSEED`）。

12. `parse.value_segments` 的实现在遇到"同名的最后一条赋值"时才覆盖前一条
    （`table[target.id] = ...` 是覆盖写）。为什么这与 `ModuleConstants.primary_of`
    （取 `rows[-1]`）是一致的？如果两处取的不是同一个定义，会发生什么？

13. 一个模块里写了：

    ```python
    EPSILON: float = 1e-5
    EPSILON = 1e-6
    ```

    请回答：① 本课为它记下几条常量定义？② `primary_of("EPSILON")` 给出哪一个？
    ③ 第 ⑤ 条性质（`duplicate_assignments_within_module`）会怎么读它？

## 四、推导与动手

14. 给定三个模块：

    - `pkg.a`：`EPSILON = 1e-5`、`BATCH = 8`
    - `pkg.b`：`EPSILON = 1e-5`、`BATCH = 32`
    - `pkg.c`：`ROOT = Path(__file__)`、`EPSILON = 1e-5`

    请写出：① 每个名字的关系类别；② `shared_groups()` 里有几个名字；
    ③ `conflicts()` 里有几个名字；④ 性质 ⑥（常量数 >= 500）在这份小台账上会怎样？

15. 证明：如果 `ModuleConstants.__post_init__` 的两条护栏（排序且不重复、不许混入别的模块）
    都成立，那么 `duplicate_names()` 只可能来自"同一个模块里同一个名字被写了两行"。

16. 用本包的公开 API 写一段 5 行以内的代码，打印出"同名组数"与"冲突组数"。

17. 写一条**新的**性质（不要求实现进源码），要求：
    - 它是一条**上界**判据；
    - 它检查"读不出取值的常量占比"（`opaque_count / constant_count()`）不超过某个界；
    - 说明它的失败意味着什么。

18. 本课把"同名不同值"当成一个**读数**而不是一次失败。
    请再举一个**本仓库里真实存在**的类似例子（可以是 day101 / day102 / day103 / day104 的），
    说明"什么情况下一个看起来像缺陷的现象应当被印出来、而不是被一条性质删掉"。
