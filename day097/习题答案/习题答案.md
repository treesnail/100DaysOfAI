## 一、一页速答

**1.**
```text
M7（day073 ~ day088）  回答"怎么表达"：从一次点积（注意力）搭出能表达序列关系的架构
M8（day089 ~ day096）  回答"怎么学会、怎么复现"：把梯度算对、走对，并跑成一条可复现的管线
```
一句话本质：**M7 决定"能不能表达"，M8 决定"能不能学会、能不能复现"。**

**2.**
```text
scores = Q·Kᵀ / √d_k        每一次打分是一次点积；除 √d_k 是尺度归一
A      = softmax(scores)     每一行是一个概率分布 ⇒ 行和为 1（这是 softmax 的**定义**，不是学到的）
out    = A·V                 用打分当权重，对 V 加权求和
```
出处：day075（Attention 机制）、day088 的命题 `attention_rows_are_distributions`
（`transformer_core.assert_rows_are_distributions` 现场验算）。

**3.** 多头在**投影内部**切头：先把整份输入投影成 Q/K/V，再从投影结果里切 h 份，
每一份 `d_k = D/h`，各自算一次注意力再拼回。切错了形状仍然对，因为每一头都是 `(n, d_k)`、
拼回还是 `(n, D)`——形状对、数值错，只有对账能发现。
出处：day076（多头注意力）、day088 命题 `multi_head_splits_inside_projection`。

**4.** 因为注意力输出是**加权求和**，权重只由内容（`Q·Kᵀ`）决定、与位置无关；
打乱输入只是打乱同一个加权的顺序，每一行内的加权集合不变，因此输出对顺序不变。
所以需要位置编码把"第几个 token"注入表征。
出处：day078（位置编码）、day088 命题 `position_encoding_breaks_permutation`。

**5.**
```text
规则   上游梯度 × 局部导数（链式法则）
纪律   累加（+=）：一个值被用了 k 次，它的梯度是 k 条路径之和
```
写错的是**纪律**那半句：用 `=` 代替 `+=` 会得到形状对、数值有限、训练仍会下降的梯度，
只是偏小——程序不会报错。出处：day090 第二章（`ChainError` 独立成族的理由）。

**6.**
```text
dW[j][k] = Σ_i dY[i][j]·X[i][k]     求和指标是**样本维** i   ⇒ 形状 (out, in)
db[j]    = Σ_i dY[i][j]             求和指标是**样本维** i   ⇒ 形状 (out,)
dX[i][k] = Σ_j dY[i][j]·W[j][k]     求和指标是**输出维** j   ⇒ 形状 (rows, in)
```
出处：day090 第四章；`dX` 遍历的是 W 的**列**，写反了形状仍然对。

**7.** 因为同一个循环权重被 T 个时刻复用：一个值被用了 k 次，梯度是 k 条路径之和。
读数（day094 7.2）：三步都回传 `‖dW‖ = 3.014188`；只留最后一步 `‖dW‖ = 1.503321`（49.9%）。
出处：day094 7.2 与用例 `test_rnn_bptt_accumulates_across_time`。

**8.** 根本原因是**权重共享**：同一组核在每一个位置被复用，参数只随核尺寸增长、与图尺寸无关。
```text
params = C_out·(C_in·k_h·k_w) + C_out
```
出处：day093 第二章（6×6 图直连 18 维全连接头 666 权重 vs `conv(1→2, k=3)` 20 权重）。

**9.**
```text
① 取 lr（调度在优化器内部，step 之前取值）
② 裁剪（整体范数）
③ 更新规则（耦合衰减在此**之前**进梯度）
④ 衰减（解耦衰减在更新**之后**缩参数）
```
顺序写死，不给调用方自己拼；顺序错了不报错、只算错。出处：day092 3.1。

**10.** 因为它被写进了两个**常量**：`RETURNED_FAMILY` 与 `ABSENT_FAMILY`，
测试逐字断言，因此"今天没有这一族"与"我忘了加"可以区分开。
```text

        （第一次同时有两条独立路径，这一族被真的抛出）
day092  ABSENT_FAMILY   = "GradientError"
        （本课消费梯度、不计算梯度，两条路径对不上在今天不可能发生）
```

**13.**

```text
（甲）卷积  params = C_out·(C_in·k_h·k_w) + C_out，与图的大小无关（只随核尺寸增长）
      循环  rnn  params = H·(D + H + 1)，与序列长度 T 完全无关（T=1/3/8 都是 12）

（乙）卷积**可并行**：全图每个位置彼此独立（都用同一张核点积），可以一次算完；

（丙）卷积的"累加"发生在**位置**上：d_kernel 把每个位置被用到的次数加权求和，

      循环的"累加"发生在**时间步**上：dW = Σ_t dz_t ⊗ x_t。

（丁）卷积读数：两层 3×3 感受野 5、参数 18 vs 一层 5×5 参数 25；
      循环读数：dW 三步 3.014188 vs 只留末步 1.503321；或参数量 T=1/3/8 都是 18(rnn)/72(lstm)。
```

## 四、诊断题

**15.**

```text
读数 A  恢复训练 vs 一口气训练，最大绝对差 = 3.2e-03（判据 == 0）
  **要动作。** 这是一条**相等**判据，3.2e-03 非 0 就是失败。最可能的原因（按顺序排查）：
  ① 恢复时没有装回优化器的跨步状态（Adam 的动量从 0 重新开始）；
  ② 恢复后重新建了 Sampler(seed)，第 k+1 轮的顺序与原来不同；
  ③ 从 epoch k 重新训，而不是从 k+1 继续。
```

## 五、推导题

**17.（推导）感受野的两种算法等价**

```text
（甲）两层 3×3（步长全 1）：
  路径一（闭式递推）  r₀ = 1
                      第 1 层：r = 1 + (3−1)·1 = 3
                      第 2 层：r = 3 + (3−1)·1 = 5
  路径二（区间传播）  初值 [0, 0]
                      往回第 2 层：[0·1, 0·1 + (3−1)] = [0, 2]      宽度 3
                      往回第 1 层：[0·1, 2·1 + (3−1)] = [0, 4]      宽度 5
  两条都得 5。∎

（乙）两层 3×3 + 池化 2×2（池化核 2、步长 2）：
  路径二（从终端的池化输出往回走）：
     初值 [0, 0]
     往回过池化（k=2, s=2）：[0·2, 0·2 + (2−1)] = [0, 1]      宽度 2
     往回过第 2 层卷积（k=3, s=1）：[0·1, 1·1 + (3−1)] = [0, 3]   宽度 4
     往回过第 1 层卷积（k=3, s=1）：[0·1, 3·1 + (3−1)] = [0, 5]   宽度 6
  感受野 = 6。闭式递推同样得 6（r = 1 → 3 → 5 → 6，池化那一步加上 (2−1)·∏s = 1）。
  为什么是 6 而不是 5：**池化的步长把"每个输出看多远"整体拉开**——
  它的窗口落在步长 2 的网格上，相邻窗口之间不再像卷积那样只错开 1 格。
  出处：day093 7.1（读数行"两层 3×3 + 池化 2×2 | 感受野 6 | 区间传播 6"）。

（丙）day093 用第 ⑦ 条性质 `receptive_field_matches_direct` 把两条路径钉在一起：
      读数 `0.000e+00 == 0`（递推 = 10 vs 区间传播 = 10，用的是一个更深、感受野为 10 的配置）。
      **自证是不成立的**：一条公式自己算两遍不算对账，因此这里用的是两条独立的算法
      （`verify.direct_receptive_field` 的区间传播 vs `study` 的闭式递推）。
```

**18.（推导）BPTT 的累加纪律**

```text
（甲）因为形状完全正确：dW 仍是 (H, D)（LSTM 下是 (4H, D)），数值有限，
      训练仍然会下降，只是梯度偏小。程序里没有任何检查能发现"少加了 T−1 项"——
      它既不是形状错误，也不是非有限值，因此既不抛 ShapeError、也不抛 NumericError。

（乙）day094 的实测（7.2）：
      三步都回传：  ‖dW‖ = 3.014188
      只留最后一步：‖dW‖ = 1.503321
      1.503321 / 3.014188 ≈ 0.4988 ⇒ "只留末步"是全累加的约 **49.9%**。

（丙）症状：loss 仍然在降、曲线形状正常，只是收敛更慢。
      因为"梯度整体偏小"与"学习率设小了"在读数上无法区分——两者的表现都是
      "每一步的更新量偏小"。这正是它危险的地方：人会去调学习率，而问题在接线。
      出处：day094 7.2 与用例 `test_rnn_bptt_accumulates_across_time`
      （断言整段的 ‖dW‖ 必须**严格大于**"只算最后一步"的 ‖dW‖）。

（丁）共同点：都是"**形状对、数值错**"。
      day093 的 d_kernel 与 d_image 互为转置，写反后 d_kernel 仍是 k×k、d_image 仍是原图大小；
      本题的"只留末步"dW 仍是 (H, D)。因此都只能靠**一把独立于推导的尺子**发现：
      day093 靠 day074 的数值差分（第 ⑤ 条性质，读数 1.579e-10 <= 1.0e-09），
      day094 靠第 ⑥ 条 bptt_matches_numerical（解析 vs 数值差分，2.222e-10 <= 1.0e-09）
      以及上面那条"必须严格更大"的累加专用断言。
```

## 附：本课最值得带回工作现场的五句话

```text
① 先问"哪条判据能反驳它"：相等 / 上界 / 下界各反驳一类错误——
   一条判据如果对错误实现也成立，它就不算判据。                     （day092 7.2 / day096 10.1）

② 反向传播 = 上游梯度 × 局部导数，然后累加；
   前半句是链式法则，后半句是纪律——而纪律那半句写错时，程序不会报错。（day090 第二章 / day094 7.2）

③ "结果更好看"是最危险的失败模式——所以"恢复训练"必须逐位相等（读数 0.0），
   而不是"损失差不多"。                           （day096 第七章）

④ 一个量只写一遍：跨天对账必须调用别人的包，自证是不成立的。
   （day092 7.3 / day093 7.3 / day094 6.2 / day095 6.1）

⑤ 缺席要可断言：把"今天没有这一族"写成常量（RETURNED_FAMILY / ABSENT_FAMILY），
   才能与"我忘了加"区分开。                        （day090 / day092 / day095 / day096 12.2）
```
