# day053 课后习题（M5-D5：微调模型评估）

共 16 题，覆盖领域评估集的四道体检（难度 / 自洽 / 泄漏 / 切分）、六个文本分量的边界定义、
"合格是合取"这条判定、三种小样本统计口径（Wilson 区间 / McNemar 精确检验 / 配对自助法）、
白盒探针（困惑度 / 命中率 / 泛化间隙）与三组标定配置、报告的三项门禁与绑定核对，
以及本日四个真实的坑（chrF 短文本、参考答案自洽、`leakage_rate` 分母、`gates` 口径不一致）。
建议完成时间：90~105 分钟。

> 说明：判断题"对 / 错"请先独立作答，再对照答案核对；参考答案见 [../习题答案/习题答案.md](../习题答案/习题答案.md)。
> **所有涉及数字的题目，数字都能在 day053 快照上实测复现**（`python scripts/finetune_eval_demo.py`，

## 第一部分：选择题

### 第 1 题（难度是结构负载，第一章）

关于 `EvalItem.structural_load` 与 `derived_difficulty`，下列哪一项**最准确**？

- A. 难度是 `EvalItem` 上的一个自由文本字段，`audit_suite` 只检查它非空
- B. `structural_load = |事实点| + |禁项| + |必须片段| + |禁止片段| +（`max_chars <= 150` 时 +1）`；
   `<= 2` 是 easy、`<= 4` 是 normal、否则 hard。声明难度与推导难度不一致时 `audit_suite`
   **返回问题清单而不抛异常**
- C. 难度由 `max_chars` 单独决定：字数越小难度越高
- D. `audit_suite` 发现不一致时会抛 `FinetuneEvalError`，因为这属于评估集的硬性错误

### 第 2 题（切分的粒度与位次，第一章）

关于 `split_suite`，下列哪一项**错误**？

- A. 逐桶配额的算术是 `n_eval = min(n - 1, max(min_eval_per_bucket, round(n · ratio)))`，
   其中 `min(n-1, ·)` 是"训练集非空"的硬保证
- B. 分层粒度选**桶**而不是"桶 × 难度"，因为 18 条用例在 6 桶 3 难度下每格只有 1 条，
   按格子切分时 `max(1, round(0.25)) = 1` 会把每一条都划进评估集
- C. 桶内取哪一条用**轮转位次**（第 `i` 个桶取第 `i mod n` 位），否则每个桶都贡献自己最简单
   的一条，评估集退化成"同一个难度档的六条"
- D. 桶内取哪一条用"每个桶都取排序后的第 0 位"，因为这样最稳定、最容易复现

### 第 3 题（合格是合取，第三章）

关于 `score_item` 的 `passed` 判定，下列哪一项**正确**？

- A. `passed = 加权总分 >= 0.8`，阈值由 `min_pass_rate` 给出
- B. `passed` 是四项的合取：事实点全覆盖 + 无禁项命中 + 无格式违规 + 拒答行为与预期一致；
   加权总分单独报告，回答"好多少"
- C. `passed` 只看事实点，格式与拒答只影响总分
- D. `expect_refusal=False` 的用例里，输出写成拒答也算合格（拒答总是安全的）

### 第 4 题（Wilson 区间，第四章）

为什么 `wilson_interval` 不用正态近似 `p ± z·sqrt(p(1-p)/n)`？下列哪一项**正确**？

- A. 正态近似算得慢
- B. 正态近似在 `p = 1.0` 时给出**宽度为 0** 的区间，等于说"18 条全对 ⇒ 合格率精确等于 100%"；
   Wilson 区间在 `p` 接近 0 或 1 时仍给出合理宽度
- C. 正态近似只在 `n > 1000` 时成立，本课样本太小所以完全不能用
- D. Wilson 区间的宽度恒为 0，所以更"精确"

### 第 5 题（McNemar 检验，第四章）

关于 `mcnemar_exact(b, c)`，下列哪一项**正确**？

- A. 它比较两臂各自的合格率，`b` / `c` 是两个合格率之差
- B. 它只看**翻转的两格**（`b` = 之前过之后不过，`c` = 之前不过之后过），
   `p = min(1, 2·Σ_{k≤min(b,c)} C(n,k)/2ⁿ)`，`n = b + c`；卡方统计量只作参考报出
- C. 它用卡方近似做判定，因为精确检验在 `n = 3` 时不可靠
- D. `b + c = 0` 时它抛错，因为无法计算

### 第 6 题（报告绑定，第七章）

`verify_manifest_binding(report, manifest)` 核对哪三项？下列哪一项**正确**？

- A. 只核对 `content_sha256`
- B. 核对 `content_sha256` / `base_model` / `step` 三项；任一项不一致就抛 `FinetuneEvalError`，
   报告没有绑定清单时也抛错
- C. 核对所有字段，包括 `train_loss` 与 `learning_rate` 的浮点相等
- D. 它只打警告，不抛异常——绑定信息是"尽力而为"的元数据
