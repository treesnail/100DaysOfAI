## 一、基础（1~6）

**1.** 用一句话说清 `encoder_only` / `decoder_only` / `encoder_decoder` 在**结构**上的三处差别。

**2.** 为什么本课说"GPT 与 BERT 的每一层是同一个块"？这句话在代码里对应哪个函数调用？

**3.** 三个变体的参数量（样本 `d=6`、`f=24`、3 层）分别是多少？`encoder_only` 与
`decoder_only` 的参数量为什么相同？

**4.** 写出块、自注意力、交叉注意力、解码器前馈、解码器 LN 这五项各自的解析式，
并用 `d=6、f=24` 算出它们的数值。

**5.** `mask_of("full", 4)` 与 `mask_of("causal", 4)` 各允许多少个位置对？两者的比值
随序列长度 `n` 增长会趋向多少？

**6.** 两张掩码的"熵天花板"分别是多少？为什么这是一个该被记下来的读数？

## 二、掩码与组装（7~13）

**7.** 填充掩码的规则是 `(not pads[j]) or (i == j)`。那个 `or (i == j)` 是为了解决什么
具体问题？如果不加它会以什么形式失败？

**8.** 填充掩码给的三条后果里，第 ③ 条说"填充行仍然看得到非填充的位置与它自己"。
这一条是本课**刻意不处理**的——请说明理由，并指出"真正该做的是什么"。

**9.** `mask_is_causal(mask)` 的判据不读 `causal` 这个参数。请写出它的两条判据，
并解释"把因果性变成**表**的性质"有什么好处（至少两条）。

**10.** 对一张长方形掩码（4×5）调用 `mask_is_causal` 会发生什么？为什么这个拒绝是正确的？

**11.** `combine_masks` 是逐位与。请构造两张**各自合法**、而交集却"把某一行清空"的掩码，
并说明第一版为什么不在这里挡住它。

**12.** `encoder_decoder` 变体为什么**不能**接受 `pads`？请把两条接口事实写出来，
并说明"静默忽略 pads"会造成什么样的失败。

**13.** 为什么 `padding_mask` 里要对每个元素做 `isinstance(value, bool)` 检查，
而不是直接 `if value`？请给出一个会因此被拒绝、而直接 `if value` 会放过去的输入。

## 三、实测依赖表（14~19）

**14.** 请描述"实测依赖表"的构造过程（三步），并说明它为什么比"读 `causal=True`"可信。

**15.** 三个变体的实测依赖表的"可达位置"分别是多少？请把它与各自的掩码对上。

**16.** 被掩码挡掉的格子，实测读数是 `0.000000e+00` 而不是 `1e-16`。请从
`masked_softmax_rows` 的实现出发解释这件事，并说明"逐位"这条判据为什么比"容差"强。

**17.** `DependencyReport` 同时给出 `blocked_gap` 与 `allowed_floor`。
只用前者时会出现什么"假通过"？请构造一个例子。

**18.** 交叉注意力那一路的实测表是 `(4, 5)` 的长方形，而且"一格 0 都没有"。
这句话与 day079 的哪一条拒绝互为正面/反面？请解释。

**19.** `perturb_row` 拒绝 `factor = 1.0`。为什么这个拒绝是必要的？
请说明"扰动为 0 时所有判据都会通过"这件事为什么危险。

## 四、四张表（20~24）

**20.** "掩码的账"里有两行反证。它们各自量到什么？
（请给出"越界/缺失"的个数与它们各自的含义。）

**21.** 为什么反证要用 `expect_mismatch=True` 这个**字段**来表达，而不是写进标签文本里？

**22.** "前缀稳定性"那张表为什么用"变了的行"这个读数，而不是用一个标量？
请给出三个变体在扰动最后一个 token 时的读数。

**23.** 家底那张表里，"逐个数"与"公式算"两条路径必须相等。这条断言挡住的是哪一类错误？
请举一个"参数少了一块、而前向照样跑"的具体例子。

**24.** `leak_study` 的 `_counts_against` 同时给出"越界"与"缺失"。
只量"越界"时会漏掉哪一种失败？请给出一个具体的掩码配置。

## 五、性质与判据（25~28）

**25.** 六条性质里哪两条在 `encoder_only` 上"不适用"？请说明本课为什么给读数加了

**27.** `check_weights_are_zero_where_masked` 在 `encoder_only` 上的证据是
"掩码外共 0 个权重"。请说明本课为什么**如实**印出这个 0，而不是把它当成"通过"。

**28.** 为什么梯度校验要放在**整条变体**上（而不是只放回 day075/079 的层与块上）？
