# day102 习题：把 100 天的失败族编成一份台账

> 对应教程：[../教程/教程.md](../教程/教程.md)
> 对应手册：[../源码/smart-research-agent/docs/failure_ledger.md](../源码/smart-research-agent/docs/failure_ledger.md)
> 建议用时：30~40 分钟。答案在 [../习题答案/习题答案.md](../习题答案/习题答案.md)。

题目分为四类：**速答**（1~6）、**对照**（7~9）、**诊断**（10~13）、**推导与动手**（14~18）。

---

## 一、速答

1. 本课扫描的目标是哪一类文件？为什么是"每个子包一份"而不是"每个 `.py` 一份"？

2. 台账里 `local / builtin / imported / unresolved` 四类归属的**判定顺序**是什么？为什么顺序不能换？

3. 一个族的 `root` 与 `sub` 是怎么区分的？为什么"每一份 `errors.py` 恰好一个根"值得做成一条相等判据？

4. 本课为什么不 `import` 被扫描的模块，而是用标准库 `ast` 读源码？请说出**两条**具体好处。

5. 台账的 `comparable()` 里"一个集合、一个字典都没有"——这句话为什么重要？

6. 本课"回来的族"与"缺席的族"分别是哪一个？各自给出一条理由。

---

## 二、对照

7. 把本课的四类归属与 day101 的"两种语料"对照：它们各自解决了什么"名字撞车"的问题？

8. 七条性质里，哪几条是**相等**、哪一条是**上界**、哪几条是**下界**？把方向写反会产生什么后果？

9. `LedgerBuildError` 与 `CoverageError` 的分工是什么？（一个是"自洽"，一个是"完整"。）

---

## 三、诊断

10. 某子包写了：

    ```python
    class ShapeError(CoreShapeError, StackError):
        ...
    ```

    其中 `CoreShapeError` 是它 `from smart_research_agent.transformer_core.errors import (...)` 进来的别名，
    `StackError` 是本文件里定义的。请给出这一条基类引用在两处（`CoreShapeError`、`StackError`）
    各自的**归属类别**与 `target`。

11. 有人把 `resolve.resolve_base` 的判定顺序从 `local → builtin → imported` 改成
    `builtin → local → imported`。请构造一个会被改错的例子，并说明现象。

12. 某次扫描后 `base_references_resolve` 报"未解析 3 个"。请说出**三种**可能导致它的原因，
    以及各自该改哪里。

13. 一个手写的族记录 `Family(package="p", name="Solo", bases=(BaseRef("Ghost", "local", "Ghost"),))`
    被塞进台账后，第一次调用 `max_depth()` 会发生什么？为什么这里必须"当场报"而不是"当成根"？

---

## 四、推导与动手

14. 给定一个小模块：

    ```python
    # a/errors.py
    class AError(ValueError): ...
    class BError(AError): ...
    class CError(BError, AError): ...
    ```

    请算出 `AError / BError / CError` 三个族的继承深度，并说明为什么 `CError` 的深度不是 3。

15. 证明：如果一份 `errors.py` 里出现 `class A(B)` 与 `class B(A)`，那么
    "每一份 `errors.py` 恰好一个根"这条性质一定失败，并且 `max_depth()` 一定抛错。

16. 用本包的公开 API 写一段 6 行以内的代码，打印出"仓库里所有**没有** `errors.py` 的子包名"。

17. 写一条**新的**性质（不要求实现进源码），要求：
    - 它是一条**下界**判据；
    - 它检查的是"跨包基类（`imported`）至少出现过一次"；
    - 说明它的失败意味着什么。

18. 本课反复强调"一份没被抓到的材料，与'它不存在'读起来一样"。
    请再举一个**本仓库里真实存在**的类似例子（可以是 day101 的，也可以是别的课的），
    并说明它是怎么被"点名"的。
