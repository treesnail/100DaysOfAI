## 第一部分：选择题

### 第 1 题（SFT 与预训练的差别，第一章）

关于"SFT 与预训练在工程上的唯一区别"，下列哪一项描述**最准确**？

- A. SFT 用的损失函数不同：SFT 用交叉熵，预训练用负对数似然
- B. SFT 的优化器不同：SFT 用 AdamW，预训练用 SGD
- C. 损失函数与优化器都相同，区别在于**求和的集合与分母**——SFT 只对答案段求平均，工程上落成 `labels` 里 prompt 段的 `-100`
- D. SFT 必须冻结一部分参数，预训练必须更新全部参数

### 第 2 题（渲染与编码，第二 / 三章）

关于 `render_supervised` 与 `encode_supervised`，下列哪一项**错误**？

- A. `RenderedSample` 用两个字符偏移（`prompt_chars` / `supervised_chars`）标明边界，而不是两个字符串
- B. 编码时必须把前缀与监督区间**分别** tokenize 再拼接，不能编码整段文本再按字符偏移切片
- C. 由于 `CharTokenizer` 是字符级的，分别编码与整体编码的结果完全相同，所以 B 的说法在本课实现里没有实际影响
- D. 若改为"先编码整段再切片"，在 BPE 类分词器上会因跨边界的字符合并而切错

### 第 3 题（截断策略，第三章）

关于 `keep-answer` 截断策略（缺省），下列哪一项**正确**？

- A. 超出 `max_length` 时从右侧截断答案，保证 prompt 完整
- B. 预算先给答案，剩下的给 prompt，并从**左侧**裁掉 prompt；答案放不下时直接抛 `SFTDataError`
- C. 超出 `max_length` 时随机丢弃一部分 token，保证分布均匀
- D. 答案放不下时自动把 `max_length` 调大，避免丢样本

### 第 4 题（loss 的分母，第三章）

`masked_cross_entropy` 返回 `(loss, 监督 token 数)`，而不是只返回 `loss`。关于这个设计，下列哪一项**错误**？

- A. 把分母交出来是刻意的：它让调用方能核对"监督 token 数是否等于自己预期"
- B. 若分母误用序列长度（含 prompt 与 padding），loss 会被系统性压低，同时**等于把有效学习率偷偷缩小了 `T'/T` 倍**
- C. 返回两个值只是为了让日志能多打印一个字段，对正确性没有影响
- D. 没有任何监督位置时应当抛错，而不是返回 0.0——返回 0 会把"mask 全错"伪装成"loss 完美"

### 第 5 题（`max_length` 的标定，第四章）

按本日实测，关于 `max_length` 的取值，下列哪一项**正确**？

- A. 应当尽量贴近基座模型的上下文窗口（如 2048 或 4096），以避免截断
- B. 应当按 day048 `DatasetStats` 的 `avg_estimated_tokens`（84.24）取 128
- C. 应当按**渲染并分词之后**的长度分位数取；本数据集实测 `p95 = 302`、`max = 320`，取 320 时 0/30 条截断
- D. 取多大都无所谓，因为 padding 只影响显存，不影响训练结果

### 第 6 题（学习率与步数，第四章）

关于本日算出的六个数字与学习率，下列哪一项**错误**？

- A. `micro_batches_per_epoch = 15`、`steps_per_epoch = 3`、`total_steps = 9`（`drop_last` 口径）
- B. `warmup_steps = int(9 × 0.03) = 0`，即 3% 的 warmup 在 9 步下必然取整为 0
- C. `effective_batch_size = per_device_train_batch_size × gradient_accumulation_steps = 8`
- D. 参考模型用 `learning_rate = 2e-4` 最合适，因为它与 7B 全参微调的推荐值一致

## 第二部分：判断题

请判断下列说法是否正确，并说明理由。

### 第 7 题（第三章）

零监督样本（`labels` 全为 `-100`）应当保留在训练集里，因为它至少能让模型多"看"一遍数据。

### 第 8 题（第三章）

为了保证模型学会"在哪里停下"，监督区间除了答案本身，还应当包含轮次终止符（如 `<|im_end|>` / `<|eot_id|>`）。

### 第 9 题（第四章）

`lr_at(0, total_steps)` 在 `warmup > 0` 时返回 0.0，这是本课实现的一个 bug，正确行为应该返回峰值学习率。

### 第 10 题（第六章）

对照实验里，不屏蔽 prompt 的那一组"训练报告 loss"更低（4.6352 < 5.4770），说明不屏蔽 prompt 效果更好。

### 第 11 题（第七章）

TRL 的 `packing=True`（把多条短样本拼进同一条序列）能提高吞吐，因此在任何规模的数据上都应当开启。
