## 一、选择题（7 题）

**1.** 让"多层网络"区别于"一层网络"的，是：

- A. 层数本身
- B. 权重矩阵的大小
- C. **激活函数**带来的非线性（拿掉它，多层塌缩成一个仿射映射）
- D. 初始化方式

**2.** 本课 `Dense` 的权重形状与前向，与 `torch.nn.Linear` 的对应是：

- A. 权重 `(in, out)`、前向 `W·x + b`
- B. 权重 `(out, in)`、前向 `x·Wᵀ + b`
- C. 权重 `(out, out)`、前向 `x·W + b`
- D. 权重 `(in, in)`、前向 `x·Wᵀ + b`

**3.** `sigmoid` 在本课里写成"按符号分支"两条式子，是因为：

- A. 两条式子算得更快
- B. 单一式子 `1/(1+e^{-x})` 在 `x = -1000` 时要去算 `e^{1000}`：
     CPython 的 `math.exp` 直接抛 `OverflowError`（numpy / torch 里则是 `inf`）
- C. 两条式子的结果不同
- D. `math.exp` 不支持负数

**4.** `softmax` 先减去最大值，这条操作的性质是：

- A. 一个近似，会引入误差
- B. 一个**恒等变形**（分子分母同乘 `e^{-max}`），只改变数值稳定性、不改变结果
- C. 只在训练时用
- D. 会把分布变成 one-hot

**5.** 关于"恒等塌缩"，正确的说法是：

- A. 只要层数够多，任何网络都能塌缩成一层
- B. **全恒等激活**的多层网络等于一个仿射映射；只要有一层带激活，这条等式就失效
- C. 塌缩是近似的，与激活无关
- D. 塌缩只在 `relu` 上成立

**6.** 交叉熵在本课里从 **logits** 起步，而不是从概率起步，因为：

- A. logits 更小
- B. 概率为 0 时 `−log(p) = +inf`；而 `−log_softmax(logits)` 在同样的输入下仍有限
- C. 概率算不出 logits
- D. 两者完全等价，随便选

**7.** `xavier` 的尺度是 `√(6/(fan_in + fan_out))`。当 `fan_in + fan_out = 0` 时，本课抛：

- A. `ZeroDivisionError`

## 四、推导题（3 题）

**16.**（推导）softmax 的平移不变性与"减最大值"。
设 `z ∈ Rⁿ` 任意，`c = max(z)`。请证明：

```text
softmax(z)_i = exp(z_i - c) / Σ_j exp(z_j - c)   ==   exp(z_i) / Σ_j exp(z_j)
```

并说明：这个等式为什么只是**数值**上的意义（不改变结果，只避免上溢）。

**17.**（推导）恒等塌缩。
设一层是 `y = x·W₁ᵀ + b₁`（`x` 是行向量、`W₁` 形状 `(m, k)`），
第二层是 `z = y·W₂ᵀ + b₂`（`W₂` 形状 `(n, m)`）。请证明存在一组 `(W, b)` 使

```text
z = x·Wᵀ + b
```

并给出 `W` 与 `b` 的表达式（用 `W₁, b₁, W₂, b₂` 表示）。
最后说明：如果两层之间插一个 `relu`，为什么这个推导不再成立。

**18.**（推导）两个下界/m 恰好值。
设预测 `p` 与目标 `t` 形状相同。请证明：

```text
（甲）mse(p, t) = 0  ⇔   p = t（逐元素）
（乙）设 q = softmax(z)、target = k，则 CE = −log q_k ≥ 0
```

（提示：甲用"平方和 = 0 ⇔ 每一项为 0"；乙用 `0 < q_k <= 1`。）
最后各写一句：这两个结论分别挡住了哪一类实现错误。
