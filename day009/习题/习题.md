### 第 10 题（给向量库加相似度阈值过滤）

在生产系统中，如果查询与库中所有记录都不相关，强行返回 top-k 会污染上下文。请在 `smart_research_agent/memory/vector_store.py` 的 `InMemoryVectorStore` 中新增一个方法：

```python
def search_with_threshold(
    self, query_vector: list[float], top_k: int = 5, min_score: float = 0.0
) -> list[tuple[VectorRecord, float]]:
    """相似度检索，但只返回 score >= min_score 的记录."""
```

要求：

1. 不修改现有 `search` 方法的行为；
2. 在 `tests/test_long_term.py` 中新增至少两个测试：一个验证阈值过滤生效（低分记录被剔除），一个验证 `min_score=0.0` 且库中只有正相似度记录时行为与 `search` 一致；
3. 运行全部测试确认无回归。

提示：可以在方法内复用 `search` 的结果再过滤，注意余弦相似度可能为负值。
